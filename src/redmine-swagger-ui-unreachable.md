# Swagger UI にアクセスできない調査結果

## インシデント概要

- 対象: `http://127.0.0.1:8000/docs`
- 現象: ブラウザからアクセスできない。
- 期待値: FastAPI 標準の Swagger UI が表示される。

## 確認した事実

- 現在、TCP ポート `8000` の待受は存在しない。
- `http://127.0.0.1:8000/docs` への接続はタイムアウトした。
- 現在、`python.exe` プロセスは存在しない。
- 直近の stderr ログには、過去に Uvicorn が `http://127.0.0.1:8000` で正常起動した記録がある。
- 直近の stdout ログには、過去に `/openapi.json` が HTTP 200 を返した記録がある。
- 過去のサーバープロセス PID `17772` は現在存在しない。

## 原因候補

### 最有力・確定可能

- API サーバーが現在起動していない。

### 否定済み

- Swagger UI が未導入: FastAPI 標準 `/docs` が有効で、README と実コードにも根拠があるため該当しない。
- `/openapi.json` 自体の恒常的な失敗: 過去ログで HTTP 200 を確認しているため、今回の接続不能の直接原因ではない。

## 判定結果

- 判定: コード修正不要。API サーバーの起動が必要。
- 実装引き継ぎ: 不要。

## 次に取るべき行動

プロジェクトルート `D:\develop\jra-scr` で次を実行する。

```powershell
uv run uvicorn jra_srb.app:app --reload
```

起動ログに次が表示された後、ブラウザで再確認する。

```text
Uvicorn running on http://127.0.0.1:8000
```

- Swagger UI: `http://127.0.0.1:8000/docs`
- 疎通確認: `http://127.0.0.1:8000/health`

## 未確認

- 今回はサーバー起動操作を行っていない。
- サーバーを終了した経緯や、自動起動の運用有無は未確認。
