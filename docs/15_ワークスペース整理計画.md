# ワークスペース整理計画

## 目的

- ルート直下の散在ファイルを減らす
- `data/` と `.workstate/` の役割を明確にする
- 実移動前に、移動先ルールと対象一覧を固定する

## 今回の前提

- 今回は移動しない
- 対象は 2026-07-09 時点で確認できた実ファイル
- 本体コード、テスト、主要ドキュメントは原則そのまま

## 移動先ルール案

### 1. ルート直下

- ルート直下に残すのは `README.md`、依存定義、Git 関連、主要設定のみ
- 単発の JSON、ログ、検証出力は置かない

### 2. `data/`

- 永続的に参照するローカルデータを置く
- 用途別に次の配下へ寄せる
  - `data/db/`: SQLite などのローカル DB
  - `data/raw/jra/`: JRA の取得生データ
  - `data/raw/nankan/`: 南関の取得生データ
  - `data/exports/`: 集計済み JSON / JSONL / CSV
  - `data/reference/`: 再取得頻度が低い参照資料
  - `data/manual_snapshots/`: 単発確認の保存物

### 3. `.workstate/`

- 開発中の作業メモ、検証補助、臨時ログ、再起動補助を置く
- 用途別に次の配下へ寄せる
  - `.workstate/logs/`: stdout / stderr / 一時ログ
  - `.workstate/scripts/`: 単発検証スクリプト
  - `.workstate/manual_checks/`: 手動確認用 JSON / txt / 小規模 DB
  - `.workstate/jra-srb/`: 継続中の spec / progress 資料置き場として維持

### 4. `notes/`

- 人間が読む運用ログ、引き継ぎメモ、当日判断ログを置く
- 機械取得 JSON や API 応答は置かない

### 5. `docs/`

- 再利用する仕様、運用手順、設計判断のみ置く
- 一回限りのログや生データは置かない

## 今回の実ファイル移動案

## 今回は移動対象にしないもの

- `src/`, `tests/`, `skills/`, `notes/`, `docs/` の通常ファイル
- `.workstate/jra-srb/` 配下の spec / progress 群

## 別枠の整理候補

- Git 管理中の `__pycache__` と `.pyc`
  - 移動ではなく追跡解除と ignore 見直しの対象
- `.gitignore` に未反映の一時出力
  - ルート直下の単発 JSON / ログは将来的に ignore 見直し候補
