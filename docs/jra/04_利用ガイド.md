# 利用ガイド

この文書は `jra-srb` を使うときの入口です。詳細な endpoint は [05_API仕様.md](/D:/develop/jra-scr/docs/jra/05_API仕様.md)、CLI コマンドは [06_CLI仕様.md](/D:/develop/jra-scr/docs/jra/06_CLI仕様.md) を正本とします。

## 何ができるか

- JRA 公式サイトから開催一覧、出馬表、オッズ、結果を取得する
- netkeiba から補完データを取得する
- 地方競馬全国協会 NAR の一部データを取得する
- 南関東 4 場の開催、出馬表、オッズ、結果、予想補助データを取得する
- 保存済み結果や分析 DB を参照する
- CLI で結果収集、分析収集、補助 API 呼び出しを行う

## セットアップ

```powershell
uv venv
uv pip install -e .[dev]
```

## API サーバー起動

```powershell
uv run uvicorn jra_srb.app:app --reload
```

確認先:

- API: `http://127.0.0.1:8000`
- Swagger UI: `http://127.0.0.1:8000/docs`
- OpenAPI JSON: `http://127.0.0.1:8000/openapi.json`
- MCP endpoint: `http://127.0.0.1:8000/mcp`

ヘルスチェック:

```powershell
curl http://127.0.0.1:8000/health
```

## テスト

```powershell
uv run --extra dev pytest -q
```

## よく使う流れ

### 1. JRA のレース情報を見る

開催一覧:

```http
GET /meetings/2026-03-22/nakayama
```

出馬表:

```http
GET /meetings/2026-03-22/nakayama/races/11/card
```

オッズ:

```http
GET /meetings/2026-03-22/nakayama/races/11/odds?bet_type=trifecta&combination=1,2,3
```

結果:

```http
GET /meetings/2026-03-22/nakayama/races/11/result
```

### 2. `race_id` が不明な状態から探す

```http
GET /search/races?date=2026-03-22&course=nakayama&keyword=スプリング
```

または:

```http
GET /races?date=2026-03-22&course=nakayama
```

### 3. netkeiba 補完データを見る

```http
GET /netkeiba/races/202605021211/result
GET /netkeiba/races/202605021211/odds?bet_type=quinella&combination=10,11
```

詳細な使い方は [10_netkeiba利用ガイド.md](/D:/develop/jra-scr/docs/jra/10_netkeiba利用ガイド.md) を参照。

### 4. 南関予想用データをまとめて取りたい

最小構成:

```http
GET /nankan/meetings/2026-07-06/kawasaki/races/1/card
GET /nankan/meetings/2026-07-06/kawasaki/races/1/odds-summary
GET /nankan/meetings/2026-07-06/kawasaki/races/1/trend-context
GET /nankankeiba/pattern/meetings/2026-07-06/kawasaki/races/1?meeting_no=4&meeting_day=1
```

まとめ取り:

```http
GET /nankan/meetings/2026-07-06/kawasaki/races/1/prediction-bundle?meeting_no=4&meeting_day=1
```

補助資料:

- [17_nankan_prediction_materials_usage.md](/D:/develop/jra-scr/docs/jra/17_nankan_prediction_materials_usage.md)
- [20_nankan_leading_jockey_usage.md](/D:/develop/jra-scr/docs/jra/20_nankan_leading_jockey_usage.md)
- [27_nankan_prediction_bundle_usage.md](/D:/develop/jra-scr/docs/jra/27_nankan_prediction_bundle_usage.md)

### 5. 保存済み結果や分析 DB を扱う

保存済み結果参照:

```http
GET /stored/results?from_date=2026-03-22&to_date=2026-03-22&course=nakayama
GET /stored/results/202603220611
```

CLI 収集:

```powershell
uv run jra-srb collect-results --from-date 2026-03-22 --to-date 2026-03-22 --courses nakayama --output data/results.jsonl
uv run jra-srb collect-analysis --from-date 2026-03-22 --to-date 2026-03-22 --courses nakayama --db data/db/analysis.sqlite --include-card --include-odds --include-results
```

## CLI の使い分け

- API をそのまま叩きたい
  - `call-local-api`
- JRA 結果を保存したい
  - `collect-results`
- 分析用 SQLite を育てたい
  - `collect-analysis`
- netkeiba 補完を analysis DB に取り込みたい
  - `generate-netkeiba-mapping`
  - `collect-netkeiba-results`
- 南関予想材料を単発取得したい
  - `fetch-nankan-prediction-bundle`
  - `fetch-nankankeiba-pattern`

CLI の詳細は [06_CLI仕様.md](/D:/develop/jra-scr/docs/jra/06_CLI仕様.md) を参照。
