# S2 順位専用学習の固定研究

2026-11-05。S0と同じ入力で学習目標を順位へ変える研究を、初案S2Aと負例の偏りを是正したS2Bまで実施した。**修正版でもS0/D0の的中率・回収率を超えず、今回の2案は不採用として閉じる。**

## 目的と変更範囲

S1では確率評価の小さな改善が的中数・回収率へつながらなかったため、次は学習目的を変えると改善するかを検証した。オッズ・当日属性・競馬場・芝ダート・距離・季節というS0の14列、教師、学習内尺度、条件群、L2を維持し、確率CEを外して対比較の順位損失だけを学習した。全モデルでS0の尺度・条件群が保存値と厳密一致した。

対比較の考え方は[Burgesらの一次資料](https://www.microsoft.com/en-us/research/publication/learning-to-rank-using-gradient-descent/)を参照した。ニューラルネットRankNetの再現ではなく、既存の線形条件モデルとSciPy最適化を再利用した研究である。

以前のspec360にもH2の履歴入力へCE＋順位損失を加えた研究があり、H2が選ばれて終了していた。今回はその再実行ではなく、現在保存できるS0入力だけの純順位学習とした。

過去追加取得・SQL・レース情報HTTP・D0/S0/S1再学習は0。既定・予想スキル・収集・購入設定は変更していない。依存追加なし（既存NumPy/SciPy/joblib/threadpoolctlを使用）。

## 初案S2Aの失敗と原因の切り分け

初案は、正解馬連を市場上位5組の非正解候補より上へ並べる目的とした。開発2023で4的中、後年7,857競走でも3的中・回収率27.52%まで悪化した。独立検算で、符号・スコア・純順位目的・精算・CIは一致しており、実装上の順位反転ではなかった。

市場上位以外の組が負例には一度も現れず、的中した時だけ正例に現れる設計だった。このため、上位外の組を押し上げる偏りが生じた。実際にS2Aが選んだ組の市場順位は平均85.10位、中央値90位、市場上位5組の選択率は0%だった。

市場確率が真の確率そのものである人工例でも、上位外スコアを上げる勾配が残ることを確認した。同じ人工例で全非正解組を負例にすると、真のlog市場での期待勾配は最大絶対値4.1e−18まで相殺された。これは学習分布の診断であり、実レースの市場確率が真値だと仮定した性能証明ではない。

最初の診断v1は温度0での単一微分だけを見ており、解釈が不十分だった。結論の根拠は全スコアの期待勾配を再現したv2と専用テストである。v1を含む途中記録は保全し、採否根拠には使わない。

この原因をspec436で明示し、負例を全ての非正解組へ広げたS2Bを一案だけ追加した。入力・L2・教師・年境界・採否基準は変えず、結果に合わせた特徴や購入条件の調整はしていない。初案4fit＋修正版4fit＝計8fitで終了した。S2Aの結果をS2Bで上書きしていない。

## 検証・実入力・最終判断

- 専用テスト9件成功。CE不使用、負例選択、競走等重み、条件を含む勾配、S0尺度再利用、結果/履歴遮断、日単位抽出、市場が正しい人工例の勾配、全負例の網羅を確認した。
- Python8ファイルの構文、ヘッダー、全関数docstringを確認。
- 両案それぞれ10,744評価スコア・42,976モデル別精算を独立照合しpassed。全4モデルの教師目的、S0尺度/条件、全bootstrap、選抜・採否も再現。計数は同じレース/基準を各案で再確認した件数であり、独立な試験件数の増加ではない。
- 2026用S2Bは2020-01-05〜2025-12-28の17,309競走、154条件（共通含む）、1,612,291正解対非正解比較で学習した。
- 10/25時点監査済み固定原本105レース300時点で、両案とも全件スコア/順位生成できた。これは同じ原本の入力互換検査であり、新規の発走前保存・未知性能試験ではない。原本以降の保存全体を不存在と判断したものでもない。
- スコアを確率に変換していない。予想テンプレートの確率欄やモデル登録へ接続していない。

**順位専用へ変える今回の2案は不採用。** 初案の負例分布の欠陥は是正できたが、修正版もS0/D0の精度・固定回収率を改善しなかった。この線形14列・固定正則化での結果であり、全ての順位学習が無効とは一般化しない。S0を現在入力で動く比較基準、D0を既存精度の比較基準として保持する。

初案正本: `artifacts/jra_research/rank_current_S2_20261105`。修正版正本: `artifacts/jra_research/rank_current_S2B_20261105`。各runのassessment.json、independent-verification.json、capture-replay.jsonを参照。S2BはS2ファミリ共通保存名 `2026_S2.joblib` を使い、モデルのcase=S2B/training_protocol=spec436/negative_top=allで区別する。S2Aのモデルを上書きしていない。
