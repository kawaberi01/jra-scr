# S0 市場・当日属性モデルの検証結果

2026-10-25。spec425に従い、新モデルS0の学習・保存原本からの推論・独立検算を完了した。**履歴なしで動くモデルは完成したが、D0を上回る更新候補とは判定しない。購入採用もしない。**

過去の不足履歴は取得できず、今後の事前情報は既に保存されているという前提で実施した。追加の過去取得をせず、既存datasetの市場と当日属性だけを利用した。

## モデルと実入力

S0の入力は単勝・馬連市場、年齢、性別、枠、馬番、競馬場、芝ダート、距離、日付。馬別15履歴特徴・ネイティブ馬ID・直近走を要求しない。履歴をゼロに置き換えたD0ではなく、14列の別モデルである。

既存の条件別学習を再利用し、共通係数に競馬場×芝ダート、芝ダート×距離帯、その組合せ、季節等の補正を加える。100教師未満の条件は学習済みの親条件・共通へ戻す。これは競馬場ごとの完全独立学習ではない。独立場別D0は既研究で比較済み。

年境界を守って2023/24/25/26の4モデルを逐次学習した。最終モデルは2020-01-05〜2025-12-28の17,309競走で学習し、154条件（共通を含む）を保持する。D0再学習0回、新規依存追加なし。

保存原本105レース300時点をカード・単勝・馬連から変換し、**300/300件で全ペア確率を生成できた**。原本の過去走は使っていない。この生成は既存保存情報の互換検査であり、発走前の新予想保存や300件の未知性能試験ではない。

2024年2,839、2025年2,856、2026年2,162競走。2026年は既存datasetの収録範囲のみである。各年の対象年より前を教師にした。既に研究で参照された過去のため、完全未知評価とは呼ばない。

D0比の損失改善区間は−0.005458〜−0.001146で、S0の方が悪い。D0より履歴情報が少ないことによる性能差は残った。開発年2023でもS0は的中率こそ上がったが損失がD0より悪く、事前固定の更新条件を満たさなかった。2026だけの改善を理由に採用しない。

## 検証と判断

- 専用4テスト成功。履歴・結果の遮断、対象日以降学習の拒否、全ペア価格欠損の拒否、学習境界と解析勾配を確認。
- 独立式で開発年を含む10,744評価分布、32,232件のモデル別精算、保存原本300分布を照合しpassed。
- 新規Python4ファイルの構文、ヘッダー、全関数docstringを確認。仕様・コード・入力・全成果物SHAを検証。
- 既定モデル、スキル、SQL、収集処理、過去予想、購入設定は変更していない。

S0は「現在の保存情報だけで推論でき、市場より確率評価が良い」基準モデルとして保存する。D0との置換・購入は見送る。今後の改良比較は、S0を利用可能入力側の基準、D0を既存精度側の基準として使える。直近走を加える場合は、学習側と実入力側で同じ定義を作れる特徴に限定する別仕様とし、今回の後年結果を見て都合のよい条件を選び直さない。
