# 予想家由来SQL研究：第四段階の結果

実施日: 2026-10-17。対象: spec100で実行前に固定した6案。**固定比較は完了したが、実購入には採用しない。**

## 結論

- 同じ評価1,594Rで学習を1,412Rから2,671Rへ増やすと、S06は79.17%→80.86%、S08は74.33%→76.07%となった。これは今回の再使用評価の差であり、将来の改善を保証しない。
- 長期学習の馬連では、履歴のみ77.42%に対して内容を混合したS08は76.07%。対数損失も3.362372→3.364733で悪化。**長期学習で内容特徴を追加する効果は確認できなかった。** 短期では回収率が改善したが、確率損失はわずかに悪化しており、一貫した優位とは扱わない。
- 6案すべて回収率100%未満。学習・保存・評価が成立することと、利益のある買い方であることは分ける。旧運用モデルの置換・実購入採用は行っていない。
- 馬連の確率損失は市場基準より小さい一方、S06のワイドBrierは市場基準より大きい。順位/確率の改善と購入成績は一致しない。

## 固定条件と入力

学習: 長期2024-01-01〜2025-09-30、短期2025-01-01〜09-30。校正: 2025年10月。評価: 2025年11〜12月、2026年1〜2月、3〜5月。夏6〜8月は除外。全期間は過去に参照済みの**再使用評価**で、独立した未使用テストではない。今回の結果を見た閾値・場・期間の変更や勝者選択は行っていない。

入力契約は `analysis34-history-retrospective31-card-v1`。SQL34の公式履歴・netkeiba内容履歴/ワイド払戻、SQL31のT30単勝/馬連・SE/RA属性・HR馬連払戻を使った。履歴母集団は旧JSONLと同値ではなく、属性の当時利用可能性も未証明。厳密発走前再現・旧モデル完全互換を主張しない。SQLite/旧JSONL読取は専用プロセスの拒否hookで禁止した。
