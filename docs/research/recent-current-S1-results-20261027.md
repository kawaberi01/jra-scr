# S1 直近走追加モデルの固定検証

2026-10-27。spec430に従い、S0へ直近走5特徴を加えたS1の4年境界モデルを学習した。**今回の構成は採用しない。S0比の確率評価に小さな改善はあるが、開発選抜・的中率・回収率で更新条件を満たさず、D0にも届かない。**

## 実施範囲と入力

過去の不足履歴は取得できず、今後の事前情報は保存済みという前提を維持した。追加取得・SQL・HTTPをせず、既存2020〜26年の年別保存ファイル7本、計23,295競走から前走状態を作成した。学習・評価対象は従来と同じ19,471競走。2020年より前や保存の抜けは補完していない。

追加特徴は、直近走の頭数相対着順、今回との距離変更、芝ダート一致、180日以内の出走間隔、欠測の5値。S0の14ペア列に、5値のペア平均/絶対差10列を足した24列の別モデルである。競馬場・芝ダート・距離帯・季節の補正と100教師以上の条件差分、正則化はS0方式を再利用した。競馬場完全独立の再探索はしていない。

学習側は保存済み馬IDで前走を追い、同日全対象の特徴確定後にだけ当日結果を状態へ反映する。保存カードの前走間隔とも照合し、不一致は欠測とする。当日側は公式直近走の最新日付枠を同じ5値へ変換し、ネイティブ馬IDを要求しない。最新の異常・対象外走を飛ばして古い好走へ置き換えない。

前走が未観測、180日より古い、障害等で解釈不能、着順/頭数が不十分なら、4値0＋欠測1とした。欠測馬を比較集合から落とさず、0を観測済みと偽らない。

### 入力充足と制約

- 全19,471競走272,050頭の特徴を生成。前走4値を採用できたのは204,627頭（75.22%）。残りは明示欠測。
- 内訳は未観測32,817、前走結果の品質不足25,330、180日外8,401、対象外表面442、保存間隔不一致433。
- 学習側は前走競走全体の順位・異常区分を完全に解釈できる場合に限定した保守的な扱い。取消等を含み実出走頭数を確定しない走も欠測になる。
- 当日原本は105レース300時点すべてでS1推論成功。3,932頭時点のうち観測採用2,993（76.12%）、未観測783、結果品質不足48、180日外96、対象外12。
- 過去年別保存の範囲と当日カード最大4枠の範囲・欠測理由は異なる。75.22%と76.12%という総充足率の近さだけで同一分布や完全な前向き適格を主張しない。歴史カードの当時公表時点も未証明。
- 300時点の生成は保存情報の互換検査。後日作成したモデルによる再生であり、発走前の新予想保存・未知性能試験ではない。

## 検証と採否

専用12テストと丸め差の再現1テスト、計13テストが成功。前日境界、同日結果の反映順、間隔不一致、異常走を古い好走へ差し替えないこと、当日結果・元D0履歴の遮断、解析勾配、float32計算境界を確認した。Python6ファイルの構文・ヘッダー・全関数docstringも確認した。

独立検算v2はpassed。全19,471競走272,050頭の前走参照元・欠測理由・特徴、開発年を含む10,744評価分布、42,976件のモデル別精算、保存原本300分布が一致した。元ソース/入力/モデル/保存ファイルのSHA、訓練年境界、選抜と採否も確認済み。最終証跡は `independent-verification.json` と `verification-method.json`。新規学習4回、D0/S0再学習0回、検算修正による再学習0回。

初回の別式検算は202501180712の確率差1.4561e−11で厳密照合に失敗した。sumと内積で中心化の縮約順が異なり、float32の丸めが最大3.7253e−9だけ違ったことを再現した。一次モデルの再生成値と保存値は一致。独立列挙を保ったまま内積/float32境界をそろえたv2検算器を追加し、許容差は緩めず、特徴・係数・学習結果も変えていない。失敗記録と診断、元検算器のSHAは保全した。joblib読込ではNumPyに関する既存依存の非推奨警告が出るが、読込と照合は実行できている。依存更新は行っていない。

**今回の前走5特徴追加研究は不採用として閉じる。** S0を利用可能入力の基準、D0を既存精度の基準として保持する。S1で後年の確率損失が僅かに改善した点は記録するが、採用条件・的中率・収益の不足を覆さない。既定モデル・予想スキル・収集・SQL・過去予想・購入設定は変更していない。今回の確認結果に合わせた追加の特徴/閾値探索は実施しない。
