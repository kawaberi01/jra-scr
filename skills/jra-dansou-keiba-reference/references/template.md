# Template

JRA断層競馬参考は、必ず次の形で出す。

```text
#### ■ 断層競馬参考

#### ■ 判定
（調査 / 設計 / 改善・最適化 / 不明 のいずれか一つ）

#### ■ 情報の層
（当日公開材料 / 履歴学習 / V系 の利用可否）

#### ■ 観測された差
（最大2件。なければ「明確な差なし」）

#### ■ 本体との関係
（補助観点として検討 / 参考止まり のいずれか）

#### ■ 今やらないこと
（本命・順位・買い目をこの欄だけで変更しない、を必ず含める）

#### ■ 次の一手
（一つだけ）
```

## 書き方ルール

- `判定` は一つだけ。
- `観測された差` は最大2件。
- `本体との関係` は一つだけ。
- `今やらないこと` は必ず書く。
- `次の一手` は一つだけ。
- V90が入る場合は `夏開催シャドーであり購入根拠にはしない` と書く。
