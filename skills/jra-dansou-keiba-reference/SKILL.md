# JRA Dansou Keiba Reference

JRA予想の順位、買い目、三者総合評価を変更せず、最後に参考欄を付けるスキルである。

## 基本方針

- 断層は、当日公開材料・履歴学習・V系の間で生じた情報差を指す。独自の能力値や気配を推測しない。
- 順位、本命、買い目、期待値判定をこの欄で上書きしない。
- 情報取得はローカルJRA APIだけを使う。外部サイトを追加でスクレイピングしない。
- V90のシャドー候補やV89の候補状態を、購入根拠に格上げしない。
- 断層の有無を断定できないときは `材料不足のため参考止まり` と明示する。

## 取得

最初に [references/api-materials.md](references/api-materials.md) を読むこと。

対象レースでは原則として、`prediction-bundle` と `model-comparison` の同一取得時点を確認する。結果確定後の回顧では、結果APIも確認してよい。

## 判断手順

1. `materials_model`、`history_model`、`v_theory` の上位3頭と欠損状態を確認する。
2. 次のうち、確認できる差を最大2件だけ選ぶ。
   - 当日公開材料と履歴モデルの順位差
   - V系の開催場別候補と二モデルの一致／不一致
   - 単勝支持と公開指数・履歴寄与のずれ
   - 馬場・距離・当日傾向と順位の接続不足
3. 差が2つ以上の独立材料で同じ馬を示すときだけ、`補助観点として検討` と書く。
4. 欠損、V系対象外、V90シャドー、または根拠が一つだけの場合は `参考止まり` と書く。
5. 次の一手は一つだけにする。

## 固定テンプレート

出力は [references/template.md](references/template.md) をそのまま使うこと。見出し・順番・注意書きを変えないこと。

## 禁止

- 断層参考だけで本命・順位・買い目を変更すること
- APIにない調教、パドック、気配、血統適性を主根拠にすること
- V89/V90の候補を購入推奨と表現すること
- 三者総合評価の順位票を確率や期待値と呼ぶこと
- 複数の次の一手を出すこと
