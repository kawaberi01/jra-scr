# 実装計画

1. 既存コード・モデル・manifest・除外理由を読み取り確認する。
2. 新方式の範囲と評価分割を固定する。
3. scriptsに特徴生成/学習/評価/予測入口を追加する。既存実装は変更しない。
4. uv run --extra mlで学習し、新規成果物ディレクトリへ保存する。BLASは1スレッドに制限する。
5. 漏洩・O2欠損・対称性・将来時刻拒否・学習目的の意味ある確認を行う。
6. 前後の入力SHA・成果物再読込を確認し、結果と将来shadow運用の再開点を保存する。

numpy/scipy/sklearn/joblibは既存ml extraの依存範囲を使い、恒久的な依存追加をしない。
