# V102～V111：既存データだけで追加した10手法

## 結論と用途

追加10手法の学習・時系列評価を完了した。事前に固定した購入候補の判定基準を満たした手法は0件。成果物は参考予測・比較研究用であり、実購入推奨モデルには昇格していない。

前回のV94は単勝の参考候補として保持する。今回のV110は馬連の条件別検証候補として保持する。V105は2026年を見る前の開発期間から選んだ比較基準であり、購入推奨を意味しない。

## 固定した方法

- 入力は既存の2024～2026年のgzipデータのみ。取得中の2003～2018年、元DB、外部データは使用していない。
- 予測時点はT-30分。T-10分、結果、払戻は予測特徴量に使用しない。結果・払戻は教師ラベルと評価にのみ使用する。
- 夏季6～8月を学習・評価とも除外。残り3,544レース。
- 日付順に学習し、開発評価は2024年4～5月、2025年1～2月・9～12月の1,564レース。2026年1～3月と4～5月の1,140レースは、既に研究に使用した探索的評価。9月の1レースは補足扱い。
- 全10手法とも条件は全体、期待回収倍率1.05以上、1レース最大1点100円。単勝オッズ2～30倍、馬連3～100倍。今回、閾値・対象条件の追加探索は0回。
- 開発段階の決定はfrozen_decision.jsonに保存し、2026年評価後も変更していない。
- 購入候補の基準は開発・評価とも100点以上・20購入日以上・回収率105%以上、上位3払戻を除いて100%超、期間別でも100%超、日単位bootstrapの下限でも100%超など。探索回数補正は近似であり、これまでの全研究を厳密に補正した独立検定ではない。
