# O1/O2市場間支持率モデルの追加検証

## 結論

- 馬連の馬別支持率を加えると、対象レース全体では単勝市場・単勝のみのモデルに対して予測損失が小さくなる。履歴特徴を除いた比較でも改善したため、O2特徴そのものに予測情報がある可能性は高い。
- 固定した単勝購入ルールは、2025年秋の808レースで回収率71.65%、2026年1～6月の1,203レースで73.80%。開催日単位の再抽出による95%区間はそれぞれ49.86～94.16%、55.24～94.28%。利益を示す結果ではない。
- 芝1400m以下では2025年秋107レース・47点で95.53%、2026年1～6月151レース・63点で92.22%。回収率の区間は広く、短距離に限定した優位性は判定できない。
- 判定は「勝率予測の研究を継続、購入用モデルとしては未採用」。今日の単一レースの結果ではモデルを採否しない。

## 検証方法

- `cross.joblib` と `basic.joblib` を固定し、再学習や購入条件の調整をせずに単勝市場と比較。
- 1レースごとの勝ち馬対数損失、Brier値、予測1位の勝率、固定ルールの回収を集計。払戻が複数ある同着レースは全勝ち馬の確率を合算。
- レース単位と開催日単位で3,000回再抽出し、予測損失差と回収率のばらつきを記録。
- 追加の特徴切り分けは、学習期間だけで「単勝情報のみ」と「単勝情報＋馬連支持率」をそれぞれ学習し、同じ評価期間で比較。購入ルールは調整していない。

## 予測精度

| 評価期間 | 市場の平均対数損失 | O1/O2モデル | 改善量・開催日単位95%区間 |
| --- | ---: | ---: | ---: |
| 2025年9～12月 | 2.018925 | 2.001495 | +0.017431［+0.00071, +0.03391］ |
| 2026年1～6月（既使用） | 2.029428 | 2.010629 | +0.018799［+0.00676, +0.03105］ |
| 2026年7～9月（19レース） | 1.893973 | 1.859459 | +0.034514［-0.15332, +0.14080］ |

履歴特徴を除いても、O2追加による平均対数損失の改善は2025年秋に+0.010592、2026年1～6月に+0.011408。2026年7～9月の19レースでは-0.000869で、判断できる件数ではない。

芝短距離だけでは2025年秋のO1/O2モデルが市場より対数損失で0.009294悪い。2026年1～6月は0.032840良いが、期間と対象条件による変動がある。

## 購入成績の補足

- 選択馬の単勝オッズ5～10倍: 2025年秋156点・回収率70.96%、2026年1～6月242点・93.64%。
- 2026年7～9月の追加19レースは9点・回収率65.56%。芝短距離4レースでは2点だけのため、回収率295%に意味のある再現性はない。
- 2025年の採用率は1,092 / 3,456レース（31.60%）。3～8月は採用0で、9月も45 / 240レース。欠落期間があるため通年代表とは言えない。

## 時点と出典の監査

- 採用4,400レースのT−30分単勝・馬連は公表時刻が判断時点以前で、両券種の公表時刻も一致。馬連の組合せ行列は単勝掲載馬に対して全件揃っていた。
- 単勝払戻の対象馬と1着馬は4,400レースすべてで一致。同着は5レースあり、評価時に複数の勝ち馬を扱った。
- 公表値の古さは中央値2分、95パーセンタイル4分、最大8分。
- 4,398 / 4,400レースの過去出馬表と発走時刻は未検証表示。全オッズ原本はレース後に取得している。公表時刻による再構成はできるが、当時の入力を実際に保存していた証拠にはならない。

## 次の検証条件

1. 学習済みモデルと購入条件を固定したまま、発走前にO1/O2、出馬表、取得時刻、予測を保存し、その後の確定結果だけで評価する。
2. 芝短距離、GⅠを含む条件別の件数を増やし、勝率予測精度と購入回収率を分けて追う。
3. 2025年の欠落期間を推測で補完せず、取得可能な原本と事前スナップショットに基づきデータ品質を改善する。

詳細な数値とモデルSHA-256は `validation_report.json` を参照。
