# 020-JRA発走前ライブシャドー記録実装計画書

## 1. 対象と目的

- 対象機能: JRA発走前ライブシャドー記録
- 今回の対象範囲: モデル、SQLite保存、Scout連携、参照API、自動test。
- 今回やらないこと: 購入、採点、scheduler、閾値調整、既存snapshot schema変更。

## 2. 実装フェーズ

### Phase 1: 契約追加

- 観測modelとpage modelを追加する。
- shadow判断正規化helperを追加する。

### Phase 2: 永続化

- additive table/indexを追加する。
- Scout保存transactionへ観測保存を統合する。
- race単位の一覧取得を追加する。

### Phase 3: Scout連携

- 成功した未発走レースから観測modelを組み立てる。
- artifact版情報とオッズ取得時刻を保存する。

### Phase 4: API

- race単位の読み取り専用GET APIを追加する。

### Phase 5: テスト・静的確認

- unit/store/API testを追加する。
- pytestとruffを実行する。
