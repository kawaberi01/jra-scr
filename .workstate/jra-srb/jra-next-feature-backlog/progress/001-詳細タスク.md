# 001-詳細タスク

更新方式: 更新型。各機能の状態、依存、DoDを最新化し、新規候補だけを追記する。

## ステータス定義

| ステータス | 意味 |
| --- | --- |
| `pending` | 着手可能、または仕様化待ち |
| `in_progress` | 仕様化・実装・検証のいずれかを実施中 |
| `blocked` | 外部条件または別タスク待ち |
| `conditional` | 利用条件が成立した場合だけ実施 |
| `completed` | DoDを満たし、必要な検証が完了 |
| `cancelled` | 採用しないと判断済み |
