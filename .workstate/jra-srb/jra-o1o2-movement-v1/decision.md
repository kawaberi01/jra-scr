# O1/O2時系列オッズ初回評価

## データ

- `data/training/jra_o1o2_asof_v1` の採用レースを使用。ファイルのSHA-256と行数は各年のmanifestと一致。
- 2023年は採用0件。学習は2024年と2025年1～2月の2,370レース、開発評価は2025年9～12月の808レース、期間外評価は2026年1～6月の1,203レース。
- 採用レースには単勝・馬連のT-30m/T-10m時点オッズ、着順、対応する確定払戻がある。2025年3～8月は時点オッズの欠損により評価できない。
- 過去の出馬表と発走時刻はほぼ全件で当時の状態を検証できず、オッズは公表時刻による事後再構成である。

## 方法

- 前日までの履歴特徴とT-10m市場価格を使う静的モデル、さらにT-30mからT-10mへのオッズ変化を加える変動モデルを比較。
- 単勝と馬連は別モデル。各レース最大1点、1点100円、期待回収倍率1.05以上という固定の試験条件で集計。
- 予測時点のオッズで選択し、確定払戻で精算。期間外評価の結果を使って条件を再調整しない。

## 結果

| 券種・モデル | 2025年開発ROI / 点数 | 2026年期間外ROI / 点数 | 2026年最大払戻除外ROI |
|---|---:|---:|---:|
| 単勝・静的 | 21.36% / 22点 | 128.22% / 45点 | 100.00% |
| 単勝・変動 | 79.57% / 46点 | 103.38% / 77点 | 86.71% |
| 馬連・静的 | 16.09% / 46点 | 0.00% / 70点 | 0.00% |
| 馬連・変動 | 14.80% / 50点 | 23.10% / 84点 | 10.12% |

## 判定

- 現時点では単勝・馬連とも購入用モデルとして採用しない。単勝の期間外評価で表面ROIが100%を超えても、開発評価で再現せず、払戻少数件への依存が大きい。
- オッズ変動による予測損失の改善は小さく、利益を示す根拠になっていない。
- 2026年1～6月は今回の期間外評価で使用済み。次の仮説を試す場合はこの期間に合わせた条件変更を行わず、将来の未使用期間で確認する。
- 詳細数値は同じフォルダーの `report.json` を参照。
