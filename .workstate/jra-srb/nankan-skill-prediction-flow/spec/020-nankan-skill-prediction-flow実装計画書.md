# 020-nankan-skill-prediction-flow実装計画書

## 実装方針
スキル本文の運用文を強化し、通常予想で取り得る自由度を先に絞る。コード追加より先に、行動規範の曖昧さを消す。

## タスク

### P01 predictor の取得順ルールを修正
- `bundle 優先` を `bundle 1 回固定` へ変更
- 再取得許可条件を列挙

### P02 predictor の追加 API 条件を修正
- bundle 成功後に再取得しない項目を明記
- 個別 odds の取得上限を明記

### P03 predictor の保存・整形ルールを修正
- 標準フローでのファイル保存禁止
- `pattern.runners` 前提と主要指標抽出を明記

### P04 predictor の観測モード規定を追加
- 通常予想と観測実行の差を明記
- 出してよいログの粒度を固定

### P05 starter に固定条件を反映
- predictor 側ルールを短く引き継ぐ
- `404` 以外では再取得しない方針を固定

### P06 文面整合確認
- predictor と starter の矛盾を除く
- 既存テンプレートや既定値との衝突がないか確認する

## 検証観点
- 同じ依頼を 1 回流した時、bundle の再取得指示がスキル文面上で不要になること
- 観測なし通常予想で、保存・エンコード切り分け・形状探索の寄り道が出にくくなること
