# S2B 負例選択偏りの是正比較

作成日: 2026-11-05。利用者が承認した順位学習研究の中で、spec435の不採用を保全し、負例分布の欠陥を是正する一案を追加する。

## 変更理由と範囲

S2初案（以下S2A）は全4fit/独立検算まで完了したが、後年7,857競走で3的中に悪化した。符号・純対比較目的・スコア・精算は一致し、実装の反転ではなかった。市場上位5負例だけでは上位外の組が正例にしか登場しない。市場確率が真の確率そのものでも、上位外の各スコアを上げる勾配が残ることを人工例で確認した。全負例なら真のlog市場で期待勾配が0になる。

S2Aの成果・失敗判定は変更しない。根拠は同runのindependent-verification.jsonとnegative-selection-diagnostic-v2.json。v1の温度0での単一微分だけでは偏りを十分に診断できないため、v2の各スコア勾配を正本とする。

変更は対比較の負例を全ての非正解ペアへ広げることだけ。S0入力14列・教師・尺度・条件群・L2・年境界・最適化・同点順・固定仮想購入は維持し、CEは引き続き使わない。強度/閾値/特徴探索は追加しない。spec435の4fitとは別runでS2Bを4fitし、合計8fitを上限とする。これ以上の修正候補は試さず採否まで閉じる。

## 実装・評価契約

- 新規S2Bモジュール、実行器、独立検算器と負例偏りの再現テストを追加する。既定・スキル・SQL・収集・旧成果は変更しない。
- S2Aの目的関数・推論・評価・bootstrapを再利用し、全非正解組の差分をfloat64で作成する。競走ごとに1/(教師数×当該競走の負例数)で重み付けする。
- メモリ2GiB・BLAS1・逐次4fitを維持。巨大な全組相互比較ではなく、正解対各非正解だけを扱う。
- 推論の14列線形スコア契約はS2共通、訓練protocolはspec436、variantはS2B_all_negatives。ファイル・比較行のS2キーはS2ファミリ共通スキーマとして保持し、run/model/protocolにS2Bを明記する。確率とは表示しない。
- 独立検算はspec435の全件検算を再利用し、教師目的の再計算のみ全負例に対応させる。S0尺度/条件一致、全スコア・精算・CI・採否・原本再生を同じ厳密性で照合する。
- 開発2023と後年2024〜26の採否条件はspec435を変更せず適用。既知過去を再利用した探索的な修正比較であり、未知確認・購入採用と主張しない。結果に合わせた追加の改良・良い群選択はしない。
- 完了条件は追加4fit、全比較、独立検算、S2Aとの原因/結果対照、報告、採否、進捗/知識記録。購入・既定変更は0。
