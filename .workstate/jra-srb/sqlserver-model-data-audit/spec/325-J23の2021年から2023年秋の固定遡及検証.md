# J23の2021〜2023年秋・固定遡及検証

作成日: 2026-10-23 JST。利用者の「過去データで試してみてください」と確認不要の継続指示に基づく。対象は仮採用主候補のJ23。実行結果を見る前に本仕様とprotocolを保存する。

検証対象は2021/2022/2023年の9/10/11月、東京・中山の正常8頭以上。2020年を市場付き学習の準備期間とし、2003年からの正常走で前日までの時計履歴を生成する。価格・払戻は既存jra_o1o2_asof_v2/20261002-raw-v2-completeの2020〜2023年保存JSONから読み、元manifestのSHAを確認する。生涯時計は既存SQL SELECT専用LiveAnnualReaderから固定年版を読み、既存年別監査digestと照合。新規取得/SQLite接続/当日APIなし。

各評価月の開始日前だけの2020年以降全場・全季の適格競走で、既存learner.fitのJ23とR1を月次で再学習する。比較M0は同じ馬連市場。最大9月×2方式=18fit。初期値/学習式/尺度/正則化0.1/最適化条件は既存のまま。2024年以降は入力/教師/モデルへ一切使わない。推論特徴は各競走日前だけの状態から作り、同日結果は日末まとめて更新する。

J23原型は12馬特徴/28ペア特徴、単勝PL乖離を含む既存式。R1は既存基本特徴の対照。購入は既存select_pairの4〜80倍/確率0.015以上/期待倍率1.05以上、最大1点600円。方式混合・条件救済・夏除外・距離境界追加・補正政策はしない。

保存入力とnativeの有効馬集合、単勝全馬/馬連全ペア、発表<=T30 cutoff、対象top2と馬連払戻組を照合。時点市場/結果の欠測・不整合は理由別隔離。取消・同着等を結果に有利なように補完しない。元履歴の歴史公表版/出馬表の真正性は未証明であり、この制約を報告する。

主集計は両場秋の全体/年別/場別。全競走logloss/Brier、市場との差、購入数/購入日/的中/ROI/利益/最大1件・3件除外/日末DDを保存。日block bootstrap20,000回seed325で探索95%区間を計算し、未知な事前登録試験とは呼ばない。既存100購入/30購入日/10的中/ROI105%以上と下限100%超の最低条件を診断表示する。2021〜23の結果を見て方式や範囲は選び直さない。
