# R1当日参考推論

作成日: 2026-10-18。対象: 秋華賞への明示利用と以後のR1研究。

## 実装契約

- 保存済みspec150 R1を再学習せず使用する。既定のV系・CatBoost・S06/S08・スキル・API設定は変更しない。
- 専用CLIから既存APIの発走前カード・馬連オッズを取得し、研究専用SQL readerで2003年以降の保存範囲から、対象日未満の履歴を構築する。R1に不要な騎手・厩舎集計を使わないことを照合し、対象馬の生年前の走査は省略できる。固定研究の5月末制限は当日用readerだけで解除する。
- 馬名完全一致と年齢からの生年整合によりSQL内の馬IDを一意に同定する。曖昧一致・無根拠なID生成をしない。R1が参照する8基本特徴と17ペア特徴を保存モデルの定義と照合する。
- 取消・除外馬を除いた全馬連組合せのオッズが必要。余分な取消馬のオッズは除外する。欠落・重複・不正価格・期限超過・発走後・対象ID不一致では出力を採用しない。
- 当日結果・払戻を取得しない。履歴は対象日未満だけ。取得時刻・SQL履歴上限・馬別最新履歴・公式近走との不足を可視化する。収録不足がある場合は完全な当日履歴と呼ばない。
- 出力は馬連確率・市場対比・時点価格・予測期待倍率。確率上位と固定購入条件合致を分ける。研究政策4〜80倍・確率0.015以上・期待倍率1.05以上・最大1点600円は変更しない。参考政策と実購入を区別し、自動購入しない。
- 馬単位の補助値を出す場合は2着内周辺確率と明記し、勝率・3着内確率や正式着順予想へ読み替えない。
- 正規化・馬番並び替え不変・結果非依存・保存モデルhash・独立softmax再計算・学習時特徴一致を検証する。 meaningfulな単体検証と実SQL/実APIの当日推論を実施する。
- 保存先は既存artifacts/jra_research/runsと共通SQL予想Store。学習原文・全年特徴を複製しない。新規SQL表・schema/index・原データ更新・削除なし。予想は参考専用と識別して保存・読み戻しする。
- R1自体の改良研究は終了しない。まず現行版の事前出力を固定し、改良は別run・事前計画で比較する。今回の当日利用が利益優位やG1適性を証明したとは扱わない。

## 完了条件

秋華賞の現時点の実データで推論を実行し、入力品質・検証結果・候補と見送りを保存する。収録不足等で推論を成立させられない場合は、その証拠と不足だけを保存し、成立済みと報告しない。後日の再実行方法と次の研究課題をprogressへ残す。
