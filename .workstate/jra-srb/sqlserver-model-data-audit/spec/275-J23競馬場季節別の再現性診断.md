# J23競馬場・季節別の再現性診断

作成日: 2026-10-23 JST。利用者は競馬場/季節の違いを既存データで確認してから新情報追加を判断する手順を了承し、「では始めてください」と指示した。対象は保存済み予測の診断・研究記録のみ。再学習・SQL/API・本番変更・購入組変更はしない。

## 事前固定

- 元runのJ23/R1/M0/J01各30月、7,127競走。元セルSHA・行損失/会計・元phase集計を照合する。既使用期間であり未知テストではない。
- 競馬場10区分、四季4区分、競馬場×四季40区分の計54区分をすべて表示。結果による区分追加・季節境界変更なし。
- 春3〜5月、夏6〜8月、秋9〜11月、冬12〜2月。月区分であり、JRAの開催名称や対象競馬場リストとは区別する。
- 暦年2024/2025/2026と元選抜2024-04〜2026-03/既使用確認2026-04〜09を別々に集計する。冬の年別表は暦年内1/2/12月の合計で、連続した冬とは称さない。
- 対象月は2024-04〜12、2025通年、2026-01〜09。季節構成の偏りを示すため、3年共通の4〜9月だけの年別表も併記する。データが0件の区分は欠損/開催なし等を切り分けられないため評価不能とし、損失/ROIはnull。
- 各区分の全競走logloss/Brierと対市場/R1/J01差、J23購入件数/日数/的中/期待的中/賭金/払戻/ROI/最大1件・3件払戻除外/最大DDを集計する。対照との確率精度比較は同一競走を使う。別母集団の平均loglossの単純順位を得意不得意の証拠にしない。
- ROIと対照比損失差の開催日bootstrap2,000回、seed275。区分ごとの95%区間は多重比較未補正の探索用で、採用判断にはしない。区間の分母0抽出は除外し、有効抽出数を表示する。

## 年をまたぐ確認

区分の全3暦年について、購入30件/10日/3的中以上かつROI>100%を満たす場合だけ「記述上の3年黒字候補」として列挙する。採用基準ではなく、条件で選んだ探索結果として扱う。共通4〜9月でも同条件を検査する。欠けた年を飛ばして3年再現としない。

別途、2024年だけで各54区分に100購入/20日/10的中以上、ROI105%以上、上位3払戻を除いてROI100%超を要求する保守的な絞り込みscreeningを固定。区分familyごとに通った区分の和集合を1政策とし、同じ2024選択を凍結して2025/2026へ適用する。選択なしなら政策を作らず、条件を緩めない。これは過去研究で見た基準を再利用する探索的な事後研究であり、独立した事前登録・実用採用ではない。2024年だけの選択でも、本研究の計画自体は全期間既使用である。

上記screening通過は購入採用ではない。独立新期間/収益の不確実性等の既存採用ゲートは維持し、本件は採用0。良い場所を事後的に組み合わせた追加政策・学習は作らない。
