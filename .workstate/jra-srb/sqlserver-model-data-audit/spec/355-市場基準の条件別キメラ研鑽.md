# 市場基準の条件別キメラ研鑽

作成日: 2026-10-24。利用者は「見込みがあるモデルが出るまで継続し、必要なら思考を柔軟に転換する」と指示。spec350の追加探索禁止は旧C2比較の契約として保持し、今回は別仮説/別runとして進める。旧結果/モデル/予想は変更しない。

## 新仮説と再利用

市場を排除して全体能力を再構成するより、同時点の単勝/馬連市場を基準に、条件別の能力・適性・ローテーションで過小/過大評価を補正する方が安定するか。旧J23と異なる点は15馬特徴の距離変更/芝ダート変更/180日出走、競馬場×芝ダート×距離/季節の共有係数を使うこと。純粋な市場校正対照を置き、部品の上乗せを測る。

既存dataset17,309競走と固定市場6年を再利用。SQL23年/旧8fitを再実行しない。過去は既使用、探索であって独立未知試験ではない。外部取得、DB/schema/既定/API/旧モデル変更、購入なし。

## 第1段階の固定候補

- T0: log馬連市場offsetに温度補正1係数。能力特徴なし。
- P0: T0に単勝PLと馬連のlog乖離を加える。能力特徴なし。
- H0: P0に旧C2の15馬特徴のペア平均/絶対差30列を追加、共通係数。
- H1: H0に競馬場×芝ダート×距離と季節の階層係数差分を追加。訓練100競走未満は共通/親へ戻る。
- H2: H1に市場乖離×平均時計/平均履歴量の2相互作用。旧J23との観点差は条件付き補正と追加3馬特徴。本人の予想式を再現するものではない。

尺度は訓練のみ。市場期待値中心化。共通L2=0.1、条件差分L2=1。温度/乖離も正則化。レース等重みsoftmax損失。最大250反復、数値スレッド1、メモリ2GiB。5候補を2020〜2022学習/2023開発で比較し、対数損失最小（1e-8同値は単純優先）を固定選抜する。年次教師を更新し、固定候補と対照T0/P0を2024/2025へ順次検証。結果で候補を選び直さない。

## 見込みの判断

大きな利益や京都長距離専用の証明は要求しない。一方、単に選抜年だけ良いものを有望と呼ばない。2024/2025の両年で市場比対数損失改善、合算で損失改善95%日単位対応区間下限>0、両年で純市場校正T0以下の損失、合算的中率が市場より0.5ポイント超悪化しない、モデル/選抜/来歴/結果遮断の検算passedを「前向き参考に進める見込み」とする。2025年京都長距離3競走の制約は維持し、見込みを京都専用の実用採用に読み替えない。購入ROIと正式採用は別。

第1段階で未達なら差分を診断し、その理由を記録して次の変更仮説/期間/評価基準を結果前に固定する。後続候補を無制限に同時追加しない。最終候補を2025末まで学習・保存し、発走前入力への推論を確認する。既存菊花賞予想は上書きしない。
