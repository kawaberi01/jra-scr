# S0 市場・当日属性モデルの固定検証

作成日: 2026-10-25。利用者の「作業を続けてください」により、直前提示の利用可能入力による新モデル作成・比較を実施する。

## 目的と変更契約

- 過去の不足履歴は取得できない。既存保存データを使い、今後も保存される市場・当日属性で推論できる研究用S0を作る。
- 新規モジュール、実行スクリプト、専用テスト、成果物・報告だけを追加する。D0、既定モデル、予想スキル、収集処理、SQLは変更しない。
- 入力は競走ID/日付/場/芝ダート/距離、出走馬番号、同時点の正規化馬連市場・単勝由来PL、当日6属性。履歴15列・ネイティブ馬ID・結果・払戻は推論に渡さない。
- 特徴14列: log市場、clip(log(PL/市場),-10,10)、6属性のペア平均/絶対差。市場期待値で中心化。D0の履歴をゼロ埋めする方式ではない。
- 既存のC2条件（場×芝ダート×距離帯、季節等）、100教師以上の条件差分、学習内尺度、L2共通0.1/差分1、L-BFGS-Bを再利用する。独立場別モデルの再探索はしない。

## 学習と固定評価

- 元D0のSHA検証済みdatasetと保存予測を再利用。追加の過去取得、SQL/HTTP、D0再学習なし。
- S0一構成だけ、2023/24/25/26の各年より前を教師に4回学習。2026モデルは2025末まで。最大4fit、並列学習なし、BLAS1、既存2GiB上限。
- 2023を開発比較、2024/25/26合算7,857競走を後年確認とする。既に参照された過去であり完全未知試験とは呼ばない。後年結果による特徴追加・閾値調整をしない。
- D0、市場と同一レースの対数損失・Brier・的中率・馬連最大確率1点100円固定回収率を比較。精算は検算済みofficial-outcomes.jsonのID/正解/払戻を照合して使う。日単位bootstrapの損失差CIも表示する。
- 研究上の改善判定は2023でD0以上の的中率かつ損失改善、後年損失差CI下限>0、後年的中率D0以上、各年市場より損失良好の全条件。未達なら候補を不採用として保存する。購入採用・既定切替はこの作業では行わない。

## 実入力・独立検算

- 保存済みforward_capture_20261025_v4の300時点を原本カード・市場から変換して最終S0で推論し、原本hashと予測を保存する。結果は結合せず、収集互換性だけを検証する。
- 訓練/推論の入力境界、歴史列/正解の遮断、全ペア/確率/日付、保存再読を確認。別式で全評価/保存原本の特徴・確率を検算する。
- 失敗は新規run内に記録し、既存成果物を上書きしない。完了したfitを不要に繰り返さない。
- 依存は既存NumPy/SciPy/joblib/threadpoolctl。新規依存追加なし。
