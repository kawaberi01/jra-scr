# 2003年以降の取得済みSQLを用いる理論20回研究

作成日: 2026-10-17。利用者の「20回ぐらい理論の壁打ちと検証」に基づく。

## 目的・影響・実装方法

予想家の内容評価・条件好転・役割/組合せという発想を20件の検証可能な仮説へ落とす。人物の予測式の完全再現とは呼ばない。前回のnetkeiba SQL34だけで理論を判断せず、2003〜2026年の年別JRA-VAN原文（SQL snapshot4〜27）のRA/SEから履歴を作る。SQLの元データ全体を作り直さない。

新しい研究module/CLI、20件台帳、結果と進捗を追加する。既存の研究reader、時点市場/精算の検査部品、SDKのRA/SE固定byte定義を再利用する。SQL schema/索引/設定/運用/旧モデル/SQLiteを変更しない。取得・再移行・削除なし。

## 入力確認と期間

- 年別raw.year_raw_recordsのpayload（RA1272/SE555 bytes）をsnapshot+一意rowid索引で各年一巡。2003/2013/2024/2026の実SQL少数本文でSHAと通過順位/上がり/ラップの存在を確認済み。公式SDK JVData_Struct.csの1始まりbyte位置を使用（SE通過352/354/356/358、上がり391、RAラップ891から25×3bytes）。
- 各本文の長さ/header/レースキー/SHA、同一馬同一レースの重複/訂正版、正常順位/頭数を検査。年別の原文件数・利用レース/馬・観測率を記録。判断不能な異なる同順位版は恣意選択せず除外理由を保存する。
- 年ごとにrawをメモリで整列し、特徴生成後に破棄。馬IDで履歴を管理し、同日結果は翌日まで特徴へ加えない。馬名同定に戻さない。現在レースの結果/上がり/通過/ラップ/確定オッズを特徴へ入れない。現在の年齢/斤量等はSE事後属性なのでT30時点可用性は未証明。
- 学習は2003-01-01〜2025-09-30の正常な平地・8頭以上、全季節。古いオッズは要求せず、過去結果/内容から馬の勝敗を学習する。古い年の馬券ROIを実証したとは呼ばない。
- 校正2025年10月、方式選択2025年11〜12月、再使用評価2026年1〜2月/3〜5月。現在の比較対象はspec120の評価1594Rを固定し、年別原文との不一致があれば共通集合と除外を全案同じにする。評価期間は研究に使用済みで、独立未使用検証ではない。
- T30市場/馬連払戻はSQL31。必要日だけ既存readerで読む。結果/市場のロスター・馬ID・着順・払戻を原文と照合する。校正の適格母集団は正常原文と既存市場/精算の共通集合として件数を報告。

## 統一の学習と評価

低メモリで全歴史を使用するため、既存scikit-learnのSGDClassifier(log_loss、L2 alpha=0.0001、average=True、seed42、shuffle=False、constant eta0=.02)を固定し、1万馬行以下のbatchで1巡学習。各レースの正例合計/負例合計を同重みとする。連続値は事前に定めた単位で有界化し、欠測値と欠測フラグを区別。epoch/alpha/特徴閾値の探索はしない。大きな特徴行列を保存しない。

馬の学習値をsigmoid→レース内正規化し、PL式で上位2頭のペア確率へ変換する。校正期間だけでT30馬連市場との対数確率混合係数[0,1]を適合。全案同じ規則（S08と同じ価格4〜80、確率1.5%以上、期待払戻順、最大1点600円）で購入成績を比較。未参照T30ワイド価格や最終オッズを捏造しない。

各回の事前仮説、反論、変更点、年別学習量、校正係数、対数損失/Brier、購入回数/的中率/ROI/最大損失/払戻集中、月別/期間別、結論を保存。全20案を表示し、成績のよい案だけ選んで報告しない。開催日bootstrapは差の探索的参考で、多数試行を補正した独立検定ではない。

## 上限と停止・完了

SQLは研究readerのみ、SELECT・30秒timeout・fetch5000以下、年50万行/全体400万行/メモリ2GiB。旧SQLite/JSONL/BAKを入力拒否hookで禁止。元payloadは保存せず、年別の利用列/本文SHAを集約したdigestだけ保存。現在/将来結果を変えても特徴が不変であること、保存後推論、会計、20件の実行有無を検査する（利用者の検証依頼に含む）。

SQL障害・壊れた本文・馬ID不整合・時間順の逆行・上限超過は失敗runを保存して依存処理を止める。原因特定なしの反復実行をしない。全量移行検証・索引追加・自動再取得へ拡大しない。

完了は20件の仮説に実測結果と判断が付くこと。利益100%超を終了条件にせず、不採用も研究結果として残す。必要データが成立しなければ未実施を完了と数えない。上限通知時はrun/PID/進捗/次の1手を保存し停止。５時間枠の正確な残率はツール取得不可。

## 初回の数値境界に対する是正

初回run20261017T100721Z_2e6121154a2f420ab3e86a2270d752a4では全19モデルの校正係数がbounded最適化の下端近傍となった。完全市場なら全ペアの確率×価格が同値になるため、微小重み/丸め誤差による買い目差を理論の差と評価できない。

既定の[0,1]校正範囲の端点0/1と内部解を明示比較する。0選択時は市場確率を演算し直さず返す。期待倍率の同点は小数12桁で判定して元のペア順で決める（EV閾値探索ではなく数値的同点の安定化）。初回のモデル学習は変更せず、保存済みモデルをSHA照合して再利用。履歴の再構築に必要な年別読取は行うが新規fitは0と記録し、入力digest一致を要求する。初回は数値境界の診断用として保持し、理論間ROIの比較結果として採用しない。期間/特徴/学習条件を変えた再試行ではない。
