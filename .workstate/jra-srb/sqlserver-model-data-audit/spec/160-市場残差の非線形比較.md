# 市場残差の非線形比較

作成日：2026-10-17。spec150で収益の成功基準が未達だった場合の次段階。

## 固定契約

- spec150で予測損失の改善と購入収益の改善を確認した後、未達ならV105の既存fit_boostを再利用して非線形な市場残差を比較する。
- 新しいV105そのものの再現とは呼ばず、同じ学習アルゴリズムを馬連・JV長期履歴へ適用した派生研究とする。
- SQL入力、年別状態更新、期間、評価集合、購入政策、成功基準はspec150を維持。年間・市場digestがspec150と一致しなければ停止。
- 比較はM0市場、R1基本履歴線形補正、R2内容付き線形補正（spec150保存モデルを再利用）、B1基本履歴の木補正、B2内容付き木補正の5案。
- B1/B2は既存scripts/jra_second_ten_model.pyのfit_boostを変更せず使用。100木、最大6葉、最少葉150、学習率0.05、hessian下限加算0.02、Newton教師値[-2,2]クリップ、seed102+step。閾値探索・木数探索なし。
- 学習は2024〜2025年9月の市場と同定済み競走。履歴自体は2003年から。2025年10月診断、11〜12月の対数損失で5案から方式選択を固定し、2026年を再使用評価。
- 既存の線形モデルは再学習しない。新規2モデルのみ。旧モデルを上書きしない。
- 予測・会計・hash・保存後推論・結果非依存の整合を検証。解釈は探索的、実運用採用とは別。
- 新依存なし。SQL SELECT以外の原データ操作なし。SQLite・旧JSONL・新規取得・移行・削除・API変更なし。
- 全特徴ファイル保存を避けるため必要行をSQLから再構築するが、再移行やデータ全量再照合はしない。同じ2GiBメモリ上限を使用。
- 機械的な成功基準未達でも評価期間に合わせて購入条件を変更しない。未達理由を確率・価格・時期・払戻集中度から診断する。

実行前追記：spec150の開発選択がR1だったため、この選択基準を比較から落とさず追加する。2026回収率による方式変更ではなく、開発選択済みの基準を保持する。新fitは引き続きB1/B2の2件のみ。
