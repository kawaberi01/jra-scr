# 市場残差と内容特徴の直接学習

作成日：2026-10-17。利用者の「結果が出るまで続ける」に基づく次の固定比較。

## 実装契約

- 対象：spec140で改善した履歴特徴の市場への追加価値を、馬連の条件付きsoftmaxで直接学習する。
- 実装：新規研究モジュール・CLI。既存V91の市場offset＋正則化条件付き尤度の式を再利用する。V91Bの単勝モデルそのものやV105の検証と混同しない。
- 原データ：統合SQLだけ。年別RA/SEの2003〜2026年で既存Statesを更新し、2024年以降の必要日だけ特徴化。元データ/全特徴のファイル保存なし。
- SQL市場：既存snapshot31、既存readerのSELECT権限/索引/行上限/タイムアウト。先に既存の日付一覧だけ確認し、空の日の反復照会を避ける。夏除外は以前の固定契約を維持。
- 分割：学習2024〜2025年9月（市場と揃う期間）、2025年10月診断、11〜12月開発で選択、2026年1〜5月を既参照評価。評価集合はspec140と同じ正常JV共通1,567競走を要求。
- 長期データ：履歴は2003年から構築。過去2003〜2023年の市場を今回新たに読み直さない。市場補正係数の学習期間は市場の揃う2024年以降と明記。
- 比較：M0市場、M1市場温度、R1基本履歴、R2直近/進出/条件復帰等の有望内容、R3固定の非線形交互作用。正則化L2=0.1、学習のみで標準化、最大400反復。方式や閾値を2026年に合わせて探索しない。
- 対称な馬連特徴：馬別特徴の和・絶対差。R3だけ内容特徴×中心化市場支持と距離変更×能力低下等の固定交互作用を追加。馬番そのものは特徴にしない。
- 購入政策：価格4〜80倍、確率0.015以上、予測期待倍率1.05以上、最大1点600円。同点EVは12桁で安定化。spec140の無条件購入とは政策が異なるため同一ROIとして比較しない。
- 選択：開発の平均対数損失で選択、同点ID順。選択を保存してから2026年を集計。
- 検証：保存後推論一致、学習のみのスケール、現在結果の特徴非依存、全入力digest、予測/会計整合、日単位対応bootstrap、期間別ROI/最大払戻除外。
- 成功判断：探索的予測改善は市場との差のbootstrap95%上限<0を参考とする。購入候補の成功は全2026 ROI>100%に加え早期/後期とも>100%、購入日30以上、日単位ROI95%下限>100%を全て要求。これを満たしても既参照データのため実運用採用とは別。選択案だけを主判定、他案は診断。
- 影響範囲：新規研究成果物のみ。取得・移行・SQLite・原文複製・削除・運用差替え・SQL schema変更なし。
- 停止条件：入力契約、共通集合、最適化、会計に不整合があれば失敗証跡を保存し、依存する評価を止める。単なる低成績は失敗エラーではなく研究結果として記録する。
- 追加pytestなし。今回依頼範囲の研究実行/成果物整合検証を行う。

## 次の判断

内容残差が改善すれば採用した特徴を固定して、選定ML候補との比較に進む。改善がなければ回収率だけ良い案を選び直さず、入力の識別力・収益化の障害を診断する。成功結果を保証したり、同じ評価集合で無期限に条件を探したりしない。
