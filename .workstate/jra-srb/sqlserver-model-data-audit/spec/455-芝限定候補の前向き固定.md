# 芝限定候補の前向き固定

2026-11-07。spec454の27セル比較と独立検算が完了した後の判断。spec454の凍結原本は変更しない。

## 採否と成果

S0の芝限定を優先前向き候補として追加固定する。前年までの成績で芝のみが2024/25/26の全回に選ばれ、284購入60的中、回収114.7183%、各年101.2037/134.4762/106.0563%、最大配当除外+2,890円。ただし95%下限86.0553%・家族下限74.7194%、件数不足で購入採用不可。M10合議上位3位も各年黒字だが最大配当除外赤字で優先しない。今回の既知過去からの候補指定を未知試験や元仕様の合格と呼ばない。十分な証拠に至らないときに、弱い候補を有能なモデルと断言しない。

## 対象・再利用・影響範囲

芝限定は固定S0/P01予想の派生評価として、2026-11-08以降の事前保存にだけ適用する。S0予想・馬連確率・E>=1・1点100円は不変。基礎予想/SQL仮想planは改変せず、予め保存した本仕様・候補JSON・凍結日時と当該事前snapshotの芝ダートを照合して別集計する。本日分を芝限定の前向き実績へ遡及追加しない。芝0/ダート1は既存from_capture実装に従う。

spec454の14日上限のHidden監督処理を実装し、既存spec453一日watcherをそのまま子プロセスで使う。日ごとの新runに保存し、同じ日を二重起動しない。モデル/研究実装SHA変更・子の失敗・未精算で停止し、API不通はその日の欠測として保持。無開催日/原本なしは購入0と「入力なし」を区別する。既定/実購入/DBスキーマ/収集/恒久タスク不変。PC終了時は止まり、勝手に復旧しない。

## 確認方法

起動窓、14日制限、候補の凍結前/開始日前への適用拒否、芝ダート、実予算0をテストする。開始前のcheck-onlyで全SHAと候補・日程を読戻し、Hidden起動後に監督PID・waiting状態・heartbeat・stderrを確認する。次日以降の成功や購入利益はまだ主張しない。
