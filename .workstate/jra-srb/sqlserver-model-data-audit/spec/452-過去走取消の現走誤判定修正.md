# 過去走の取消を現走の取消と誤認する入力不具合

2026-11-07。継続研究450の結果照合で33競走73観測に、事前取消扱いの馬が公式結果で完走している矛盾を発見。全行テキストを検索するextractors._runner_statusが過去走セルtd.pastも現在の取消判定へ含めている。保存カードの過去走に順位なしがあり、再現テストで因果を確認してから修正する。33競走全てが同じ原因と断定するものではない。

利用者は必要な実装/検証を毎回の確認なしに進めることを承認済み。変更は同関数と専用テストのみ。既存の現在行の取消/除外検出を再利用し、直接のtd/thセルのうちclass=pastのセルだけ現在判定から外す。表を破壊/書換えず、過去走抽出は維持。過去のraw入力/予測/順位/精算は上書きしない。結果による取消馬の復活や遡及的な買い目変更は禁止。

過去走のみ取消/除外なら現走active、現在の取消があればwithdrawn、現在取消と過去取消の併存もwithdrawn、過去走構造不変をテスト。既存extractorテスト・実フィクスチャも実施。修正前の再現→修正後の成功を記録する。常駐API/収集を無断で停止・再起動せず、新プロセスでの修正適用と、稼働済みプロセスが旧コードを保持する可能性を区別する。

研究450の固定買い目は、勝ち馬が入力名簿から欠けても全買い目を不的中として精算し、都合よく除外しない。追加期間は入力品質問題を別フラグで報告し、利益が出たとしても入力不整合があるまま購入採用しない。
