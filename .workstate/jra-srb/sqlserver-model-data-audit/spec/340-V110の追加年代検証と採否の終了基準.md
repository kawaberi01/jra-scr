# V110の追加年代検証と採否の終了基準

作成日: 2026-10-24 JST。利用者は「どこまで判断できるまで、一気に進めてほしい」と明示。2024/2025の新結果を計算する前に本仕様を固定する。

## 判断の目的と区切り

現在のV110と購入条件を、この案件の実用候補として続けるかを判断して終了する。「あらゆる将来・あらゆる改造でも使えない」という証明は目的にしない。元購入方式と、的中率優先の確率1位という別用途を分ける。合格しない用途は現在の方式を不採用とし、追加期間・新閾値の探索を無期限に続けない。

元購入方式は既に2021〜2023年ROI78.49%で安定黒字を支持しない。2024/2025を同じ入力版で補い、2021〜2025を合算して既存最低ゲート（100購入・30日・10的中・ROI105%以上・開催日bootstrap95%下限100%超）を確認する。ただし2021〜2023の不合格を最新年だけで取り消さず、年代別の不安定性も採用上の反証として扱う。下記の的中率用途が通っても購入方式の合格を意味しない。

的中率用途は、V110の確率1位を既存の馬連市場M0の確率1位と同じ2024/2025競走で比較する。市場と比べる価値の最低差を結果前に2ポイントと置く（利用者指定の目標的中率ではなく、複雑なモデルを採用する研究上の最低改善幅）。合計600競走・60開催日以上、両年の的中率差が正、2年合計差2ポイント以上、開催日対応bootstrap95%差区間下限0超、両年loglossがM0より改善をすべて満たす場合だけ、実用化の追加候補に残す。未達は「今回固定した的中率用途では不採用」で終了する。絶対的な高的中率を保証しない。

統計的差が不明確なら科学的には不確実性を残しつつ、実務判断は追加の複雑さを採用する根拠不足として不採用とする。データ数が不足する場合だけ性能判定不能と明記する。条件を緩めない。

## 固定実行

- spec330のv2/20261002-raw-v2-completeを2020〜2025へ拡張する。2020開始、各評価月開始前の全場・6〜8月以外を拡大学習。評価は2024/2025の東京・非夏。18予定月のうち東京なしの月だけskip、通常12fit。
- V110 top3学習/馬連変換/元購入1.05・3〜100倍・最大1点/600円精算を再利用。元43履歴列と42モデル列、尺度/正則化を変更しない。古い18fitは再実行しない。
- 保存した2021〜2023年と新2024/2025年を入力意味の同じ方式として集計。旧v1報告は混ぜない。学習ID/時点、分離式の元suite一致、結果/T10遮断、入力SHA/元モデルコードSHAを検査する。
- 比較は元購入、V110確率1位、M0確率1位、PL確率1位。PLは参考対照で自動採用しない。確率1位の払戻も参考保存するが利益最適化しない。
- 主評価は2024/2025合計と各年、2021〜2025合計は補助。秋は過去規定の参考だけ。新しい場/距離/確率閾値/モデル混合の探索は0。
- 開催日単位bootstrap20,000回seed340。確率評価、的中率、差、校正の区間は探索的で、後年選択されたモデルの完全未知試験とは呼ばない。

## 対象ファイルと影響

既存案件diagnosticsのbacktest_v110_early_tokyo_20261023.pyを評価年/入力末年が指定可能なよう最小拡張し、既定2021〜2023の挙動を維持する。既存verifierも評価年指定だけ拡張。新規wrapperから2024/2025を指定する。新成果物v110_late_tokyo_20261024と統合評価v110_final_assessment_20261024、進捗077を作成する。製品コード/本番採用/購入/DB/外部取得/依存追加なし。利用者の一括継続指示内で実施し承認を重ねない。

## 確認と終了

新fit全モデル・全予測・元購入精算・代表別式を既存独立verifierで照合。統合判定の件数/差/ゲートは別集計で照合する。実ファイルのSHA・AST・日本語ドキュメントを確認する。失敗時は依存する判定を止めて記録する。成功後に採否と残る不確実性を明示し、次の追加実験を必須扱いせず今回のV110判定を閉じる。
