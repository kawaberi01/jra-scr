# 購入ペアの確率診断

作成日: 2026-10-17。内容特徴比較後、計画②の最初の診断として行う。

目的は、全ペアの損失改善が購入成績へ結び付かない状況を、実際に選択したペアに限定して調べること。新しい購入規則や校正器を評価結果から学習しない。

- 入力はspec120成功runの保存済み選択ペア予測7970行。raw SQL・旧SQLite/旧JSONL・原データは読まない。再学習・SQL再読取なし。
- 5案それぞれ全体と3期間について、購入数・的中数・予測的中数（確率の合計）・実的中率・平均予測確率・選択ペアBrier・回収率を報告。
- 確率帯を結果を見る前に固定：[0,.015,.025,.05,.1,.2,.5,1]。空の帯も明記し、成績のよい帯だけで購入条件を作らない。
- 開催日単位1000回bootstrapで平均の予測確率−実績の差を集計。探索的診断で、多重比較補正済み検定ではない。
- 保存予測にT30価格を含めなかったため、ここでは価格変化や期待払戻の差を推定しない。利益低下の原因を確率のズレだけに断定しない。
- 出力は小さな集計JSONと結果資料。元run・モデル・運用・SQL・旧データは変更しない。5案以外の購入候補や閾値を追加しない。
