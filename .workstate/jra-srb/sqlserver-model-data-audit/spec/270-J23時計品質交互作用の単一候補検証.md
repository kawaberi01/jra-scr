# J23時計品質交互作用の単一候補検証

作成日: 2026-10-23 JST。利用者「案を検証してください」に基づく研究。progress060の提案を1案C02として検証する。対象は案件内診断コード・成果物・記録。SQL読取のみ、本番・既定・元モデル・購入政策は変更しない。

## 固定する候補

J23の基礎経験量特徴を残し、追加のPL乖離×経験量項だけを品質項へ補間する。新しい28係数の全面再学習ではなく、凍結済み月別J23に対する1自由度の時系列screeningとする。

馬の時計品質qは、直近正常走最大3件について `n/(n+2)*exp(-経過日数/365)/sqrt(1+var(時計指標,ddof=0))`。履歴0件は0、1件の分散は0。分散は条件差・成長も含む代理値であり、真の予測不確実性と断定しない。365日・分散への1は既存品質式と標準化時計の単位に基づき固定。結果を見て変更しない。

ペア品質は2頭の平均。品質と経験量の振幅差による単純縮小を避け、各月より前のOOS競走で、競走内ペア平均を競走間等重み平均した経験量/品質の比kを使う。当月や将来の分布は尺度に含めない。

`logit_new=logit_J23 + alpha * (b27 * center(gap*k*pair_quality) - original_experience_term)`。
gapは既存のclip(log(PL/市場),-10,10)、b27は凍結モデルの経験交互作用係数/尺度。centerは当該競走の市場期待値を差し引く操作。alphaは[0,1]、0で原型維持、1で当該追加項を全面置換。他の項は保持。

alphaは前月までの再構築OOS全競走のlogloss最小化、固定罰則`.001*alpha**2/2`。当月に適用するkを過去教師にも適用し、その月のalphaを推定する。尺度と係数の学習は対象月より前だけ。2024-04〜06をwarmup、2024-07〜2026-03の21月を選抜とする。これは全期間既使用の探索で独立テストではない。

## 検証と停止

1. 事前protocolを保存。選抜前にwarmupを含む24月5,657競走の前日履歴・全ペア市場を再構築し、J23/J01/R1/M0の保存正解確率・logloss・Brierと一致を確認する。市場は既存100競走索引バッチを再利用し、原文・全特徴の永続複製はしない。
2. 時間1,800秒、2GiB、RA/SE年50万/全200万行、照会30秒。元の年別digest/セル/モデルSHAを照合。不一致・失敗は依存計算を止める。
3. 1候補、調整0。前回C01と同じ選抜条件: 1,000競走/30日以上、J23比logloss改善0.1%以上、日単位対応bootstrap2,000回95%区間上端<0、市場以下のlogloss。全ペアBrierも測定し、悪化時は通過扱いにしない。
4. 不合格なら確認6月の再構築・新fit・予測は0で停止。通過した場合だけ同じ定義で既使用確認へ進む。通過しても実用採用とはしない。回収率・購入政策は今回評価しない。
5. 数値微分、凸目的の端点比較、確率和1、alpha0原型一致、品質の時点・範囲・分散依存、過去月だけの尺度、保存結果からの日集計再計算を検証する。
