# S1 直近走特徴の固定研究

作成日: 2026-10-27。利用者は直前のS0＋直近走の提案を承認し、研究を採否まで進めるよう依頼した。

## 実装契約

- 対象は新規S1モジュール、既存ファイルからの特徴作成・学習スクリプト、独立検算、専用テスト、成果物・記録。既定モデル・スキル・収集・SQLは変更しない。
- 過去の不足履歴は取得できない。SHA検証済みの既存2020〜26年races.jsonl.gzに保存されたID・条件・結果を日付順で処理する。追加取得・SQL/HTTP・D0/S0再学習はしない。
- 元D0 datasetと既存S0/D0の年別保存確率・公式精算を再利用する。既参照過去の探索であり未知試験ではない。

## 特徴定義と履歴の制約

S0の14ペア列に、直近走5馬特徴の平均/絶対差10列を追加するS1一構成（24列）。追加特徴は、直近走の頭数相対着順=(頭数−着順)/(頭数−1)、距離変更clip((今回m−前走m)/400,−3,3)、芝ダート一致、間隔日数/180、欠測フラグ。探索で項目・窓を変更しない。

対象は前日以前180日以内の直近出走。着順・頭数・平地芝/ダート・距離が全て解釈できる時だけ4値＋欠測0。それ以外は4値0＋欠測1とする。0を観測済みと偽らない。異常/障害/地方など解釈不能な直近走を飛ばして古い好走に差し替えない。

学習側は保存済み馬IDで直近イベントを追い、全同日対象特徴の確定後に当日の結果を反映する。選択したイベントの日付は保存済み当日カードのhorse_has_historyおよびdays_since_last_scaled×365と照合し、前走間隔の不一致は欠測扱いとする。これは欠落ファイルから古い走を前走と誤認することを減らす保守的な照合であり、元カードの歴史公表時点は未証明。2020年より前の欠落は取得せず、欠測にする。既存集計間隔は元履歴実装の365日上限/丸めを踏まえ、180日以内の一致だけを採用する。

実入力側は保存カードofficial_recent_racesの最新日付スロットを選び、同じ5値を作る。公開スロットは最大4枠という観測限界があり、全履歴があるとは扱わない。未来/同日走は拒否。空スロットは欠測。馬IDは当日入力には要求しない。学習側の保存網と公式直近枠の収録範囲差・欠測率を報告する。

## 学習・比較・採否

- S0の条件群（場×芝ダート×距離帯・季節等）、100教師、学習内尺度、L2共通0.1/差分1、L-BFGS-Bを再利用。4年境界2023/24/25/26の4fitをBLAS1で逐次、2GiB上限で実行する。
- 2023を開発比較とし、S1がS0より損失良好かつ的中率同等以上なら追加特徴の開発採用。後年2024〜26の同じ7,857競走でS0/D0/市場と対数損失・Brier・的中率・馬連1位1点100円の回収率を比較する。
- 特徴追加の有望判定は、開発採用、後年S0比損失改善の開催日bootstrap95%下限>0、後年的中率S0以上、各年市場より損失良好の全条件。D0置換候補にはさらにD0比損失改善CI下限>0および的中率D0以上を必要とする。未達なら不採用として閉じ、後年結果を見た特徴・閾値探索をしない。
- 競馬場/芝ダート/距離帯/季節別は全群を説明用に集計する。良い群だけを選ばない。購入採用は別問題であり、今回は既定変更・実購入なし。
- 保存済み105レース300時点からS1を生成し、入力充足と欠測を確認する。後日作成モデルの再生であり発走前新予想・未知性能とは呼ばない。

## 完了条件と停止

由来ファイルSHA、前日境界・履歴遮断・属性結合・欠測・勾配のテスト、全特徴/確率/精算の独立検算、再読込、比較報告・採否・進捗保存まで実施する。新規依存なし。失敗は新規runに保存し、成功fitを不要に繰り返さず、不整合の処理に依存する学習・配置は止める。
