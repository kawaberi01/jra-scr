# D0の競走条件別診断

作成日2026-10-24。spec370の追加3案は開発でD0未満、D0保持を確定した後の説明用診断。モデル選択・購入条件・係数・閾値を変更しない。

目的: 利用者の競馬場・距離等の細分化という研究意図に沿い、保存済み2024/2025/2026のD0対市場を同一競走で対応集計する。競馬場×芝ダート、さらに距離帯、さらに季節という3段階を全件出す。合算100競走以上かつ各年20競走以上を「記述比較の件数がある群」と事前に定義。件数を満たしても優位の証明とはしない。京都芝2601m以上と秋の同条件は件数不足でも明示する。

入力は独立検算済みD0成功runの競走別損失・的中と同じSHAのdataset。市場損失は保存済み市場確率の正解ペアから算出する。全7,857競走のID一意性とD0全体集計が前結果に一致すること、各粒度で件数の総和が7,857に一致すること、3年分の合算を確認する。条件間の大量比較に対する有意差や未知再現性を主張しない。新規スクリプトと集計JSON/報告だけ、学習/SQL/HTTP/新規依存/予想更新なし。ソース・モデル・入力SHA不整合時は停止する。
