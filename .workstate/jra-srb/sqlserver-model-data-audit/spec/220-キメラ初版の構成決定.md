# キメラ初版の構成決定

作成日: 2026-10-18 JST。状態: 利用者依頼による構成の選定。実装・学習・性能採用は未実施。

## 決定

初版を「時計と相手水準に基づく能力評価に、ラップ・条件適性を組み合わせ、近況と情報の確かさで調整するキメラ」とする。モデルIDは実装前に既存IDと重複しないものを定める。人物の印や手順の再現ではなく、複数の予想論から抽出した発想を独自に組み合わせる。

これは素材比較に基づく設計上の決定で、性能の順位・改善の確認ではない。実装可否は指定データの監査を通過することが条件。データ未成立時に時計等を従来の着順特徴へ黙って置換して実行しない。

## 10系統の比較と選定

| 素材 | 既存との差分・補完する役割 | 初版の扱い | 理由・成立条件 |
|---|---|---|---|
| 時計補正 | 頭数正規化着順では見えない走行能力の尺度 | 核Aに採用 | コース・距離・馬場条件別の比較ができる。原時計と条件、単位・時点・異常値・期間別欠測の監査が必要 |
| 相手関係・レース水準 | 同じ3着でも相手が違う場合の評価差 | 核Aに採用 | 時計と同じ能力を二重加点せず、時計評価と相手評価が不一致の時の調整・不確実性として扱う。対戦相手の履歴が必要 |
| 区間ラップ適性 | 過去の能力が今回の流れで発揮されるか | 核Bに採用 | 全体ラップ型とその条件下の個体成績を用い、相手構成の展開見込みとの関係を評価。個別区間時計の実測があるとは扱わない |
| ローテーション・状態変化 | 過去評価をそのまま今回へ持ち込む危険の調整 | 制御Cに限定採用 | 経過日数・条件変化・近況の継続性を信頼度に使う。心理・疲労を観測したとは言わず、旧T03/T13等の名前替えを独立成果にしない |
| 条件付き人物・個体評価 | 騎手・厩舎の条件別差 | 初版の新規部品にはしない | 旧3着内率は比較用の既存入力として凍結。条件を細分化する新プロファイルは少標本/交絡と候補数を増やすため後回し |
| 血統 | 過去走が少ない馬・未経験条件の補完 | 次段階候補として保留 | 核の直接観測を先に成立させる。親子ID・時点付き履歴と少標本処理を未確認。不要と結論したわけではない |
| 調教 | 走行履歴と異なる直前の状態情報 | 次段階候補として保留 | 時点付き調教履歴・場所・記録条件・欠測を未確認。名前や馬体重で代用しない |
| トラックバイアス | 内外・位置取りの有利不利 | 初版対象外 | 実進路の観測と当日途中時点の推定を未確認。核Aの時計上の馬場差と、内外の進路偏りを混同しない |
| 個別の物理的不利 | 接触・出遅れ・折り合いなど | 初版対象外 | 通過順位だけで実不利を数値化したと扱わない。記録・公開時刻の確保が別途必要 |
| 馬体/パドック | 数値履歴にない状態・形態 | 初版対象外 | 過去の時刻付き映像/画像・評価・利用条件を未確認。初版全体の検証を遅らせる要因となるため分離 |

先に3部品を決めて素材を当てはめたものではなく、10系統を比較し、既存経路に明確な差分を作る観測とその補完関係を選んだ。残した素材を失敗のたびに順次追加して評価期間を使い回す運用にはしない。

## 各部品の責務

### A：時計・相手水準を踏まえた過去走能力

コース・距離・芝ダート・馬場条件等を考慮した時計尺度を基礎にする。相手の強さはその過去レースより前の成績から推定し、相手の将来の勝ち上がりを先取りしない。時計と相手水準を独立した能力点として単純加算しない。

過去走の観測が得られた後、次のレースに向けて能力を更新する。基準時計や馬場差等の推定も、該当する評価時点より後のデータで再計算して過去予測へ混ぜない。異なる時期・クラス・馬場の同じ着順を同能力と扱う現在の簡略集計からの変更が中心となる。

### B：ラップ型と今回条件の適合

Aで高能力でも、持続的に速い流れと終盤に加速する流れで同じ評価にはしない。過去の全体ラップ型、その条件下の個体パフォーマンス、今回の距離・コースと全出走馬の過去脚質から、今回の能力発揮の違いを推定する。

今回の展開は一つに決め打ちせず、速い/中間/遅い等の分布として扱う方法を基本案にする。区分と基準は学習期間内で固定する。現レースの実ラップ・通過順は特徴へ入れない。個別馬の全区間時計を推測値で実測のように扱わない。

### C：近況・履歴の信頼度による調整

履歴件数、今回条件に近い経験、観測欠測、経過日数と近走の継続性から、A/Bの推定をどこまで反映するかを調整する。履歴が薄い条件の見かけの高評価を抑え、裏付けがない場合は事前に固定した基礎推定へ縮約する。

単に点を加える独立した状態モデルにはせず、A/Bへの信頼度として使う。欠測時に将来結果や根拠のない好調点で補完しない。年齢・斤量・枠等の既存基本入力は発走前可用性を確認して再利用する。

## 統合と出力

`過去走のA → 今回条件と展開によるBの調整 → Cによる反映度の制御 → 全馬連組の確率`

人物ごとの印の平均や、別名の能力点の足し算は行わない。A/B/Cの作用を、同じ学習器に渡す入力と少数の関係項として固定する。学習器の詳細は実装仕様で確定し、構成選定後のアルゴリズム総当たりはしない。現在のR1確率の校正係数・価格帯閾値を調整する構成ではない。

最終的に比較する目的は既存研究と同じ馬連確率とする。2頭間の勝敗確率や単勝確率を、そのまま馬連の的中確率へ読み替えない。全組合せの確率合計を1にする計算と、その保存後検証を必須にする。

市場確率は同じ時点の比較基準、価格は購入判断として扱う。市場との混合を行う場合は別の設計変更として扱い、今回の構成選定だけで混合係数探索まで承認したとはしない。

## データについて今回確認できたこと

- 既存コードjra_research_tipster_twenty.pyのstrengthは1−(着順−1)/(頭数−1)。48特徴に走破タイム・血統・調教を直接入力していない。相手の強さを直接調整する処理も今回の経路では確認できない。
- 通常研究readerによるsys.tables/sys.columns/sys.typesの限定SELECTを実行。finish_time列をapi_runtime.result_entries、api_runtime.netkeiba_result_entries、live.result_entries、live.netkeiba_result_entriesで確認。型はnvarchar。
- live.result_entriesのmigration_row_id順TOP5を読み、1:12.2、1:12.7、1:13.0、1:13.1、1:13.4の文字列表現を確認した。全期間・正常値率・snapshotとJV履歴の同定・過去時点の版を保証する標本ではない。
- 血統/調教関連ではsire_id、dam_id、father_id、mother_id、training_date、training_time、pedigree_jsonという完全一致列名は、今回の可視メタデータに該当なし。別名・原文・JSON・非可視表に存在しないという意味ではない。
- 既存JV年別readerではRA/SEのラップ・馬ID・着順等の利用実績がある。今回SEの走破タイムoffsetや血統/調教原文の有無を新たに保証する調査はしていない。

SQLは既存ExperimentMarketReaderとHistoryConfigによる通常研究接続のSELECTのみ。管理者接続・権限変更・index変更・データ更新なし。取得した観測から利用可能性を過大評価しない。

## 実装前の成立条件と再利用

1. 既存SQLの版・レースID・馬ID・日時を使い、時計と相手履歴の対応、年/月/場/条件別の欠測・異常率を確認する。原時計をJVから読む場合もSDK定義と少数値の照合が必要。
2. 基準時計・馬場差・相手評価・展開推定は時系列で生成し、評価時点より後の情報が混ざらないことを確認する。同日結果の扱いは既存の翌日更新規約を基本とする。
3. 核Aが不成立なら初版の実装/学習を停止する。Bのラップ不足時は寄与を抑えてAへ戻す規則を実行前に定め、欠測を理由に対象競走を都合よく選ばない。
4. AnnualReader/LiveAnnualReaderの年別読取、HistoryConfig、馬ID・日付の履歴更新規約、RunArtifactsのhash・予測保存、既存のHR精算・日単位bootstrap・保存検証を再利用する。API・既定スキル・元R1を直接改変しない。
5. 実装の対象ファイル・必要な既存関数への変更・最小確認方法を具体化してから、更新AGENTSに従い利用者の了承を得て実装する。今回の依頼で行ったのは構成決定と限定調査であり、新規実装ではない。

## 最小の比較構成と終了条件

候補はA+B+Cの本体1案。Aのみ、A+Bの2対照を同じ学習器・期間で比較し、B/Cの追加効果を順に見る。これは候補総当たりではなく、事前固定する部品寄与の診断。最終評価を見てよかった対照へ採用し直さない。

市場と保存R1を同一競走・同一時点で比較し、既存S06/S08も時点を揃えた出力が利用可能な場合に限って参考比較する。未生成の比較結果を補完しない。

予測精度と購入成績を分ける原則を維持する。spec200の提案を基に、学習・開発・独立評価の具体的な期間と必要件数、R1比0.5%/市場比0.25%の損失改善、日単位区間・Brier・購入標本/収益条件を実行前の契約で固定する。今回の構成決定だけで正式な評価期間を確定したとはしない。

比較後の微調整案を追加せず、未達ならこの固定構成は不採用とする。血統等の保留素材を同じ評価結果を見ながら順次足さない。R1現行入力系列の終了は維持する。

## 考え方の出典と独自設計の区別

- [RHSPEEDERの公開説明](https://jra-van.jp/dlb/sft/lib/rhspeeder.html)から、時計を条件補正して能力評価する視点を参考にした。同製品の計算・指数は転載/再現しない。
- [JRA-VAN対戦型の説明](https://jra-van.jp/fun/dm/game_mining.html)とspec210のキムラヨウヘイの公開説明から、相対比較・相手水準を独立に考える視点を参考にした。両者の方式が同一とは主張しない。
- [夏目耕四郎の公式説明](https://ameblo.jp/546natsume/entry-12521033618.html)から、能力と区間ラップへの適性を分ける視点を参考にした。個別区間時計や本人の非公開式を復元したとはしない。
- spec210のローテーションの発想を、独自にCの反映度の制御へ整理した。本人の心理状態判定・具体的手順の再現ではない。

以上を組み合わせた構成・データ監査条件・比較計画は本案件の設計判断であり、引用先がこのキメラの性能を実証したわけではない。
