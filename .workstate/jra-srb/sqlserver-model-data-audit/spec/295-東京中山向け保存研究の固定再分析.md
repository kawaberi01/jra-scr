# 東京・中山向け保存研究の固定再分析

作成日: 2026-10-23 JST。利用者の意図訂正066と「では開始してください」に基づく実行仕様。目的は過去研究から東京・中山で有望なモデル/適用条件を再評価し、2026年10月以降の利用候補を絞ること。研究期間は保存OOSの2024-04〜2026-09、2024/2025と2026を分ける。全期間既使用の探索であり未知性は主張しない。

## 候補と区分

- 基準panel: 元30月のJ23/R1/J01/M0、同じ7,127競走から東京・中山を抽出。
- V110 panel: 機械学習V110保存OOSと上記基準の共通競走。元確率配列から正解確率/logloss/Brierを再計算し、保存loss・ペア数/ラベル・購入精算を照合。不整合競走は理由別に隔離し、除外件数を表示する。
- S08 panel: 分解研究metricsのrace_diagnosticsからfull/historyの競走全体logloss/Brierと既存stratum rich/sparseを取得。選択ペア保存行を別照合し会計を確認。J23基準と共通する競走だけで比較する。
- 基本条件は両場合算/東京/中山、それぞれ通年/秋（9〜11月）の6区分。V110は両場合算の2000m超を通年/秋の2区分追加。S08は両場合算の既存rich/sparseを通年/秋の4区分追加。結果で境界・モデル・条件を増やさない。
- 年別2024/2025/2026、2025末まで/2026、全期間を表示。2026は9月までで、東京秋は該当0、中山秋は9月だけになり得る。0件を不振としない。

## 比較契約

各panel内は同じ競走でモデルを比較し、panel間の異なる集合のROIを直接順位付けしない。J23等の元選択を維持。V110は元100円精算を600円へ比例換算、S08は元600円。この換算は予算差だけの調整で、価格帯/閾値の差は残るためモデル＋元購入政策の比較とする。

全競走logloss/Brier、購入点数/日数/的中/期待的中、ROI/総損益/1元競走当たり損益/最大DD、最大1件/3件払戻除外を表示する。全ペア確率を保存していない方式の再選択・新混合はしない。

V110のprojected_return/probabilityから復元できる数値価格は、元ticket価格・元M0の勝ちペア確率/二乗和、J23選択価格との一致を診断する。比較の入力市場が違う場合も隠さず、同じ情報を与えたモデル単体比較とは称さない。保存内容だけでは全馬名/全horse ID/公表時点までは受入できない。この限定を記録し、SQL再読取で全面再現したと主張しない。

開催日対応bootstrap2,000回、seed295。ROI区間・J23に対する損失/利益差を併記する。区間は多重比較未補正の探索診断。的中0群のbootstrap[0,0]を真の将来ROI0としない。

## 結論の区別

実用採用や本番変更は今回行わない。100購入/30日/10的中以上、ROI105%以上と開催日ROI95%下限100%超の既存型の最低収益条件を各集計で表示し、良い点推定と区別する。高配当除外は脆弱性診断であり、全方式へ新たな一律合格ルールとして遡及適用しない。

2024/2025の秋での再現、2026の別季節における安定性を分けて解釈する。東京秋2026が未保存でも過去の研究価値まで否定しない。10月以降で利用する候補の優先順位と未確認事項を記録する。
