# D0競馬場別独立学習の固定比較

2026-10-25。利用者がspec390の並行研究を踏まえ「学習を開始」と指示。A系統の実行契約。目的は教師を競馬場別に完全分割する効果の対応比較。旧D0・既定モデル・予想・API/schema/依存を変更しない。

## 固定入力と方式

spec365の検算済み19,471競走(2020〜2025の17,309と2026保存2,162)をSHA確認して再利用。15馬履歴特徴と6公開属性、同時点市場/PL、同じD0の46ペア列を使用。馬の履歴形成は他場の過去走も含む元の時系列特徴を維持し、学習教師の競馬場だけを限定する。全場履歴を再構築しない。

L0=元の全場共有D0、L1=当該競馬場だけの教師で既存attribute.fit(D0)を実行。特徴、目的関数、正則化、最低100教師の条件差分、最適化250回/1数値スレッド/2GiBを変更しない。独立モデルにtrained_courseとscope情報を保存し、別場への推論を拒否する。

## 期間・学習回数・選択

2020〜2022教師→2023開発。10場それぞれL1を学習し、同じ場のL0と同じ競走/市場で比較。L1の開発損失がL0より1e-8超小さく、的中率がL0未満でない時だけ、その場の開発選択をL1に固定。それ以外はL0。選択で後年を使用しない。

2024と2025は各前年末までの全当該場教師、2026は2025末までの全当該場教師で、全10場のL1を作る。開発でL0を選んだ場も独立型の成績を説明用に保存するが、後年を見てL1へ変更しない。最大40新fit(10場×4境界)、旧全場D0 fit0。年度・馬集合・時点市場・結果が同一の対応比較を行う。2026は保存末尾9/22まで。

## 場別と全体の判定

各場の固定確認3年合算で、L1損失<L0、対応日bootstrap95%改善下限>0、各年市場より損失改善、合算的中率L0以上、開発選択L1の5条件を全て満たす場を追加の有望研究候補とする。10場比較の区間は探索的で、同時検定の有意差・未知再現性を証明しない。未達の場はL0を保持。各年/全体のL0・L1・市場、開発固定の場別ルーティングも全件保存する。場別結果を全体率だけで置換しない。

採用判断に関わらず最終10独立モデルを保存し、性能合格とモデル完成を区別する。既定モデルへの自動登録はしない。未達場の確認成績を理由に新閾値/部品/クラスを追加しない。B系統の新特徴を今回の学習へ混ぜない。

## 実装・確認・停止

新規の薄い競馬場scope module、runner、tests、独立verifierのみ。既存attribute.fit/predict、D0年別モデル/保存分布、集計/対応日bootstrapを再利用。全教師の場限定と日付、全test集合一致、元SHA、保存後一致、結果遮断、別場拒否を確認。全保存L1分布を別行列の式で検算し、選択/全40教師ID/場別判定/全体ルーティング/最終モデルSHAを照合する。

失敗はfailure.jsonを保存して依存する実行を停止。根拠のない再試行をしない。重い学習は一つずつ、学習中にBの資料/データ監査を進める。SQL/HTTP/実購入/予想変更0。
