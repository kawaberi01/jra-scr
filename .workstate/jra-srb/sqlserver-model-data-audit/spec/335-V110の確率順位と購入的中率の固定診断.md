# V110の確率順位と購入的中率の固定診断

作成日: 2026-10-24 JST。利用者の「進めてください」に基づく保存予測の原因分析。新モデル・購入条件の実装ではない。

対象はspec330の2021〜2023年東京1,320競走。保存済みpredictions.jsonl.gzを使い、学習・原入力取得・本番変更は行わない。結果前に以下の診断を固定する。

- 全馬連、各競走の最大予測確率1点、元条件の購入1点の3母集団で、予測確率平均・実的中率を照合する。元購入は997点29的中へ一致すること。
- 確率帯は[0,1,2,3,5,10,20,30,50,100]%の境界を固定する。帯ごとの件数・予測的中数・実的中数・的中率を保存。少数帯や購入選別後の帯を独立試験と呼ばない。
- 各競走の確率1位をV110/PL/M0で比較。主に確率順位を診断し、1位を買う新方針の採用・利益判定はしない。
- V110の確率順位1〜5位と6位以下の実的中数/予測的中数を保存し、元購入の順位・オッズ・確率の分布を確認。全馬連についてSpearmanを安易に使わず、固定確率帯と順位で判断する。
- 元購入・V110確率1位について、モデル確率と市場正規化確率に対する実的中率差を開催日block bootstrap 10,000回seed335で探索的に確認する。V1101位−元購入とV1101位−M0の的中差も同じ開催日単位で計算する。前者は購入有無で母数が異なる比率差であり因果効果と呼ばない。
- 的中はpayout_per_100>0で数える。複数正解のfractional targetによる確率スコアと、買い目が的中する二値頻度を混同しない。複数正解があれば明示する。
- 年別にも同じ集計を保存し、合計のみで再現性を断定しない。高確率帯の結果を見た閾値選択はしない。

確認方法: 元データSHA保存、3方式のレース集合/組順/正解一致、確率和、元購入選択/的中の再計算、帯・順位の件数/的中合計保存、別処理による代表集計再照合。標準ライブラリと既存numpyのみ。成果物は新しいv110_probability_diagnostic_20261024、記録076。旧330成果物は変更しない。
