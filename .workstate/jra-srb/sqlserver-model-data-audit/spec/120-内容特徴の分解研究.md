# 内容特徴の分解研究：固定条件

作成日: 2026-10-17。利用者の改善案①の実施依頼に基づく。削除は利用者指示で保留。

## 目的と対象

内容特徴が現行S08に寄与するかを種類別に調べ、SQL34での欠測/形式不適格と利用時の欠測を区別する。新研究module/CLI/結果資料/progressだけを追加・更新する。既存step4、旧モデル、共通Store、設定、SQL、APIを変更しない。新規取得・SQLite/旧JSONL読取・移行・削除・原データ/全特徴の保存は行わない。

## 結果を見る前に固定する条件

- 入力・採用集合・期間はspec100を継承。長期履歴2671R、内容学習2025年1412R、校正2025年10月224R、評価2025年11月〜2026年5月1594R。夏を除外。既使用期間の探索的比較であり未使用テストではない。
- 基準run: 20261017T051954Z_72e96ea8375744bcac0243ab86518cca。入力digest一致と既存models.joblibのSHAを確認する。保存済み長期q_historyとq_recent/変換を再利用し、基準モデルを再学習しない。
- 5案：history（長期q_history）、full（現行長期S08）、no_corner、no_pace、no_closing。3除外案だけ内容モデルを同じ2025年学習/校正・penalty=.1で再学習する。新閾値の探索はしない。
- no_corner：content[7,8,9,11]の和/差、condition[23,24]の和/差、末尾3つの脚質相互作用を除外。通過順位に依存する派生項目も含める。
- no_pace：content[10,11]の和/差を除外。no_closing：content[5,6]の和/差を除外。これらは互いに独立した除外比較で、効果を足し合わせない。
- 学習/校正30%以上観測という既存の採用列を維持し、その中から該当列だけを除外する。補完は学習期のみで適合。欠測indicatorも除外済み列から作らない。
- 混合gateは現行fullと全除外案で同じ値を使う。列除外でgateを変えて二要因を同時に比較しない。gate自体の最適化は今回行わない。
- 馬連の同じS08購入規則（価格4〜80、確率1.5%以上、期待払戻順、最大1点600円）を全5案で適用。馬連のみ。ワイドモデルとML方式・購入規則の改造は後続。
- 対数損失/Brierと回収率/点数/日数/最大資金減少を、全体・既存3期間で併記。同日単位1000回bootstrapによるfull比の対数損失差の95%区間を記録。多重比較補正済み検定や独立検証とは呼ばない。
- 欠測診断はSQL34の既存3表読取に付随する月別集計。原値の有無、通過順位/ラップの形式適格、馬名・推定生年・性別の同定可能率、推論入力のペア観測率を記録。追加の全量SQL走査を行わない。
- レース内の両馬に最新通過順位/ラップが観測されるペア割合が共に50%以上かで事前固定2群へ分け、両群を全部報告。群ごとの購入ルールは作らない。

## 実行・停止・完了条件

SELECT専用・旧入力拒否hook・2GiB・7日入力・30秒query timeout等は継承。既存の結果混入設計検査も継承。新保存モデルの再読込推論一致、確率和、会計、基準full/historyのstep4損失/回収率一致を実験内で確認する。外部テスト/pytestは追加実行しない。

期間/入力digest/基準モデルが違う、上限超過、SQL失敗、保存後推論差、不正精算ならそのrunを失敗として記録し後続を止める。原因特定なしの再試行をしない。初回の誤実装なら同条件を維持した対象限定修正だけを行う。

保存は新モデル・契約/列名・入力digest・月別診断・レース別の選択ペアと評価・集計に限定し、全ペア/全特徴の追加複製を避ける。欠測を原因と断定しない。改善がなければ今回の除外案を終了と記録し、利益が出るまで条件を掘り続けない。
