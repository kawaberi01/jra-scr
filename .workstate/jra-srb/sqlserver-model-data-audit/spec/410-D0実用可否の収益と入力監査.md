# D0実用可否の収益と入力監査

2026-10-25。利用者の継続検証指示に基づく固定契約。D0の確率参考利用と、現在の実用購入採用を分け、今回の証拠で採否を明記する。将来データがまだないことを性能合格と扱わず、採用判断を無期限保留にしない。

1. 元D0/市場/BCの同じ2024〜2026年7,857競走で全レース馬連確率1位に100円を仮想投資。購入額/的中/公式100円払戻/利益/回収率、年別・全場別・芝ダート距離別、日単位bootstrap2000回のROI95%区間を計算。正解ペアと払戻を元カード結果から独立再照合。同着等の例外は元datasetの対象外範囲を維持し、新除外なし。
2. 最大的中払戻1件/上位5件を外した収支を説明用に併記し、良いレースや場を後から選ばない。的中率上位と収益優位を区別。3年は既使用の過去であり未知試験ではない。
3. この全レース1点は固定ベンチマークであり、未定義の全買い方について不可能と断定しない。オッズを正規化した市場確率だけから発走時の期待値買いを捏造しない。購入用の事前価格/見送りルールと検証がない場合は購入採用しない。
4. 当日全日scout保存をSHA固定し、全件の分析/失敗理由、全場履歴最新性、発走前保存・時点入力の証拠を監査。少数分析可能と全日使用可能を分ける。学習時のRAやカードの歴史公表時点未証明は継続。
5. 現在の実用購入採用は、未知/前向きの十分な証拠・結果を読む前の固定予測と購入ルール・当時入力/最新履歴の検証・対応期間の利益とROI区間下限>100%・年別頑健性・高配当1件依存なしを全て満たす場合のみ。どれか不明/未達なら現段階不採用と明記。前向き件数はspec415に従い、過去成績を流用しない。
6. 研究参考の利用は計算検算/市場比損失改善の既存根拠を認めるが、入力を検証できた個別競走に限定。単勝勝率/着順確率への読み替え、全レース高確度の主張、購入推奨はしない。

実装は新規監査script/tests/verifierと研究出力だけ。既存Store/API/SQL/設定/予想変更なし。結果利用は評価専用で予測計算に混入しない。sourceと元payout不一致はfailで停止。独立再集計と全SHAを確認する。
