# 条件制限の時系列再検証と継続運用

2026-11-07。利用者の「更に研究を続けて一定の成果まで繰り返す」という承認に基づく。既存の実購入禁止・過去履歴の追加取得不可・未来入力保存済みを維持する。成果は判定可能な研究結果と再現可能な検証運用であり、利益を保証しない。

## 対象・再利用・確認方法

1. 本日の48件をpayload/GET読戻し/評価読戻しから監査する。v2から移行した1件は元v2の原本を参照し、コピーや再生成をしない。各ID、発走前受領、予測一致、予算0、仮想精算を照合し、本日実績を保存する。
2. 既存S0/T30/P01、M10/T10/Aの全2023〜26年の保存確率・価格・払戻を再利用。モデル再学習なし。5区分（場、距離、芝ダート、場×芝ダート、芝ダート×距離）×2選別規則を各モデルで比較する。距離帯は<=1400、1401〜1800、1801〜2200、2201〜2600、2601以上。境界を成績で動かさない。
3. 選別は各評価年の前年末までの購入行だけで決定。基本は過去30購入・5的中・10開催日以上で合計黒字。年安定型はさらに、観測された各前年に10購入以上かつ各年黒字を要求。条件不足は見送り、全体成績へフォールバックしない。2024/25/26の3回を逐次比較し、当年以降の結果を選別に使わない。分割モデルの再学習ではなく購入制限である。
4. 同時点T10のM10/A候補を、S0_directの確率順位1位一致、順位3位以内、S0_directのE>=1、S10のE>=1、両者のE>=1、という5固定条件で比較する。S0/T30との時点混同をしない。元M10/Aの閾値/選択は変更せず、合議は独立証拠とは呼ばない。
5. 対照2+条件制限20+合議5=27セル。既存policy.assessによる同日20,000再抽出・全27セルの家族下限・年間件数/黒字・最大配当除外・最低購入/的中/日数の採否を維持する。既使用過去で未知試験とは呼ばない。成績に応じた追加区分・閾値探索はしない。全選択を別実装の集計・前年境界照合で検算する。

## 変更範囲と対象外

専用研究module/script/test、成果物、仕様/進捗/判断記録だけ。既存データローダー・年別確率・固定選択/精算/区間・shadow watcherを再利用。既定モデル・予想スキル・DB構造・収集設定・実購入・API/collectorの再起動は対象外。

## 次開催への継続

条件の採否にかかわらず、事前固定済みS0/P01とM10/Aを比較候補として保持する。今後の同じ研究の継続を承認済みと解釈し、spec453の一日限定をこの追加仕様に限って拡張する。恒久タスクは作らず、最長14暦日（2026-11-08〜11-21、各日09〜18時JST）のHiddenプロセスで既存一日workerを順次使う。日付ごとの新run、監督台帳、モデル/実装SHAを固定し、変更・失敗で自動停止する。PC終了時の自動復旧は対象外。API/collectorの可用性は観測して記録し、勝手に起動/再起動しない。実購入は常に0。無開催日も無購入として台帳に残す。

## 停止条件

入力SHA/名簿/年境界/金額/原本照合の不一致は依存処理を停止し失敗証跡を保存。成果が弱いことを理由に既知期間の条件追加を繰り返さない。将来の結果未発生を研究成功や購入可と扱わない。
