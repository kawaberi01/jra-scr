# 新キメラ20仮説の比較研究案

作成日: 2026-10-18 JST。状態: 利用者が実装・学習・性能測定まで承認済み。重複確認は不要。利用者の「仮説を立て20ケース壁打ちから検証研究を試行してより良いモデルを作る」依頼への具体案。

## 目的と既存研究との差分

予想家本人の再現ではなく、公開予想論から得た概念を検証可能な特徴・確率モデルへ翻訳する。過去の19理論＋混合の20案と、終了済みABC初版を再実行しただけのものは新ケースに数えない。

初版ABCは485競走で対数損失4.113505、R1比21.62197%悪化。これは結果であり、時計尺度・関数形・縮約・確率統合のどこが原因かを分離した証明ではない。各仮説には反論と失敗条件を置き、支持された部品だけで最終候補を固定する。全案不合格なら不採用で終了し、「使えるモデルができた」と報告しない。

監査68,315競走・973,066出走、24年digest、時計/馬場100%の証拠を再利用する。全期間は履歴形成と学習可能な対象に使うが、過去予測の特徴には必ず前日までの情報だけを使う。血統・調教・映像・パドックを取得済みと仮定しない。

## 固定する20ケースの壁打ち

基準N0は初版ABの定義を固定した再利用対照。N0だけを再学習して新規研究とは数えない。H01〜H18は下記の差分をN0へ単独で加える。複数箇所の改変を一つの成功原因としない。H19/H20はN0に対する固定の確率統合方法。全20ケースで正規化された馬連確率を出す。

| ID | 仮説・実装する差分 | 反論・疑わしい点 | 棄却する観測／旧研究との違い |
|---|---|---|---|
| H01 | 時計基準を勝馬だけから過去出走馬全体の代表速度へ変える | 弱い馬の構成で基準が動く | 時系列検証で損失が改善しないなら棄却。初版の勝馬基準との分離比較 |
| H02 | 時計差を芝ダート・距離別の過去の分散でも標準化する | 少数条件の分散が不安定 | 学習履歴のみで尺度を固定し、欠測群で悪化するなら棄却。固定2m/s単位を変更 |
| H03 | 時計の馬場・場別補正を過去180日窓へ限定する | 短期化で標本を失う | 平坦な長期平均との差と月別の悪化を確認。旧着順特徴の近況窓変更とは区別 |
| H04 | 直近3走の時計平均を中央値へ変える | 強い一走まで捨てる | 外れ値の多い馬だけの好成績を全体利益と扱わない。時計外れ値耐性の比較 |
| H05 | 秒差から「勝馬との距離換算差／走行距離」を追加する | 遅い組の好走を過大評価する | 相手評価を残した対照との差がなければ棄却。単なる順位正規化と区別 |
| H06 | 相手ratingの更新幅を履歴数で縮約する | 初出走や成長馬に反応できない | 少履歴・十分履歴を分け、全体改善と最低限の安定性を要求。固定更新率との差 |
| H07 | 時計効果に固定した折れ線基底を追加する | 非線形列が過学習する | 節点は学習標本の分位点だけで決め、検証結果から増減しない。線形時計との比較 |
| H08 | 芝とダートで時計・相手水準の係数を分ける | 係数分割でデータ効率が落ちる | 両群を別掲し、全体だけの改善で一方の大幅悪化を隠さない。入力追加ではなく効果の分離 |
| H09 | 距離帯の一致／不一致を距離差の連続重みへ変える | 適距離の境目をならしてしまう | 固定距離カーネルで比較し、帯境界だけの事後調整をしない。旧距離帯平均との差 |
| H10 | 場適性を芝ダート別に分け、件数による縮約を行う | 同じ場の標本が細分化する | 少数群の損失と全体を別掲。単純な競馬場平均との差 |
| H11 | 馬自身の上がり3Fを、その過去レースの全体後半ラップとの差で表す | 個別区間と全体区間は測定範囲が一致しない | 定義・欠測を明示し、同一レース平均との差を個別実測ラップと呼ばない。旧上がり順位との違い |
| H12 | 先行密度を3区分から連続値へ変え、脚質との積を追加する | 先行争いは単純な人数比で決まらない | 実ペースを入力せず、前日時点の脚質だけで検証。旧密度集計ではなく時計・脚質との関係 |
| H13 | 速い流れを先行した負担を、相対時計と着順の食い違いとして追加する | 単純に能力不足だった可能性 | 相対時計を外すと旧理論T06と同じなので別ケースにしない。全体と該当群の両方を確認 |
| H14 | 時計の近況と自己最高との差に、前走からの日数を掛け合わせる | 休養後の回復と劣化を区別できない | 固定交互作用一つで比較し、都合のよい休養日数を探索しない。旧着順ベース復調との違い |
| H15 | 信頼度を能力値へ掛けず、件数・経過日・欠測を独立入力にする | 能力値の誤差自体は抑えられない | 初版Cの悪化の原因を決めつけず、ABとの差で判定。Cの乗算処理との比較 |
| H16 | 履歴ゼロ馬に年齢・芝ダート別の過去日コホート事前値を置く | 粗い事前値が個体差を隠す | 全体と履歴ゼロ群を併記し、血統等を推測しない。初版の一律ゼロとの違い |
| H17 | ペアの平均・絶対差に時計同士および時計×脚質の積を追加する | 相関した列が尤度だけを稼ぐ | 検証で改善しなければ棄却。min/maxへの言い換えは同じ線形空間なので新案に数えない |
| H18 | 馬ごとの能力スコアから順序付き1・2着を合算する確率へ変更する | 2頭の依存関係を単純化する | 全ペア総和1と馬番順不変を検証し、馬連尤度で比較。単勝確率の積で代用しない |
| H19 | N0の新時計確率10%と同時点市場90%を算術混合する | 悪いN0の混合で市場も悪化し得る | 重みは0.1固定、事後探索なし。旧R1の校正・価格・時点研究の再開ではない |
| H20 | N0の新時計確率10%と同時点市場90%を幾何混合し再正規化する | 小さい予測確率を必要以上に抑える | 重みは0.1固定、H19との差と市場比を確認。新時計情報の統合方法だけを比較 |

これらは有効性の主張ではなく未検証の仮説。H01〜H18は固定差分なので、複合仮説を後から好きに組み合わせる探索は含まない。H19/H20も市場に近づけただけなら採用しない。

## 時系列の選抜と比較の公正さ

1. 実行前に20定義・特徴式・seed・正則化・分割日・上限をconfigとspecへ固定してhash保存。入力が足りないケースは理由を記録し、別仮説へ無断差し替えしない。
2. 一次: 2003〜2024年で学習、2025年1〜6月で20案を比較。市場を用いるH19/H20は予測時だけ同じT30を用い、学習入力に市場は不要。候補全ての成績・月別・履歴数別を保存する。
3. 一次の対数損失順で最大3案を固定。件数95%以上を満たさない案や実装検証に失敗した案は候補に入れない。購入成績を使って順位を付けない。
4. 二次: 最大3案だけ2025年6月末までで再学習し、2025年7〜9月で比較。一次からの安定性も確認して最終1案を固定する。未改善なら終了。二次の結果を見て部品追加や再組合せはしない。
5. 固定1案だけ2025年9月末までで再学習し、既存485競走の11〜12月をR1・市場と比較する。一次/二次用のR1を置く場合は、その時点までで学習し直した同仕様対照と明記し、将来まで学習済みの保存R1を過去へ適用しない。
6. この485競走を通過した場合だけ2026年の既定1279競走を評価。既参照期間での回顧検証と明示する。新規の発走前予測を固定・保存した後の将来結果で、別途外部確認する。

一次/二次のT30履歴・HRが対象期間に揃うかは新しい限定事前確認が必要。95%未満なら学習を始めず、欠損日・件数を報告する。別時点市場や確定オッズで補わない。旧監査の年別全量再実行はしない。

既に2025/2026を見ており、今回の分割でも完全な未知データは作れない。20案から選んだ後の区間を単一事前候補と同じ確証として扱わない。選抜期間では多重比較を踏まえた対応日bootstrapを報告し、最終485競走でもR1/市場の2比較だけの補正を「全研究の選択バイアスを解消した」と説明しない。

## 性能・購入・停止条件

- 予測の既定条件を維持: 開発400競走/15日/95%以上、対R1損失0.5%以上改善、同時点市場比0.25%以上改善、Brier悪化0.5%以内、対応日bootstrap2,000回・主2比較各97.5%区間の上限0未満。
- 後続検証: 1,000競走/40日/95%以上、同じ精度条件と期間別非悪化を要求。
- 購入は別判定: 固定政策で100点/30購入日/10的中以上、回収率105%以上、R1比+5ポイント以上、日別区間の回収率下限100%超かつ対応損益差下限0超。最大払戻除外も併記。購入成績で精度未達を覆さない。
- 上限は20ケース、一次20学習＋二次最大3学習＋最終1学習。N0・時点適正R1などの対照は別記し、候補追加に流用しない。新規20超の探索・同じ結果を見た再調整は行わない。
- 数値最適化は既定L2=0.01、最大400反復、2GB制約を基本とし、仕様上変更が必要なら成績を見る前に理由と変更を固定する。時系列の検証完了がない案を採用しない。
- 入力不整合・時点違反・メモリ超過・非収束は実装/入力失敗として依存処理を停止し、性能不合格と区別する。修正後も入力・学習目的・候補の同一性を検証する。
