# 当日属性と連続距離の条件共有

作成日: 2026-10-24。利用者の追加研鑽指示に基づく別仮説。spec360の順位追加/市場混合は開発で不適格、H2を保持したまま入力表現を比較する。

## 仮説・入力

H2の15特徴には馬の現在の年齢/性別/枠の属性が直接入っていない。これを公開属性として追加する。また距離帯の完全な交差条件は長距離で少標本になるため、距離を連続値で扱って近い条件から係数を共有する。既存v2保存カード/履歴特徴を検査し、年齢・性別・枠・馬番を馬番順に同定する。未公表/欠測が多い斤量・馬体重を0埋めで追加しない。歴史カード属性の公表時点未証明は引き続き明記する。

追加馬属性6列: 年齢/10、牝フラグ、騸フラグ、枠/8、馬番/頭数、枠欠測フラグ。対象競走の公開値だけ。初期充足確認で2026の全保存出走中600行に枠欠測があるため、欠測は観測値とせず中立0.5+明示フラグで表す。斤量は旧年ほぼ全欠測で使わない。レース条件フラグは既存is_newcomer/is_maiden/is_open_or_stakesの3列を同一競走で一致確認して使う。市場と結果の馬集合が既に照合済みの既存17,309+2026年2,162競走へ公開属性を結合する。SQL/HTTP/原文再構築なし。

属性結合の初回は学習前に停止。2026の公開性齢「せん6/鹿」等で、旧履歴フラグの騸/牡/牝が全0になる表記未対応を特定した。新属性の性齢は公開sex_ageから牡/牝/セ/セン/せん/騸を正規化して作り、非0の旧フラグとの矛盾や年齢不一致は拒否する。旧データ/旧H2を修正しない。初回failed成果物を保持し、修正理由と新コードSHAで別runを作る。性能結果を見た条件変更ではない。

2回目も学習前に旧年齢尺度との照合で停止。実コードjra_history_dataset.pyの旧age_scaledはmin(年齢/10,1)であり、牡11の公開表示と1.0は矛盾ではない。照合は旧尺度の上限を反映し、新入力は公開年齢/10を保持する。誤った矛盾扱いを修正した。以後はprepare-onlyで全19,471競走のD2入力を受け入れた後、同じSHAの派生datasetだけで学習する。馬番/有効頭数は欠番で1超もあり得るため定義通り最大18/8まで認める。

## 固定比較

- H2: 保存済み対照、再学習なし。
- D0: H2の34ペア特徴に6属性のペア平均/絶対差12列。
- D1: D0に旧15特徴の30ペア特徴×連続距離sを追加。s=clip((距離-2000)/1000,-1.2,1.6)。距離帯の教師を分断せず全距離から学習。
- D2: D1に能力/適性9特徴の18ペア特徴×レース条件フラグ3列の相互作用54列を追加。

H2と同じ市場offset/条件季節差分/訓練尺度/共通L2=0.1/差分L2=1。対数損失で学習し順位損失は加えない。最適化250、数値スレッド1、2GiB。

## 選抜・判定

2020〜2022学習→2023開発で4案の対数損失最小、1e-8同値はH2/D0/D1/D2の単純順に1案固定。2024/2025は年次過去教師更新、2026は2025末固定モデルで確認。結果から次点へ選び直さない。既使用の過去であり独立未知テストではない。

H2からの追加有望条件: 確認3年合算損失がH2未満、対応損失改善95%下限>0、各年市場より損失改善、合算的中率がH2未満でない。的中率差区間が正かは別表示。長距離専用優位/利益は今回も証明しない。未達ならH2を保持し、候補を勝手に入れ替えない。最終係数/入力定義/保存後一致/結果遮断/属性結合/時点境界と別式を検証する。
