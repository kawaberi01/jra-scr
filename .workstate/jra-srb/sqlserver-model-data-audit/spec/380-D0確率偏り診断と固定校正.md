# D0確率偏り診断と固定校正

作成日2026-10-25。利用者のD0研究継続指示に基づく新規研究契約。既存D0・旧予想・既定/API/schema/依存を変更しない。対象は保存分布の診断と、D0出力の校正だけ。

## 診断

保存D0の2023〜2026出力と同一競走の市場qを用いる。全体と中山芝1801〜2200mについて、正解確率の対数損失差、的中/不的中別、1位組一致/不一致別、正解p<0.01の競走、損失差の大きい上位10件、1位確率の固定帯(0/.05/.1/.2/.4/1)別の予測平均と実的中を記述する。中山の群は既に確認結果から見つかったものであり、原因診断に使っても当該場だけ校正/除外する候補は作らない。

## 入力・期間

spec365成功runのdatasetと、2023/2024/2025/final2026の保存済み全確率をSHAと競走ID/正解損失/時系列を確認して再利用。D0再学習0、SQL/HTTP0。2023のD0は2020〜2022教師。校正係数の学習は2023-01-01〜08-31のみ、候補選択は2023-09-01〜12-31のみ。2024/2025/2026で校正係数の更新や次点の再選抜をしない。D0本体は既存の年次モデルをそのまま使う。2026は保存済み9/22まで。既使用の過去なので探索的検証で、未知テストと呼ばない。

## 固定候補

同じ全馬連分布p=D0、q=同時点市場を使う。
- K0: pそのまま。
- KT: softmax(t*log(p))、tを[0.7,1.3]の1変数で校正。順位不変。
- KR: softmax(log(q)+a*log(p/q))、aを[0,1]で校正。
- KC: KRのaをD0の最大ペア確率0.2以上/未満の2群で別校正。場/距離/正解は群判定に使わない。校正群が100競走未満ならa=1のまま。
- KM: (1-e)*p+e*q、eを[0,0.5]で校正。半分以上D0を保持する。

校正は既存SciPy minimize_scalar(method=bounded,xatol=1e-8,maxiter=200)を使用、端点とidentityも明示評価し、損失1e-10同値はidentityに近い方。各競走を等重みで正解対数損失を最小化。最大5scalar fit、D0 fit0、校正/選択の入力を分離する。保存後確率も確認。候補選択は9〜12月の対数損失最小、1e-8同値ならK0/KT/KR/KC/KMの順。後年で再選択しない。
