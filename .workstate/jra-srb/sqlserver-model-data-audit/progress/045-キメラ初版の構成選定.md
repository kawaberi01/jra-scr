# キメラ初版の構成選定

作成日: 2026-10-18 JST。利用者の「材料を比較して構成を決める」に基づく設計判断。

## 決定した構成

- A：時計と相手水準を踏まえた過去走能力。
- B：全体ラップ型、その条件下の個体成績、今回の距離/コース/相手構成による適合。
- C：経過日数・近況・条件経験量・欠測等によるA/Bの反映度の制御。
- 最終出力は馬連確率。市場は同時点の比較基準、価格は購入判断として分離する。

時計補正・相手水準・ラップ適性を核に採用。ローテーションは信頼度の制御へ限定。人物別の予想の平均や本人への一致を目指さない。

血統・調教は観測情報を増やす候補として保留。トラックバイアス/個別不利/パドックは観測・時点の裏付けが不足するため初版対象外。条件付き騎手/厩舎の細分化も初版の新規部品にはしない。旧全モデルに未実施だと断言したり、不要と判断したわけではない。

## 今回の根拠確認

- progress044とspec210の10系統比較を参照。RHSPEEDER・夏目公式説明・JRA-VAN対戦型の一次公開資料を再確認。
- 既存ResearchReader/ExperimentMarketReader/HistoryConfigの経路と、現行特徴・馬連推論関数の所在を限定確認。
- 通常研究SQL接続で、カタログ2照会とlive.result_entriesのTOP5を読取。finish_timeはlive/api_runtimeの結果表4か所でnvarchar。少数例は1:12.2等の分秒文字列。全期間の利用可能性は未確認。
- sire_id/dam_id等の完全一致列名は今回の可視カタログに該当なし。別名・JSON・原文の存在を否定する結果ではない。
- データの更新、権限/DDL、管理者接続、新規プログラム、学習、当日予想変更はなし。

## 完了と未完の区別

構成の選定は完了。仕様正本はspec/220-キメラ初版の構成決定.md。実装可否の全期間データ監査、独立評価期間・評価契約、学習器の具体化、実装、性能評価は未実施。

核Aは必要データの監査を通過しなければ実行停止。時計を着順で代用して同じ設計を実行したことにしない。B欠測時のAへの縮約・Cの反映度は実行前に固定する。

比較は本体A+B+Cの1案と対照Aのみ/A+B。市場・元R1と同時点で比較し、精度と購入成績を別判定。最終評価を見て勝った対照へ採用し直したり保留素材を順次追加したりしない。

## 次回着手点と維持事項

1. 時計・条件・馬ID・相手履歴の期間別充足と、既存raw/正規化表との同定・時点を監査する。
2. 実装対象と既存再利用方法、最小テスト・保存検証を具体化する。
3. 更新AGENTSに従い、実装方針の了承後にコードへ反映する。構成選定の依頼は新規実装の承認とは混同しない。

元R1の現行入力校正/価格/時点更新系列は終了のまま。既定スキル・API・既存モデルを維持する。新キメラの精度向上・収益性は未確認。
