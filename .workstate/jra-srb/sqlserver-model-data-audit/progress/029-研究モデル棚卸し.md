# JRA研究モデルの棚卸しと時系列

確認日: 2026-10-17。対象: `D:/develop/jra-scr` の現コード・保存モデル・研究報告、および現行JRA予想スキル。

## 1. この棚卸しの目的と確認範囲

現在使う予想方式、継続したい研究、終了済み研究を利用者が選べるようにする。従来の「全21プロファイルを移行する」範囲は、この一覧を確認してから決め直す。今回、学習・予測・SQL照会・外部競馬データ取得・削除・モデル差替えは行っていない。既存の報告値を転記しており、成績の再計算ではない。

- **研究判定**: 検証条件に合格したか、購入利益を確認できたか。
- **運用方針**: 利用者の予想手順として、何を順位・買い目の基準にするか。
- **実装状態**: APIやCLIが存在するか。記載の入口が今回実行成功したという意味ではない。

この3つを分ける。特にV89/V90は、過去報告が未昇格・不採用でも、現行スキルでは予想の正式運用基準として指定されている。研究判定だけを根拠に、利用者の仮正式運用を取り消した扱いにしない。
