# 過去研究と条件別再評価の再検討

実施日: 2026-10-23 JST。利用者の「過去の研究と合わせてどのような組み合わせで進めるとよいか再検討」に基づく調査・方針案作成。実行案は[spec280](../spec/280-過去研究と条件別再評価の比較方針案.md)。新しい成績計算・学習・SQL/API・本番変更は行っていない。

## 推奨する順序

まずJ23の予測器/元購入規則を変えず、**全体/福島・新潟見送り/小倉だけ/中山秋だけ**の4構成を比較する。次に、過去から局所条件を保持していた**機械学習V110の2000m超**、**S08の内容観測条件**を順に評価する。第1段階4構成＋第2段階2構成、計6構成に限定する案。

第1段階の優先は福島/新潟見送り。062で3年購入不振が続き、小倉/中山秋限定より適用数を広く残せる。これが改善するかの新しい会計比較は今回まだ実施していない。小倉/中山秋の黒字は候補を作る動機であり、採用根拠ではない。

機械学習V110の2000m超は旧開発120.5%/2026探索278%だが高配当依存が強い。S08は内容観測による損失差があった一方、観測切替のROIは73.98%へ低下した。両者は旧非夏季の入力なので、そのまま小倉の夏と組み合わせない。距離/場/季節を最初から重ねた細分化も避ける。

## 併用の扱い

- Q03/Q06は場の選択と同時投入せず、基礎比較が終わってから1要素ずつ追加差を見る。全締切価格欠測や完全な過去月履歴の制約を先に解消する。
- V89/V90、S06ワイド、V94単勝、CatBoost等は券種/役割を分けた参照枠。J23馬連のROIと直接競わせたり、履歴/市場を共有する2票を独立な裏付けと数えない。利用者指定の現行運用は変更しない。
- 旧V88/V89は場限定の先例だが、旧V88は後付けの場除外、V89は標本/季節別適用不足が課題だった。場限定だけで復活と呼ばない。
- C01/C02、旧大量閾値系列、H15/H20等は先行候補へ追加しない。新しい根拠なしに全研究×54区分を再実行しない。
- モデル混合/多数決は後段。J30は既に混合でも採用未達で、保存J23には全ペア分布がない。誤差補完性と同じ馬/時点/券種の確認が先。

## 今回の実ファイル照合

1. J23元runは7,127競走。V110_tickets.jsonには開発1,564/探索1,140、計2,704競走、日付/場/距離/損失/元買い目がある。J23のJVキーを日付・場・R番号で暫定12桁ID化すると重複0、V110との共通IDは2,519。ただしロスター/同時点価格まで照合した受入件数ではない。
2. V110の保存予測gzip先頭行でkeys/probability/projected_return配列schemaを確認。全行の検証やV110確率の互換性はまだ監査していない。
3. S08分解研究run `20261017T091533Z_631037c77cb34fd895c779df1ba77e8d`はhistory/full/no_corner/no_pace/no_closing各1,594競走で、J23との共通race keyは各1,567。保存probabilityは選択ペアのscalar、全ペア分布とT30価格は未保存。ID共通だけで直ちに混合/購入選び直し可能とはしない。
4. 既存報告ではV110/S08等に夏除外・欠測月の偏りがある。入力期間を揃えない既存ROIの横比較はしない。
5. 共通知識の原本自足性要件をNotionで読取確認。適用範囲は原本統合案件で本件の採否とは別。Notion書込なし。
