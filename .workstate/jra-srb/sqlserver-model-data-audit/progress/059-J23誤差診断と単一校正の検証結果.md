# J23誤差診断と単一校正の検証結果

実施日: 2026-10-23 JST。利用者の「では手順を追って進めてください」に基づき、誤差診断と原因に対応する1案の検証を実施。手順はspec260。既使用期間の探索であり、未知データでの改善証明ではない。

## 結論

J23は全体の確率誤差では市場・R1・J01より小さい。追加3特徴が一律に有害という根拠はなく、特徴を外す判断はしない。購入部分の確率過大評価を疑い、市場へ縮約する1係数校正を時系列で試したが、固定選抜ゲートに不合格。候補C01を不採用として停止した。今回は精度改善を達成したとは報告しない。

## 1. 保存済み誤差の診断

対象は元run `20261022T080510Z_b6a4eb0716114496b680ea3378644159`のJ23/R1/M0/J01、30月120セル、同一7,127競走。J01はJ23の基礎12特徴を使い、PL乖離・時計との積・信頼度との積の追加3列を持たない構造上の対照。両者の別々の学習係数も変わるため、追加3列の因果効果を確定した除外実験とは呼ばない。

|---|---:|---:|
| J23 logloss | 3.35459058 | 3.36258422 |
| R1比の相対logloss改善 | 0.2921% | 0.1799% |
| 市場比の相対logloss改善 | 0.4943% | 0.4506% |
| J01比の相対logloss改善 | 0.3679% | 0.3093% |
| J23購入数 | 2,012 | 366 |
| 購入ペアの期待的中/実的中 | 133.93/107 | 23.07/22 |

対市場/J01の対応日bootstrap区間は両期ともJ23改善側。R1比の確認期95%差区間は`[-0.0128013, +0.0000381]`で0をまたぐ。区分探索と既参照期間のため、独立採用の有意性とは扱わない。

ここでの選抜は元研究の24月。055の購入政策比較は先頭3月を係数warmupに使う21月のため、選抜購入数・ROIが異なる。今回の元J23選抜24月ROIは71.14%、以前の21月73.32%と矛盾しない。

### 悪化する条件と限界

- 福島はJ23がR1/市場より悪い向きの点推定が両期で見られるが、探索区間は0をまたぐ。場ごとの除外・閾値変更はしない。確認期だけを見て選ぶ場条件も作らない。
- 頭数8〜11/12〜14/15〜18の全3区分で、J23の対照比平均loglossは両期とも改善側。頭数を一律に制限する根拠は得られない。
- 5〜20%確率の購入ペアは、選抜856購入で期待84.28対実63、確認149購入で14.76対12。ただし購入部分の探索で、全馬連の校正不良を証明しない。確認期の購入全体は23.07対22で、偏りは選抜ほど大きくない。
- 全ペアベクトル、競走ごとの時計信頼度、PL乖離そのものが保存行にない。どの特徴がどの競走の誤差を生んだかは、保存要約だけでは特定できない。

集計前の固定区分は月・競馬場・頭数・J23購入有無、購入確率/オッズ帯。結果を使った区分追加・回収率を見ての購入調整はしていない。source SHA、同一競走/正解/HR/ペア数、行ごとのlogloss/Brier/会計、元phase指標を照合passed。

## 2. 1案の確率校正screening

候補C01: `p_new=(1-alpha)*p_market+alpha*p_J23`。0≤alpha≤1。全競走の混合尤度＋固定弱罰則で、前月までの保存OOSだけからalphaを月次で学習。J23本体の重みは再学習せず、購入条件も変えない。Q03/Q06の購入見送り条件とは別の確率分布全体の補正。

方向診断の点推定は市場へ寄せる向きだが、その区間は両期とも0をまたぎ弱い仮説だった。結果前に1案・調整0・21月の選抜ゲート・不合格時停止を固定し、安価なscreeningだけを行った。

基本モデルrefit0、校正係数fit21、確認6月の新係数fit0/新予測0。学習末尾が対象月より前であることを全fitで照合した。結果を見て罰則や学習窓や採用基準を変えていない。次候補を追加して救済していない。

正解ペア確率から混合loglossは厳密に計算できるが、Brierにはpとqの内積が必要なため未測定。全ペアの選択・回収率も未測定。確認期間を未使用の新期間と呼ばない。

## 次にすること

この校正案はここで終了。元J23、Q03/Q06の扱いは維持し、今回の失敗で元J23自体を破棄しない。

次の研究工程は、保存要約にない「PL乖離・時計信頼度・モデルの市場補正量」を少数の保存済み競走について既存SQL/固定モデルで再構築し、元の予測一致を確かめてから誤差との関係を調べること。対象の事前固定・時間/メモリ上限・再現一致の停止条件を先に具体化する。全900評価・全30仮説の再実行は不要。得られた原因がない状態でさらに混合/閾値候補を増やさない。

別期間での改善確認は、今回候補が選抜を通らず、新期間の時点付き完全入力も不足するため未実施。実開催の参考保存の未実測は058の別トラックとして保持する。
