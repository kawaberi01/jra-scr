# 実装指示

010/020の順序と範囲に従う。既存の券種設定、タイムライン保存、履歴スキップを維持する。既存利用者変更は上書きしない。

起動スクリプトはWindows PowerShell 5.1対応で、標準エラーをPowerShellの停止例外へ変換せず子プロセス終了コードで判定する。子プロセスはHiddenで起動し、起動失敗もUTF-8実行記録へ残す。ロックファイルはDisposeで解放し、削除競合を避けるため残す。

登録スクリプトは既存タスク実行中なら停止せず失敗する。新タスク登録・内容確認後に旧タスクを無効化する。旧タスクXMLのバックアップから戻せる状態を残す。秘密値は保存しない。

過去失敗の原因断定と収集完了の先取り報告は禁止。検証/適用結果と次回確認点をprogressへ記録する。

## 2026-10-24：取得上限修正の実装契約

利用者の修正依頼に基づき、010/020の取得上限改訂を既存の収集・CLI・日次起動へ反映する。上限は当日の予定から計算し、明示上限を超えない。途中打切りと正常完了を区別する。既存保存のスキップ、券種別取得時点、排他、ログ、SQL backend経路を再利用する。テストは疑似サービスと一時DBを使い、provider・業務DBへ試験データを書かない。本日の欠落データを別時点のオッズで埋めない。
