## 4. 注意点
- 南関東のレースIDは16桁で、既存JRAの12桁 `race_id` と混在させない。
- 発売前のオッズURLは404になるため、上流障害ではなく「未提供」と扱う。
- 公式サイトはShift_JISのHTMLを返すため、既存JRA同様に文字コード検出または明示decodeが必要。
- オッズはHTML内にサーバー描画済みで含まれる。ブラウザ実行やログインは前提にしない。
- 2026-07-05時点の調査結果であり、実装時はfixture化して構造変化を検知できるようにする。
