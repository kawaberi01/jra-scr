# 010-jra-win-ev-revalidation 実装仕様書

## 0. 最初に読む要約

- 対象機能: JRA通常戦の単勝EV再検証基盤
- 改修目的: 順位用確率を購入用確率と誤認せず、校正・収益・大穴依存を独立評価する。
- 現行仕様の要点: 未校正のレース内正規化値から最大EV馬を1頭選び、予算全額を推奨している。
- 最重要注意点: 外部評価期間を使った閾値調整は禁止し、昇格条件を満たすまで `shadow_only` を維持する。

## 1. 変更後仕様

### 1.1 運用状態

- 通常戦EV方策に `strategy=history_win_ev` と `ticket_status=shadow_only|recommended` を持たせる。
- 初期状態は必ず `shadow_only` とし、APIの `tickets` は空にする。
- `selection` と候補指標は検証保存用に返してよいが、理由文に「未校正・購入非推奨」を含める。
- `recommended` への変更はコード定数の直接変更ではなく、採用レポートと固定されたpolicy設定の両方が存在する場合だけ許可する。

### 1.2 データ監査

- 対象はJRA通常戦。新馬・メイクデビュー、障害、取消・除外、単勝オッズまたは確定結果欠損レースを別集計または除外する。
- 各レースについて、予測に使用する履歴は対象日より前だけとする。
- 最終単勝オッズを使うバックテストと、ライブ時点オッズを使うシャドー評価を混同しない。
- 監査結果として対象期間、レース数、runner数、オッズ取得率、結果取得率、除外理由件数を保存する。
- 必須項目の取得率が95%未満、または外部評価対象が500レース未満なら採否判定を停止し、データ不足とする。

### 1.3 時系列分割

- race_date昇順で、同一日を分割しない。
- 利用可能期間を次の比率で分割し、実際の境界日をmetadataへ固定する。
  - 学習: 先頭70%
  - 校正・方策選択: 次の15%
  - 外部評価: 最後の15%
- 学習期間だけでモデルを学習する。
- Platt / isotonicの学習と方策選択は校正・方策選択期間だけを使う。
- 外部評価期間は最終候補を1つに固定した後、1回だけ評価する。
- 外部評価結果を見て方策を変えた場合、新しい未使用期間が得られるまで昇格不可とする。

### 1.4 確率候補

次を同一レコードへ保存し、混同しない。

- `raw_win_probability`: ロジスティック回帰の生確率
- `race_normalized_probability`: 生確率をレース内正規化した値
- `platt_probability`: 校正期間だけで学習したPlatt校正値
- `isotonic_probability`: 校正期間だけで学習したisotonic校正値
- `market_probability_raw`: `1 / odds`
- `market_probability_normalized`: 控除率を正規化した市場確率

購入方策候補へ使えるのは、校正期間でBrierとlog lossが生確率以下となり、校正binが成立した確率だけとする。条件を満たす方式がなければ方策は不採用とする。

### 1.5 校正評価

- 全体および次の単勝オッズ帯別に集計する。
  - 2倍未満
  - 2倍以上5倍未満
  - 5倍以上10倍未満
  - 10倍以上20倍未満
  - 20倍以上30倍未満
  - 30倍以上50倍未満
  - 50倍以上
- 指標:
  - Brier score
  - log loss
  - ECE（10bin、等頻度）
  - 予測確率平均と実勝率
  - サンプル数
- 各binまたは各オッズ帯が100 runner未満の場合は参考値とし、採否根拠にしない。
- 市場確率を必須ベースラインとして同じ指標を出す。

### 1.6 方策候補の事前固定グリッド

外部評価前に次の有限グリッドだけを比較する。結果を見て値を追加しない。

- 確率方式: 校正条件を満たした方式のみ
- 最低期待回収倍率: `1.05 / 1.10 / 1.20`
- 最低market edge: `0.02 / 0.03 / 0.05`
- 最大単勝オッズ: `20 / 30 / 50`
- モデル順位上限: `1 / 3 / 5`
- 最低馬履歴出走数: `2 / 5`
- 1レース最大候補: 1頭
- 購入額: 比較中は全候補一律100円。Kelly配分と予算全額配分は禁止する。

### 1.7 方策評価指標

- 対象レース数、候補数、推奨率
- 的中数、的中率、総購入額、総払戻、回収率
- 最大払戻1件除外回収率
- 上位3払戻除外回収率
- 最大払戻1件の総払戻占有率
- 最大ドローダウン
- 最大連敗数
- 平均・中央値オッズ
- 単勝30倍超採用率
- 単勝50倍超採用率
- オッズ帯別候補数・的中率・回収率
- 月別・競馬場別・芝ダート別成績

### 1.8 方策選択順序

校正・方策選択期間では次の辞書順で候補を1つに固定する。

1. 候補数200件以上を満たす
2. 上位3払戻除外回収率が高い
3. 最大払戻1件除外回収率が高い
4. 最大払戻占有率が低い
5. 最大ドローダウンが小さい
6. 全回収率が高い

候補数200件未満の方策は、表面回収率にかかわらず選択しない。

### 1.9 外部評価での昇格条件

固定済み方策が外部評価で次をすべて満たすこと。

- 候補数100件以上
- 全回収率100%以上
- 最大払戻1件除外回収率95%以上
- 上位3払戻除外回収率90%以上
- 最大払戻1件の総払戻占有率25%以下
- 単勝30倍超採用率10%以下
- 単勝50倍超採用率0%
- 20日以上に候補が分散している
- データリーク監査に違反がない

1つでも満たさなければ `shadow_only` を維持する。基準を下げて同じ外部期間で再判定してはならない。

### 1.10 ライブシャドー

- 外部評価合格後も直ちに購入推奨へ昇格しない。
- 30開催日かつ200候補以上を満たすまで、発走前の取得時点、オッズ、候補、理由を保存する。
- 確定後に同じ評価指標を算出する。
- ライブシャドーでも外部評価の昇格条件をすべて満たした場合だけ `recommended` への変更候補とする。
- 最終昇格は採用レポートで明示し、自動昇格しない。

## 4. エラー・停止条件

- オッズまたは結果の取得率不足
- 時系列境界の重複
- 対象日以後の履歴特徴量混入
- 校正対象と外部評価対象の重複
- 外部評価前に候補方策を1つへ固定できない
- 必須指標を算出できない
- 既存の未コミット変更と対象箇所が競合し、意図を確認できない

## 5. 対象外

- ワイド・馬連・三連系の共同確率
- V89/V90系の再検証
- 新馬戦方策の再設計
- Kelly基準や動的資金配分
- 外部評価結果を見た追加チューニング
- 自動購入

## 6. 要確認事項

- 履歴DBで最終単勝オッズを取得できる期間と取得率はPhase 1で確定する。
- ライブ時点オッズの蓄積が200候補に達しない場合、日数だけでシャドーを終了しない。
