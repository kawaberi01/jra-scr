# 直接対決パーツ追加検証仕様

作成日: 2026-11-21。利用者の直接対決パーツ導入・実装・再検証の指示に基づく。対象は福島記念。新仮説を最終2021〜2025年へ適合させない。

## 定義

恒久馬IDと競走キーで、今回の出走馬同士が対象日より前730日以内に同じ芝競走で対戦した記録を抽出する。対象日・同日・未来走は一切使わない。両馬が実出走し有効な着順がある場合だけ比較する。中止等で順位不明、取消/除外は優劣を付けない。同着は引分。

2特徴を1群H「直接対決」として追加する。

| 特徴 | 集計 |
| --- | --- |
| 全芝対戦バランス | 相手ごとの直近1対戦で先着+1/後着-1/同着0を集計。合計正/0/負を先着優勢/均衡/後着多いへ分類。対戦相手なしはNone |
| 近距離対戦バランス | 当該距離±200mの芝競走に限定し、同じ計算。福島芝2000なら芝1800〜2200。対戦なしはNone |

各特徴の直近対戦はそれぞれの対象条件内で選ぶ。全芝の最新がマイルでも、その前の1800〜2200m対戦が近距離側で使われる場合がある。730日・200m・カテゴリ境界は固定し探索しない。特徴の相関と、1対戦でも同じカテゴリになる粗さを限界として明記する。

根拠に相手ID/名前、競走キー、日付、距離、場、両馬着順、斤量・差、経過日数を保存。条件差を隠して同じ能力比較と断定しない。モデル化するのは先着関係のみ。時計差は今回16頭の保存公式時計を比較可能な組の補足にできるが、歴年標準履歴に揃っていないため学習特徴には含めない。公式着差や対戦相手全頭の能力推定は対象外。

## 計算と4固定比較

既存group_deltas、probabilities、metrics、confirmationを再利用。Hも過去の同名福島記念でのカテゴリ好走率から縮約20・同場階層縮約で差分を計算する。条件未観測・対戦なしは差分0。

1. G: 既存一般5群・倍率1のスコア。
2. G+H: Gスコア＋0.5×H差分。
3. N: 既存F3（前走着順・間隔）のスコア。
4. N+H: Nスコア＋0.5×H差分。

Hは確率を単純混合せず、差分を既存スコアへ追加する。対戦なしを一律確率との混合で直接減点しない。全頭のスコアは既存関数で0〜1・合計3へ正規化するため、他馬の評価変更による相対確率の移動は起こる。Hの有無だけを変え、基準の選択をし直さない。Nは既存開発期間で選ばれた近況群を固定する。

2003〜2007の5開催待機、2008〜2020開発13開催、2021〜2025参照済み確認5開催。4方式×18開催=72予測。G+H対G、N+H対Nを個別比較。既存のBrier1%以上改善・logloss非悪化・過半数改善・上位3捕捉非悪化・開催bootstrap上端0未満・一律非劣化を参考基準として判定する。seed240・5000回。参照済み5年なので、基準通過でも探索的改善候補に留め独立確認済みや本採用としない。

年度平均と出走行平均を混同しない。最上位3着内・上位3/6捕捉・欠測/対戦カバー率・開発/確認期間別・年度別悪化を保存する。利益は未検証。
