# 030-南関東結果API追加実装指示書

## 1. 対象概要
- 対象機能: 南関東公式結果API
- 改修目的: 既存 `/nankan` のcard/oddsに、公式結果取得resultを追加する
- この機能が行う処理:
  - `/result/{race_id}.do` を取得する
  - 結果表から着順を抽出する
  - 払戻表から払戻を抽出する
  - `RaceResult` として返す
- 変更してよい範囲:
  - `src/jra_srb/app.py`
  - `src/jra_srb/nankan_provider.py`
  - `src/jra_srb/nankan_service.py`
  - `src/jra_srb/nankan_extractors.py`

  - `tests/test_nankan_service.py`
  - `tests/test_nankan_extractors.py`
  - `tests/fixtures/nankan_result_*.html`
  - `docs/jra/05_API仕様.md`
- 変更してはならない範囲:
  - 既存 `/nankan/.../card`
  - 既存 `/nankan/.../odds`
  - 既存 `/nankankeiba/pattern/...`
  - 既存 `/nar/...`
  - 既存JRA/netkeiba endpoint

## 4. 実装ルール
- 既存の南関card/odds実装を作り直さない。
- 新しい `NankanResultService` は作らない。既存 `NankanService` に追加する。
- `RaceResult` 以外の新規レスポンスモデルは作らない。
- 払戻 `bet_type` は `win`, `place`, `quinella`, `wide`, `exacta`, `trio`, `trifecta` に正規化する。
- `普通馬複` は `quinella`。
- `三連複` は `trio`。
- `三連単` は `trifecta`。
- `馬単` は `exacta`。
- `ワイド` は `wide`。
- `単勝` は `win`。
- `複勝` は `place`。
- 枠複/枠単は初期実装では返さない。
- 組番は `-` 区切りで返す。
- 結果未提供404は `ResourceNotFoundError` に変換する。
- cache keyは `nankan:result:{race_id}` とする。
- cache TTLは3600秒を既定にする。
