# 当日スカウト共通履歴の実行内共有

作成日: 2026-10-18。

## 暫定実装契約

- 対象: JraDayRaceScoutのAPI/保存済みカード経路とscripts/scout_jra_catboost_day.py。
- 変更範囲: 履歴・近走builderへ明示的な実行単位の共有contextを追加。同じ日付・DBに対する過去履歴を1回だけ読み、生涯集計と近走集計を1回だけ構築する。CatBoostの過去dataset生成にも取得済み行を渡す。
- 初回SQL: 過去の結果頭数をwindow集計して、結合で消える着順も近走の分母へ保持する。SQL Serverの対象SELECTだけにHASH JOIN指定を付ける。通常readerを維持する。
- 対象外: sa運用、DBテーブル/索引/統計/権限/設定変更、再学習、R1専用履歴、旧日付固定の保存比較script、プロセス間の永続cache、API再起動・デプロイ・コミット。
- 寿命: 1回のrun/mainだけ。日付やDB不一致は拒否。読み込み失敗は同じrun中に再試行しない。共有するのは履歴データでありconnectionではない。
- 既存挙動: 43/49列・時点・履歴母集団・頭数分母・並び・順位を維持。当日カード/取消/オッズはレースごとの既存経路を維持。
- 検証: 実行内SQL1回・集計1回、異なるrunでの再取得、同日/未来結果除外、NULL着順・未結合着順の頭数、未知馬が共有集計を変更しないこと、失敗時再取得なし、SQL hintの限定、API/CLIの複数レース共有をテストする。通常readerによる実SQLの全行digestと所要時間を有界に確認する。
- 停止条件: 既存特徴量と同値にできない、他セッションの変更と競合する、SQL/モデルの契約変更が必要な場合は依存処理を止めて記録する。
- progress: 本フォルダーへ今回の差分と検証結果を保存。他セッションが更新中の研究002/006は上書きしない。
