# v93〜v102 十世代の開発比較

## 固定条件

- 開発比較期間: 2025-10-01 から 2025-12-31。
- 2024年7〜8月のv90外部評価は、条件調整に使用しない。
- v97〜v102の条件は、評価実行前に [実装契約](v97_v102_implementation_contract.md) として固定した。
- 昇格条件: 買い目20点以上、回収率・最大払戻除外回収率・上位3払戻除外回収率がすべて100%以上。

## 評価結果

- 表面回収率の最高値はv94の470.0%であるが、買い目2点で再現性を判断できない。今回追加した候補だけではv100の313.3%が最高だが、買い目3点にとどまる。
- v96とv97、v99とv102は、この期間ではそれぞれ同一の買い目・払戻になった。下限をさらに緩める、または同距離条件へ調教師条件を重ねても、実際の購入集合を変えられなかった。
- 全10世代で上位3払戻除外回収率が0%であり、上位払戻への依存を解消できなかった。

## 結論

10世代の範囲で、採用可能な最適解は見つからなかった。v100を「表面上の開発期間首位」として選ぶことも可能だが、事前の昇格基準を満たさないため、実運用版・最適版には指定しない。

この先に必要なのは同じ2025年Q4への条件追加ではなく、候補を固定した未使用期間での外部評価である。外部評価でも買い目20点以上かつ3種類の回収率がすべて100%以上になった場合にのみ、初めて採用候補とする。
