# v143 検証方法比較の契約

v143は外部評価で不採用済みであり、ここでは採用可否を覆さない。将来の新理論に使うべき検証方法を決めるため、v143を固定したケーススタディとして扱う。

| 方法 | 検証内容 | 判定観点 |
| --- | --- | --- |
| H1 単発外部 | 2024年7〜8月の未使用期間 | 最終採否に必要だが、1期間では偶然を除けない。 |
| H2 5分割時系列 | 2025年を2か月単位で5回評価 | 各期間の買い目数と払戻依存を確認する。 |
| H3 夏季横断 | 2024年7〜8月と2025年7〜8月を比較 | 夏競馬の再現性を確認する。 |
| H4 再標本化 | H1の47買い目を5,000回ブートストラップ | 回収率の不確実性を確認する。 |
| H5 予測時点監査 | 買い目レースに対する時点付きオッズ保存率 | 確定後情報の混入を判定する。 |

H2の5期間は、2025年1〜2月、3〜4月、5〜6月、7〜8月、9〜10月とする。v143の設計に使った2025年Q4は、H2の評価には使わない。
