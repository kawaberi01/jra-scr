# ペア直接選定・50候補の探索上限結果

## 範囲

- v145〜v154: 初期10候補
- v155〜v194: 事前固定した40候補の格子探索
- 開発期間: 2025年1〜6月
- 詳細な候補定義: [v145〜v154契約](v145_v154_pair_contract.md)、[v155〜v194契約](v155_v194_pair_grid_contract.md)

## 結果

| 指標 | 最良値 | 版 |
| --- | ---: | --- |
| 上位3払戻除外回収率 | 76.4% | v156（軸スコア差2点以上） |
| 最大払戻除外回収率 | 89.3% | v156 |
| 全回収率 | 97.1% | v156 |
| 買い目数 | 140点 | v156 |

v156は十分な買い目数を確保したが、全回収率・払戻依存を除いた回収率がいずれも100%未満である。

## 採否

50候補中、買い目30点以上かつ上位3払戻除外回収率100%以上の候補は0件だった。したがって、2025年7〜10月の検証および2026年1〜4月の最終外部評価へ進める候補はない。

最良候補は140点の母数で基準未達だった。ここで同一の特徴量・同一の払戻条件をさらに調整しても、結果への当てはめが増すだけなので、ペア理論の探索は50候補で終了する。
