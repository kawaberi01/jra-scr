# v103〜v117 暫定実装契約（レース構造選別）

## 対象

- 3着内率の足切りとは別仮説として、レース構造で購入レースを選別する15候補 `v103`〜`v117`。

## 事前固定する候補

| 版 | v90からの変更 |
| --- | --- |
| v103 | 頭数11頭以上 |
| v104 | 頭数14頭以上 |
| v105 | 頭数12頭以下 |
| v106 | 芝のみ |
| v107 | ダートのみ |
| v108 | 中穴単勝オッズ10倍以上 |
| v109 | 中穴単勝オッズ12倍以上 |
| v110 | 中穴単勝オッズ15倍以下 |
| v111 | 軸人気1〜2番人気のみ |
| v112 | 軸人気1〜2番人気かつ中穴4〜5番人気のみ |
| v113 | 7R以降のみ |
| v114 | 6R以前のみ |
| v115 | 14頭以上では中穴単勝オッズ15倍以下 |
| v116 | 14頭以上では中穴単勝オッズ12倍以下 |
| v117 | 1レースあたり中穴相手を1頭まで |

## 対象外

- 軸スコア、夏開催場の範囲、v90〜v102の定義、2024年7〜8月外部評価の結果を見た条件調整。

## 停止条件と採用規則

- 15候補は評価開始後に追加・変更しない。
- 開発期間は2025年Q4、各候補をオフラインで1回だけ評価する。
- 開発比較の優先順位は、上位3払戻除外回収率、最大払戻除外回収率、買い目数、全回収率の順とする。
- 最上位候補でも、買い目20点以上かつ3種類の回収率が全て100%以上でなければ不採用とする。条件を満たす候補だけを、未使用の2024年7〜8月で外部評価する。
