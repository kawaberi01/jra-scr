# v118〜v142 暫定実装契約（5仮説×5候補）

## 対象

- 未知データで再現する中穴ワイド理論の探索として、v90を基準にした25候補 `v118`〜`v142` を事前固定する。

## 仮説と候補

| 仮説 | 版 | 変更 |
| --- | --- | --- |
| 軸オッズ帯 | v118〜v122 | 軸の単勝オッズ帯を、2.5倍以下、2.5〜4倍、6倍超、4倍以下、全帯に分ける。 |
| スコア差 | v123〜v127 | 第1相手に必要な軸とのスコア差を、0、2.5、5、7.5、10点にする。 |
| 馬体重増減 | v128〜v132 | 中穴相手の絶対馬体重増減を、0kg、2kg、4kg、6kg、制限なしにする。 |
| 大頭数の粒度 | v133〜v137 | 14頭以上を前提に、15頭以下、16頭以上、16頭以下、17頭以上、17頭以下に分ける。 |
| 同距離低実績補正 | v138〜v142 | 同距離3着内率15%未満の中穴相手への加点を、0、4、8、12、16点にする。 |

## 固定条件

- 開発比較期間は2025-10-01から2025-12-31。キャッシュ済みデータだけを使用する。
- 軸スコアの基礎重み、夏開催場、払戻計算、v90〜v117の定義は変更しない。
- 評価結果を見て25候補を追加・変更しない。

## 判定規則

- 比較順位は、上位3払戻除外回収率、最大払戻除外回収率、買い目数、全回収率の順とする。
- 買い目20点以上かつ3種類の回収率がすべて100%以上の候補だけを、未使用の2024年7〜8月で外部評価する。
- この条件を満たす候補がなければ、実運用の最適解は「該当なし」とする。
