# v90_summer 3回イテレーション報告

実施日: 2026-07-11

## 目的と固定条件

- 目的: 夏開催群（札幌・函館・福島・新潟・小倉）向けの中穴ワイド候補を作る。
- 開発データ: 2025年の固定 train / validation。
- 評価対象: `2025-10-01..2025-12-31` validation。
- 禁止: 2026年holdoutを使った調整、結果後の追加イテレーション。
- 上限: 3候補（v90, v91, v92）。

## 判定根拠

- v90は表面上のROIが1.00を上回るが、最大払戻を除くと1.00を下回る。
- v90の全払戻は上位3払戻に依存しており、頑健な回収とはいえない。
- v91 / v92は買い目を減らしただけで、精度・回収率とも改善しなかった。
- validationの買い目数が最大9点であり、良化しても採用判断をできる標本数ではない。

## 結論

- `v90_summer` は夏開催向けの紙上運用・データ記録候補として残す。
- v90 / v91 / v92はいずれも検証済みの購入理論としては採用しない。
- 3回上限に達したため、追加の閾値探索は行わない。
- 次の正当な検証は、v90を固定して夏開催の発走前データを保存し、未知の結果が30点以上に達してから行う。
