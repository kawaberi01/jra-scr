# 夏競馬を除く10試行の結果

10方式を検証したが、購入に値する根拠を満たすモデルは0件だった。100%を超えた回収率だけで採用せず、件数・期間別再現性・高配当依存・探索数を考慮して判断した。

ユーザーの追加条件により夏を除外した。範囲確認への回答がない間の既定として6～8月を学習・検証・評価すべてから外した。元データ4400件から856件を除外し、3544件を使用。入力ファイル自体は変更していない。

## 固定した評価方法

- 予測時点: T-30m。T-10mは使用しない。現在レースの結果・払戻は学習ラベルと精算にだけ使う。
- 開発区間: 2024年4～5月472件、2025年1～2月284件、2025年9～12月808件、計1564件。各開始日より前だけで学習。
- 探索評価: 2026年1～3月768件、4～5月372件、計1140件。各期開始前までで再学習する。
- 2026年9月1件は補足のみ。2026年は既使用の探索データで、独立した未使用テストではない。
- 政策: 単勝2～30倍/馬連3～100倍、1レース1点100円。期待倍率閾値1.00/1.10/1.20/1.35と、全体/芝/ダート/距離3帯/人気3帯から選択。10方式×4閾値×9条件の360候補をすべて保存。
- 選択: 開発50点・10開催日以上を優先し、開発ROIの片側95%下限が最大の政策を各方式に固定した。2026年の成績を見て閾値やモデルを変えていない。
- 購入候補ゲート: 開発・評価とも100点/20開催日以上、ROI105%以上、最高払戻3件を除いて100%超、期間別にも必要件数と黒字、開催日bootstrapの探索数を考慮した下側限界100%超。開発の各区間20点、2026年の各区間30点を必要とした。

bootstrapは開催日単位20000回。開発は360候補、探索評価は10方式の数を考慮した保守的な分位点も表示した。これは近似診断であり、データ選択の偏りや過去の研究利用を解消するものではない。

## 見つかった特徴と限界

### 1. 短距離は一部でプラスだが、期間をまたいで安定しない

V92の1400m以下は2026年42点で118.1%。ただし1～3月は38点・130.5%、4～5月は4点・的中0。開発は95.1%だった。高額的中3件を除くと2026年70.0%まで下がる。

### 2. 非線形モデルの芝に傾向があるが、高配当への依存が大きい

V94の固定政策の購入分を後から芝に分けると、開発105点・120.8%、2026年30点・107.3%。ただし2026年の高額的中3件を除くと10.4%になる。これは後から分解した観察で、芝限定の新政策を採用したわけではない。

V94全体でも2026年71点・108.0%だが、1～3月57点・134.6%、4～5月14点・的中0。高額的中3件除去後は34.6%。通常の日bootstrap 95%区間も31.8～200.5%と広い。継続購入の根拠として不足する。

### 3. 馬連の人気上位でも、芝・ダートの優劣が逆転する

V101の馬連1～3番人気は2026年195点・99.4%で、相対的に点数が多い。芝は開発111.0%から2026年80.2%へ、ダートは開発75.3%から2026年116.9%へ逆転した。ダートだけを後から採れば黒字に見えるが、開発で再現していないため採用しない。

### 4. T-30mの割安感が、そのまま確定払戻にはならない

V97の的中券だけで比較すると、確定払戻の合計はT-30mオッズで計算した想定払戻の74.3%だった。V92は83.9%、V94は91.1%。当たった券だけの観察で全馬へ一般化できないが、T-30m価格に基づく期待値をそのまま受け取れない例である。これを学習するV99も試したが、2026年15点・的中0で改善は確認できなかった。

### 5. 大きな支持差の出現頻度が変わる

V93の「芝・期待倍率1.35以上」は開発68点・130.6%だったが、再学習後の2026年では2点しかない。V98も開発77点に対し2026年1点。高い回収率だけでなく、同じ条件が後の期間にも十分現れるかを確認する必要がある。
