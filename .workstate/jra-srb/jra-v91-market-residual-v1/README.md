# V91 学習・評価結果

2024～2026年の採用4,400レースでV系モデルを再構築した。研究候補としてV91Bを選択したが、旧crossに対する優位と利益は確認できていない。稼働モデルの差替えは行っていない。

## 新しい発想

旧basic/crossの独立した馬別二値分類から、同一レースの勝率総和が1になる条件付きsoftmaxへ変更した。

`p_i = softmax(log(O1市場確率_i) + 相対特徴量_i × 係数)`

市場を基準に、説明できる差だけを修正する。履歴はレース内で比較し、履歴件数が少ない馬・騎手・厩舎の効果を弱める。V91Aはこの履歴補正、V91Bはさらに馬連グラフを使う。

V91Bは単勝市場からPlackett-Luce仮定で各馬連の支持を想定し、実際のO2支持との残差を調べる。馬別の周辺支持、どの相手と支持されるか、相手支持の分散を使う。O2は「2着以内の支持」であり単勝支持とは役割が異なるため、単純なO2/O1比から組合せ全体の残差へ拡張した。この仮定が競馬の真の着順生成過程であるとは主張しない。

O2が欠損・不完全ならグラフ特徴量を0にしてO1・履歴で予測する。V91Bの履歴係数はV91Aとは別に学習するので、欠損時にAと完全一致するわけではない。今回の採用データにはT-30m O2欠損がなく、欠損時の精度は未評価。動作のみテストした。

全入力gzipとmanifestのSHA-256、採用件数、採用月別件数、除外JSONL件数と全体除外理由を照合した。学習後の入力SHAも一致。race_id重複0件。出馬表は4,398件で当時未検証、検証済み2件。

主な除外は2024年のanalysisレース欠損1,069件、2025年のO1取得チェックポイント欠損2,243件、2026年の結果・払戻欠損545件など。1レースに複数理由が付くため、理由件数の合計は除外レース数と一致しない。

202608010410の出馬表に馬番「取消」の行がある。T-30m O1に非数値取消表示があるため、その行を予測せず、数値オッズの14頭を対象とした。入力の修正やレース全体の除外は行っていない。判断には結果・runner.statusを使っていない。

履歴生成は対象日全レース作成後に日内結果を反映するコードを確認。予測時にはhistory_as_ofが対象日0時であること、O1と利用するO2の発表時刻がT-30m以前であることを検査した。T-10m、result、払戻、馬体重、結果頭数に依存するfield_size_scaled/horse_no_scaledは特徴量に含めていない。

## 選択と評価

学習2,370件は2025-02-28まで、設定選択808件は2025年9～12月。市場、温度補正、A/BのL2係数0.01/0.1/1を比較し、検証のレース対数損失でB・L2=0.1を選択。2026年や回収率から設定を変更していない。旧モデルを読込評価し、同じ学習期間でbasic/crossを再学習した結果も一致した。

以下は2026年1～6月1,203レースの、2025-02までで固定したモデルの探索評価。対数損失は小さいほどよい。

| モデル | 対数損失 | 予測1位の勝率 | 単勝点数 | 回収率 |
|---|---:|---:|---:|---:|
| O1市場 | 2.02943 | 30.59% | 0 | — |
| 旧basic | 2.02150 | 30.59% | 64 | 113.91% |
| 旧cross | 2.01063 | 31.26% | 468 | 73.80% |
| V91A | 2.02362 | 29.93% | 57 | 84.21% |
| V91B | 2.00890 | 31.67% | 454 | 77.14% |

単勝政策は2～30倍、予測勝率×T-30m単勝オッズ1.05以上、1レース最大1点100円。払戻は確定値で精算。T-30mの価格は最終価格ではない。市場そのものにはこの閾値を超える候補がなく、購入0点となる。

V91Bと旧crossの対数損失差は-0.00173。42開催日を単位とする対応付きbootstrap 1,000回の95%区間は[-0.00860, +0.00612]で、0を含む。旧crossに対する優位は未確認。O1市場との差は-0.02053、区間[-0.03232, -0.00790]だが、既使用の探索データ内の比較である。

2025年検証では旧crossの対数損失2.00259に対してV91Bは2.00566で、旧crossが良かった。V91Bの2025年回収率も88.85%にとどまる。候補間の選択であり、既存を全面的に上回ったとは扱わない。

設定を固定して過去のみで再学習した拡大型評価は、2026年1～3月768件で回収率73.89%、4～6月435件で85.12%。7～9月は19件しかなく、固定モデル8点回収率233.75%、拡大型4点262.5%は成功根拠にしない。

同着がある場合、ラベルを1着馬へ均等配分し対数損失を計算する。そのため旧reportの「1着馬確率の合計」による指標とは一部数値が違う。この表は旧・新を同じ定義で再評価した。

## 成果物

- `V91A.joblib`: 全4,400件で学習したO1・相対履歴モデル。
- `V91B.joblib` / `V91_selected.joblib`: 全4,400件で学習した選択モデル。同じ内容。
- `frozen_selected.joblib` / `frozen_V91A_form.joblib` / `frozen_V91B_graph.joblib`: 2025-02までで学習した過去評価用モデル。
- `refit_basic.joblib` / `refit_cross.joblib`: 旧方式の同期間再学習。
- `frozen_predictions.jsonl.gz`: 検証と2026年の固定モデルの馬別確率。
- `report.json`: 監査、分割、候補、月別・芝ダート、校正、購入明細、拡大型評価、係数、環境、SHA。
- `comparison_statistics.json`: 選択モデルと旧crossの対応付き日単位bootstrap。
- `summary.json`: 主な数値。
- `source/`: 実行した学習・特徴生成・予測コードの保存コピー。

joblibは独自クラスではなく、numpy配列・係数・特徴量契約・メタデータを格納した辞書。予測は`jra_v91_model.forecast(artifact, race)`を使う。

再学習は新しい出力先を指定する。既存成果物ディレクトリには上書きしない。

```powershell
rtk uv run --extra ml python "scripts\evaluate_jra_v91.py" --output-dir ".workstate\jra-srb\jra-v91-next-run"
```

将来のT-30mレースJSON（元データと同じrace/inputs構造、結果不要）を用意し、shadow予測する。

```powershell
rtk uv run --extra ml python "scripts\score_jra_v91.py" --model ".workstate\jra-srb\jra-v91-market-residual-v1\V91_selected.joblib" --race-json "<将来レースのJSONパス>"
```

CLIは学習最終日以前を拒否する。日時・取得証拠付きの入力と出力を今後の発走前に保存し、その後に結果で評価する必要がある。本成果物は既存の出馬表生成APIへ接続しておらず、ライブ入力の生成と予測の永続化は別途必要。

テストは`rtk uv run --extra ml --extra dev pytest -q "tests\test_jra_v91_model.py"`、6件成功。全候補・最終モデルの最適化が収束し、保存後再読込の予測一致も確認した。既存ml extraのnumpy/scipy/sklearn/joblibを使用し、依存追加なし。

確率評価に対数損失を用いる根拠は[scikit-learn公式文書](https://scikit-learn.org/stable/modules/calibration.html)、最適化には[SciPyのL-BFGS-B](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-lbfgsb.html)を利用した。

過去オッズは後日再構成され、多くの発走時刻・出馬表は当時未検証。2026年は既に研究に使用されている。過去評価を実運用実績や独立した未使用テストとは呼ばない。
