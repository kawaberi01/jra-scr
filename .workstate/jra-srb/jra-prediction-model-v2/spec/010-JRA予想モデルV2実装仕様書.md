# 010-JRA予想モデルV2実装仕様書

> 2026-07-11 制約確定: 発走前オッズ・時点データは取得不能のため、初版学習モデルでは市場系特徴量・期待値買い目を使用しない。既存DBを変更せず、過去履歴から1着/3着内を学習する `jra-history-logistic-v1` を先行実装する。以下の市場系仕様は将来取得可能になった場合の別段階とする。

## 0. 最初に読む要約
- 対象機能: JRA予想順位、信頼度、買い目、見送り、バックテスト
- 改修目的: 固定生値加算を、正規化・欠損制御・確率校正・期待値判定へ段階更新する
- 現行仕様の要点: Ω指数、単勝支持、近走時計・上がりを固定加点し、上位軸のワイド2点を常に作る
- 最重要注意点: 結果漏洩を防ぎ、券種オッズ未取得時は期待値を推定せず見送る

## 1. 変更後仕様

### 1.1 入力
- `JraPredictionBundle`
- 予想基準時刻 `as_of`
- モデル設定 `model_version`、特徴量重み、データ品質閾値、購入閾値
- 対象予算

### 1.2 特徴量
- 能力系:
  - Ω指数のレース内percentile
  - 同条件優先の近走時計percentile
  - 同条件優先の上がりpercentile
  - 近5走着順、人気差、通過順から作る安定度・脚質整合度
- 条件系:
  - 芝/ダート、距離差、競馬場一致、馬場一致
  - 2歳、新馬、障害は別セグメントとする
- 人・当日系:
  - 騎手、厩舎、同日先行レース傾向は補正値とし、主スコアを単独で逆転させない
- 市場系:
  - 単勝の暗黙確率を控除率調整後に正規化
  - 能力スコアとは別の `market_score` として保持
- 品質系:
  - 特徴量ごとの欠損フラグ
  - `data_completeness`、`odds_freshness_seconds`、`source_status`

### 1.3 スコアと確率
- `ability_score`: 市場オッズを除く正規化特徴量の重み付き合計
- `market_score`: 単勝暗黙確率
- `combined_score`: 能力と市場の合成。重みは設定ファイルでversion管理する
- レース内softmax等により `win_probability` を出す。
- 十分な学習データがない初期V2では確率を「順位比較用暫定値」と明示し、校正済みと表示しない。
- 学習導入後は日付順validationでisotonicまたはPlatt校正を比較し、Brier scoreが改善した方式だけ採用する。

### 1.4 信頼度と見送り
- `confidence` は以下から `high / medium / low` を決める。
  - 1位と2位のスコア差
  - 上位馬のデータ充足率
  - 市場と能力評価の一致度
  - レース区分の既知/未知
- 以下はいずれかで `no_bet=true` とする。
  - カードまたは単勝が欠損
  - 対象券種の組合せオッズが欠損
  - データ充足率が閾値未満
  - 1位・2位差が閾値未満
  - 期待値が購入閾値未満
  - 未校正モデルで高リスク券種を要求
- `no_bet_reasons` を必ず配列で返す。

### 1.5 買い目
- 順位予想と買い目選択を別処理にする。
- 券種ごとに公式組合せオッズがある場合のみ期待値を計算する。
- `estimated_probability * decimal_odds - 1` を期待収益率の基礎とする。
- 初期V2の購入可能券種は単勝と、組合せオッズ取得済みのワイド/馬連に限定する。
- 1レース上限、1日上限、最低100円、最大点数を設定で制御する。
- Kelly基準は十分な校正後の別段階とし、初期V2では固定小額または比例配分とする。

### 1.6 出力
- `model_version`
- `as_of`、各sourceの取得時刻
- 順位、能力スコア、市場スコア、合成スコア、暫定/校正済み確率
- 特徴量寄与と欠損
- 信頼度、データ品質
- `no_bet`、理由
- 買い目、取得済みオッズ、期待値、金額
- v1互換の `predicted_ranking`、`predicted_top3`、`axis_horse_numbers`

### 1.7 副作用
- v1とv2の予想を別`theory_version`でSQLiteへ保存できる。
- 同一レース・同一as_of・同一versionの重複生成を一意に識別する。
- 特徴量スナップショットとモデル設定hashを予想JSONへ保存する。

### 1.8 異常系
- 公開データ欠損: 予想順位は可能な範囲で返すが購入は見送る。
- オッズ未公開: `no_bet=true`。推測オッズを作らない。
- モデル設定不正: 400相当で失敗し、v1へ黙ってフォールバックしない。
- 未対応レース区分: `unsupported_segment`として見送る。

## 5. エラー / ログ / 設定
- エラー処理: 欠損は状態として返し、設定不正・未対応versionは明示エラー
- ログ: model_version、config_hash、as_of、data_quality、no_bet理由、処理時間
- 設定: JSONで重み・閾値・予算上限をversion管理
- 機密情報: 認証情報を追加しない。匿名公開・JRA公式範囲を維持
