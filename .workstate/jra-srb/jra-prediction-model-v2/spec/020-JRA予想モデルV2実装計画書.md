# 020-JRA予想モデルV2実装計画書

> 2026-07-11 計画更新: 新規1,000R収集を待たず、既存JRA公式4,846RをDB外へ正規化してオッズなし履歴モデル初版を作成する。発走前オッズ・時点データ、期待値買い目は対象外とする。

## 1. 対象と目的
- 対象機能: JRA予想モデルV2と買い目ポリシー
- 改修目的: 順位精度、確率校正、期待値、見送りを独立評価できるようにする
- 対象範囲: 特徴量、正規化ルールモデル、品質判定、買い目判断、shadow運用、時系列評価
- やらないこと: 少数データ学習、有料データ導入、v1削除

## 2. 実装フェーズ

### Phase 1: データ契約と取得品質
- bundle各項目の取得率、時刻、組合せオッズ空応答を監査する。
- 事前スナップショットの継続収集CLIを整備する。

### Phase 2: 特徴量とデータ品質
- race内percentile、条件一致、欠損フラグ、充足率を実装する。
- 特徴量スナップショットを保存する。

### Phase 3: ルールモデルV2
- ability、market、combinedを分離する。
- confidenceとno-betを実装する。

### Phase 4: 買い目ポリシー
- 券種オッズ取得済みの場合だけ期待値を計算する。
- 日次・レース上限と見送りを実装する。

### Phase 5: shadow運用とバックテスト
- v1/v2を同じas_ofで保存し、結果確定後に双方を評価する。
- 日付順walk-forward集計を実装する。

### Phase 6: 学習モデル移行判定
- 1,000Rかつ30開催日以上でのみ候補モデルを学習する。
- rule-v2を時系列validationで上回らない場合は採用しない。
