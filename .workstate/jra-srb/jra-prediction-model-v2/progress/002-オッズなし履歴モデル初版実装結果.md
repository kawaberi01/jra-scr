# オッズなし履歴モデル初版 実装結果

更新: 2026-07-11 22:36 JST

## 実装
- source DBをSQLite `mode=ro`で開き、既存値を変更せず学習用gzip JSONLを生成。
- race_idの競馬場コード、既存surface/distanceを正規化。
- 対象レースより前の履歴だけから、馬・同場・同surface・距離帯・騎手・調教師特徴量を生成。
- 1着、3着内のロジスティック回帰を別々に学習。
- 開催日単位の時系列holdoutで評価し、全履歴で最終artifactを再学習。
- 推論用係数をJSON化し、推論時はscikit-learn不要。

## データ
- JRA公式source限定: 4,846R / 67,039 runner rows / 154日
- 期間: 2024-01-06～2026-07-11
- 特徴量: 43
- オッズ・人気・Ω指数: 不使用
