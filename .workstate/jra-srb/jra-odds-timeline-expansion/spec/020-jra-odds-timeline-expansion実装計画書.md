# 020-jra-odds-timeline-expansion実装計画書

## 1. 対象と目的

- 対象: JRAオッズ履歴CLIと毎週実行スクリプト。
- 目的: 負荷を抑えながら馬連・三連複の全組合せ時系列を保存する。
- 対象外: 予想ロジック、DBスキーマ、既存履歴の再取得。

## 2. 実装フェーズ

1. CLI解析関数と引数を追加する。
2. collectorが時点ごとの対象券種を選べるようにする。
3. PowerShell運用値を更新する。
4. 単体テストを追加し、対象テストを実行する。

## 3. タスク一覧

| ID | 作業内容 | DoD |
| --- | --- | --- |
| 1 | 券種別時点の解析 | 正常・異常入力を決定的に検証できる。 |
| 2 | collectorの時点別絞り込み | 三連複が30分前に取得されない。 |
| 3 | 運用スクリプト更新 | 次回タスクが4券種・所定時点・432上限で起動する。 |
| 4 | テストと自己レビュー | 変更範囲のテストが通り、差分に余計な変更がない。 |

## 4. 完了判定

- 次回のスケジュール実行に必要な引数がスクリプトへ固定されている。
- 既存のCLI呼び出しが引数省略時に同じ挙動を保つ。
- 自動テストで券種別時点の呼び出し順が確認できる。
