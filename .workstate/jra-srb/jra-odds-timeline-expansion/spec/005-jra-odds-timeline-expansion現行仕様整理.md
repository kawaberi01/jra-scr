# 005-jra-odds-timeline-expansion現行仕様整理

## 現行の収集フロー

1. `collect-jra-odds-timeline` は全開催・全レースについて、指定した共通の発走前時点を時系列タスクへ展開する。
2. 各時点で出馬表を更新し、指定された全券種のオッズを取得してSQLiteへ保存する。
3. CLI既定は `win,wide`、時点は `30,10,2` 分前である。
4. 毎週土日9時のWindowsタスクは同CLIを呼び、最大216ライブリクエストで停止する。

## 保存範囲

- ワイドは上位のみではなく、APIが返す全組合せを `odds_entries` へ保存する。
- 2026-07-18の確認では、8〜16頭立てで1時点28〜120組を保存し、単勝頭数から算出した全組合せ数と一致した。
- `SUPPORTED_JRA_BET_TYPES` には既に `quinella` と `trio` が含まれるため、取得・保存の券種実装は既存流用できる。

## 現行の制約

- `--offset-minutes` は全券種に共通であり、三連複だけを10・2分前に制限できない。
- 現行の最大216リクエストは、36レース・3時点・card+単勝+ワイドの理論最大324リクエストを下回る。
