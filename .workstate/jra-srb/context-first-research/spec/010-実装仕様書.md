# エリザベス女王杯の条件集計予想ツール実装仕様

作成日: 2026-11-08。初版v1。利用者の「実装仕様をまず書いてから実装」の指示により仕様保存後に実装する。既知条件の研究用実装で、本番モデル採用ではない。

## 入出力と責務

- `configs/research/race_conditions_elizabeth_v1.json`: 対象名、固定source31、期間2003〜2025、比較開始は過去5開催以上、縮約強度20、5グループの既知条件、query上限、設定版。成績による閾値調整をしない。
- 純計算モジュール、読取reader、出力とCLIを追加。SQL exportと保存入力によるoffline analyze、将来カードのpredictを分離する。
- 出力: dataset.json（必要な解析済み対象行と該当馬の過去履歴のみ、raw本文・接続情報なし）、coverage.json、conditions.csv、comparisons.csv、predictions.json、metrics.json、report.md、manifest.json。設定・入力・コードSHAと作成時刻を保持する。
- 既存出力フォルダーは上書きしない。失敗はfailure.jsonとfailed manifestを残す。自動再試行・SQL書込・外部取得・API起動・既定置換・購入はしない。

## データの取得と境界

研究readerの接続を再利用し、DB名・過大roleなし・必要表のSELECTと更新権限なし・source31 verifiedを確認。競走は名称だけで候補抽出後、日付/場所/距離/トラックと一意キーを検証する。出走馬は保存済み競走hashと競走キーの同値で結合する。

対象馬IDの履歴だけをhistory.entries/history.racesから上限付きで一括取得する。必要RAは競走キーと対応年のverified snapshotを指定して500キー以下ずつ取得。通常全件走査・SE全件取得はしない。履歴上限20000行、RA候補上限20000行、query30秒。超過・競合・破損は停止する。馬ID不明、重複馬番、日付不整合も停止。

RA表には競走キー索引がなく、実DBでLOB列のIN比較と型付き集合の結合が停止した。既存の一意索引(snapshot,rowid)を利用する。年snapshotごとのRAについてキーとrowidだけの小台帳を取得し、必要キーをメモリで選び、選択rowidだけで原文を索引取得する。各年10000行・合計100000行の台帳上限、原文20000行上限を設け、SE原文や全masterを走査しない。原文はfixed binaryで投影し、元DATALENGTH=1272とSHAを照合。台帳の完全キー長と返却キーの一致を検査する。既存索引・DBの変更はしない。

馬ID履歴もLOBのIN比較では実DBで30秒に達するため、nvarchar(10)の型付き馬ID集合とのHASH JOINを使う。元の馬IDが要求集合にあることを返却後に照合する。競走の結合は保存SHAと固定長キーを併用する。

RAはSDKに従いgrade[614:615]、種別[616:618]、記号[618:621]、重量[621:622]、条件[634:637]、距離[697:701]、トラック[705:707]、天候[887:888]、芝馬場[888:889]、ダート馬場[889:890]を読む。ASCII codeは未検証の意味へ翻訳しない。既存metadataの距離・トラックと一致を照合。原文の作成日・区分最大版を選び、同順位の異なるSHAは停止。欠損RAは欠損として保持し推測しない。

当該レース結果と過去履歴を別に保持し、特徴生成は対象日より前の履歴だけを使う。同日履歴は除外。取消/除外（abnormal_code 1/2）は非出走として一覧に残し予測から除外、それ以外の実出走異常は順位欠損を不成功として記録。実rank<=3の頭数が3でない競走は記述表に残し確率評価から除外。これらのcode意味は既存SE SDKの異常区分との照合も行う。

過去カードは事後の出走集合・属性であるためhistorical_retrospectiveを明記し、厳密な事前再現や未知期間の独立実証と称しない。地方・海外・保存開始前の未収録履歴はunknown。最新前走であることの独立証明は初版ではなく、前走は「DB内の直近確認走」と表示する。

## 固定の既知特徴とグループ

| グループ | 特徴 |
|---|---|
| 基本属性 | 年齢3/4/5/6以上、枠1〜3/4〜6/7〜8 |
| 前哨戦経路 | DB内直近走の競走名、gradeコード、重量方式コード、牝馬等を含む競走記号コード |
| 直近成績と間隔 | 直近走順位1〜3/4〜5/6以下、間隔28日以下/29〜56日/57日以上 |
| 条件変更 | 直近距離1800以下/1801〜2000/2001〜2200/2201以上、延長/同距離/短縮、実斤量増/同/減 |
| 過去実績 | 同名レース3着以内、同場同芝ダ同距離3着以内、grade A/B/Cの3着以内の各経験 |

履歴0件なら履歴由来値はunknown。国内保存履歴に該当好走なしは「確認なし」であり、不適性や全世界での未経験を意味しない。騎手・調教師・天候馬場・開催資格は一覧/監査に保持するが初版の独立加点には使用しない。各年の共通属性は個体差として加点しない。前哨戦の改称を推測で同一視しない。京都と阪神は別scopeとして傾向を示し、確率推定では後述の縮約で共有する。

## 集計と予想算式

主評価は各馬の3着以内。勝率・馬連・購入利益は算出しない。過去条件の全該当/非該当出走数、3着以内数、開催年数、年別結果を残す。

予測日より前の同名競走だけを集計。基準率bは過去の3着以内数/出走数。特徴値vの全場事後率g=(成功数+20b)/(件数+20)、同じ開催場の率p=(同場成功数+20g)/(同場件数+20)。基準の同場率もbへ20件縮約し、logit(p)-logit(同場基準率)を根拠差分にする。カテゴリが過去に一度もない値、unknownは差分0。グループ内は既知カテゴリの差分の平均、5グループは等重みで平均する。重み探索はしない。

各馬のスコア=logit(3/頭数)+平均差分。共通切片を二分法で求め、sigmoid(スコア+切片)の合計を3に合わせる。これは同時確率や検証済み校正を意味せず「未校正の推定3着内確率」と表示する。未知だけなら一律3/頭数へ戻る。頭数4〜18を許可し、tieは馬番順で表示するが同確率の優劣とは説明しない。

表示する根拠はグループを一つ無効化し確率を再計算した差（パーセントポイント）を大きい順に最大3件。これは条件付きのモデル感度であり因果効果ではなく、足して全差分になるとは限らない。根拠には該当件数/年数/好走率とunknown数を添える。

## 過去年の評価

過去5開催を満たす年から順次評価する。全体、京都、阪神、年別の件数、Brier、二値logloss、上位1頭の3着以内的中率、上位3頭の好走馬捕捉数を集計する。基準は同じ出走集合の一律3/n。5グループを一つずつ外す比較も全て保存し、良いものだけを最終方式に選ばない。比較結果は研究用の記述として報告し、統計的な優位・収益保証を主張しない。

## 将来カード入力

JSONにrace_key/race_date/race_name/venue_code/distance/track_code、timezone付きobserved_at/start_at、出走馬ID・馬名・馬番・年齢・枠・性別・斤量・statusを要求。最終着順等は許可しない。observed_at<start_at、競走日とキー一致、対象名称、全活動馬の一意IDを検証。latest_race_dateを任意で受け、DB内直近走と不一致ならfreshness未達とする。追加馬IDはexport時にcardから読み込める。

将来出力は履歴最新性・当日カード公表時点・履歴未収録が完全でない限りreference_only。実用可を自動付与しない。2026年の実際の馬を仮定して捏造した予想は作らない。

カード観測日より後の履歴・同名競走の結果も遮断する。発走日より前という条件だけで観測後の結果を使わない。初版は観測当日の走りも保守的に除外する。

## 検証項目

結果・未来履歴を変えても事前特徴/予想が変わらないこと、過去5年境界、unknown/未観測、開催場縮約、確率範囲と総和、取消・同着、出走ID重複、RA破損/版衝突、保存SHA/再読込、非該当・年別件数一致、既存出力拒否、秘密非表示を検査。実DBは固定版の限定export/analyzeを実行し、独立集計で主要件数とBrierを再計算する。
