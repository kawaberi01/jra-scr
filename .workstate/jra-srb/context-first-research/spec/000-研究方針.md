# 既知の特徴によるエリザベス女王杯の予想研究

作成日: 2026-11-08。対象worktree: `D:/develop/jra-scr-new-prediction-model`。ブランチ: `research/new-prediction-model`。方針の正本。

## 利用者が了承した方向

- 主軸は同じ重賞の年次履歴。初期対象はエリザベス女王杯で、2026-11-15の開催に合わせる。
- 既知の一般的な特徴を使い、各年の競走条件・全出走馬の事前履歴・結果を対応させる。好走馬だけでなく、該当して負けた馬・非該当馬を残す。
- 新しい特徴の自動発見や多数パーツの追加は後回し。予想家の予想を模倣せず、当人の当たり外れ推定は将来の追加候補。
- 現段階は条件別集計・比較・適用を中心とし、繰り返し機械学習するモデルを前提にしない。集計の更新とモデルの再学習を区別する。
- 何を根拠に評価が変わったかを説明できるようにする。説明を予測後の作文だけにしない。

## 初期の比較項目

| 役割 | 比較する材料 | 扱い |
|---|---|---|
| 比較する年の適合 | 競走名、開催場、芝ダート、距離・内外回り、日程、牝馬限定・年齢資格、格、重量方式 | 京都・阪神等の代替開催や制度変更を識別。全馬共通条件を個体の優劣と混同しない |
| 馬の基本属性 | 年齢、性別、枠・馬番、実斤量、頭数 | 列の存在・非空と意味の正しさを分けて確認 |
| 出走経路 | 前走名・格・距離・着順・着差、出走間隔、距離変更、前走の牝馬限定/混合や重量方式 | 各対象競走の発走前に確定した履歴だけ使用。前走項目の収録と公表時点は未監査 |
| 実績 | 以前の同レース、距離・コース、重賞での実績 | 対象日より前の実績に限定。履歴不足を不適性と扱わない |
| 保存確認済みの補助属性 | 騎手、調教師 | 初期の表示・監査に保持するが、独立加点する算式は未確定 |

初期の主軸を作るための項目であり、全項目を独立パーツとして実装する契約ではない。定量・牝馬限定は比較する年の選定や前走との差を評価する材料。

## 最初の成果物と検証順

1. 各年の競走条件と全出走馬・前走履歴の対応表、項目別欠損表を作る。既存DBを読取専用で調べ、未収録の過去履歴を無断で外部再取得しない。
2. 条件定義、対象年、京都と阪神の扱い、主評価事象、評価不能時の扱いを結果による選別前に固定する。
3. 年別の条件該当馬・非該当馬・着順を一覧化する。探索用の記述統計と、実際に予想へ使う規則を分ける。
4. 少数の既知条件を使った主軸予想の算出方法を具体化し、実装前に対象・既存処理の再利用・出力・検証を提示して了承を得る。既知の条件でも組合せや重みを過去結果で選んだ場合は選択として記録する。
5. 過去年までの情報だけで翌年を評価する時系列比較を行い、年別・合算・件数・対象率を報告する。既に参照済みの年を未知テストと呼ばない。
6. 2026年は規則固定後、入力と判断時刻を発走前に保存する。最終出走馬・取消等の変化を反映して版管理し、確定後に保存予想と比較する。自動実行・購入・スケジュール登録は含まない。

## 表示の案

結論、使った条件、条件が評価へ与えた影響、反対材料、判断不能を表示。詳細では年別の該当・非該当全出走馬を確認できる構成。主軸一つと影響の大きい補助三つまでを表に出す案で、表示上限は未確定。単純な該当数を勝率と呼ばない。
