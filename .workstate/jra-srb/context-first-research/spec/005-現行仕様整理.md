# 現行仕様と再利用箇所

作成日: 2026-11-08。今回の実装対象はこのworktreeのみ。

- Pythonパッケージは `src/jra_srb`、実行入口は `scripts`、pytestは `tests`。mssql-pythonは既存依存。新規MLライブラリを必要としない。
- `jra_research_reader.ResearchReader` は研究専用設定、SELECT限定cursor、秘密を含まない例外・query診断を提供する。ここを継承して対象を固定したreaderを追加する。
- `jra_research_contracts` のResearchError、digest、timestampを再利用する。API writer、通常モデル、取得スケジュールには接続しない。
- 固定history snapshot31はverifiedの `prediction-full-20261008`。対象23競走・392行と事後属性を確認済み。前走を含む履歴は同snapshotの馬IDと競走キーで結合する。
- 競走JSONの属性は限定的。grade/種別/記号/重量方式/天候馬場は必要な競走の保存RA原文だけを追加参照する。SDKのJV_RA_RACE/RACE_JYOKENのbyte位置を確認。RA長1272、競走識別、SHA、版競合を検証し、原文は出力しない。
- 既存RunArtifactsは出力名と予想形式が別研究に固定されるため変更しない。新CLIが指定された未使用出力フォルダーに今回の比較表・JSON・Markdownを保存する。
- 旧raw解析は異常馬一頭や同着で全競走を除外する実装もある。今回その関数を流用せず、取消等は馬単位で記録、実出走の異常完走・同着の扱いを明示する。
- 当日予想の既存factory・モデル登録・HTTP/APIは変更しない。初版の将来予想は明示JSONカードを入力し、IDと履歴の充足を検査する。
