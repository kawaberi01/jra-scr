# 三重賞の共通パターン検証

作成日: 2026-11-14。利用者は武蔵野S・デイリー杯2歳Sを研究題材へ追加し、汎用パターン探索を指示。既存の仕様先行・追加許可不要の指示に従い実施する。

## 対象と既存制約

- エリザベス女王杯、武蔵野ステークス、デイリー杯2歳ステークス。2026公式日程では本日東京11R武蔵野GⅢダ1600、京都11Rデイリー杯GⅡ芝1600。
- snapshot31の2003〜2025を使用し、2026の結果を探索へ含めない。DBで追加2系列各23開催を確認。武蔵野の冠名変更を明示別名に持つ。デイリー杯クイーンC25開催は別競走のため除外。
- 旧validate_raceはエリザベス/芝2200/牝馬3歳以上限定。その検査を緩めず、別の研究module/CLIで2歳・牡牝・ダートを扱う。既存make_features、条件率、確率合計3、指標、縮約20等を再利用する。
- 同場距離実績は芝/ダートを一致させる。旧実装の芝前提をダートへ転用しない。2歳戦の年齢や同名前年実績など、識別力のない項目も可視化する。

## 固定する候補と基準

5群をA基本属性/B前走経路/C直近成績・間隔/D条件変更/E過去実績とし、以下4候補を全結果比較前に固定する。

| ID | 使用群 | 方針 |
| --- | --- | --- |
| route | B+C | 前走・ローテ |
| aptitude | D+E | 適性・実績 |
| attributes | A+C+D | 属性・近況 |
| balanced | A+B+C+D+E | 総合 |

各候補は採用群内の等配分（使用群数で正規化）、倍率1・縮約20・開催場共有方式は従来どおり。以前の32構成は分母5固定なので、今回の少数群候補とは同じ式ではないことを表示する。

一律3/頭数と、凍結v2（全5群、格別実績、倍率4、v1±5pt）を比較用に追加。v2はエリザベス過去を参照して発見した設定であり、全系列で独立未知検証と呼ばない。倍率等の交差探索は今回しない。

## 検証の順序

1. 各系列の同名競走で、過去5開催を待機して翌年を予測する。全頭・不成功・非該当を保持し、対象結果を特徴に使わない。過去属性/実出走集合の事後版という制約は維持。
2. 同じ比較年について4候補/一律/v2を保存。主指標Brier、副指標logloss・最上位3着内・上位3頭捕捉。同確率は期待値。
3. 系列間の頭数差に対処し、系列ごとの一律比Brier改善率を系列均等で平均して候補を選ぶ。生のBrierを頭数の異なる系列で単純平均して首位を決めない。
4. 過去の検証5年が揃った年から、(a)系列別選択、(b)全3系列共通選択、(c)対象系列以外の2系列だけで選択、を比較。選択に使うのは評価年より前の暦年に限定。同日/同年の別重賞結果も使わない。
5. 時系列選択と固定総合/一律/v2を同じ評価年で比較する。開催年をブロックにした参考bootstrap5000回、seed20261114を保存。探索値と選択後成績を分ける。
6. 4候補の3系列での非劣解を最大3本まで候補一覧に残す。ただし3系列だけで普遍性を認定しない。共通優位の暫定条件は全3系列で一律より平均Brier改善、外部系列選択の系列均等改善率が正、参考区間下端が正。未達なら共通優位未確認と報告し、条件を緩めない。

## 実装対象・取得・検証

- 新規: configs/research/graded_common_patterns_v1.json、src/jra_srb/jra_graded_patterns.py、scripts/run_jra_graded_patterns.py、対応テスト・独立照合・レポート。
- 既存ConditionsReaderのSELECT専用preflight/target_entries/RA原文確認を再利用。無索引のhorse+races同時結合は既知失敗なので繰り返さない。今回はhorse IDによるentries単独の有界選択後、競走hash索引でmetadataを別取得する。
- 最大履歴20000行・race metadata5000件・対象50件/系列・RA metadata100000行。超過・ID/日付/コード矛盾・版競合は失敗証跡を残して停止。接続・権限・例外の秘密を出さない。
- 初回取得では対象馬の生涯後半まで含めた競走数がmetadata上限を超えたため、依存するmetadata取得を停止。再開では各馬が対象同名競走へ最後に出た日より前の履歴だけに絞る。特に2歳戦後の成馬キャリアを不要に取得・評価しない。上限は引き上げない。
- テスト: 2歳/牡牝/ダート、芝ダートの実績分離、系列別結合、暦年境界、他系列だけの選択、元のv1互換、未来結果変更の非影響、確率合計、再処理の入力SHA。
- 成果物: 3系列の年別比較、全馬値、選択履歴、データ充足/未知/特徴の識別力、代表候補、独立検算と進捗。今回の目的は汎用候補比較で、当日買い目や既定モデル切替ではない。
