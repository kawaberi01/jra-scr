# 条件群合成の外れ値耐性という追加仮説

作成日: 2026-11-13。050/060では強度増加に平均改善がある一方、13開催の差区間は0を含む。H11では一つの極端な条件群が全体を引っ張る可能性を調べる。結果確認前に下記を固定する。

- 入力は050で保存した縮約20・無減衰・同場階層化の5群差分。新特徴なし。
- 通常の5群平均に代えて、中央値、最大最小を除く中央3群平均の2方式。
- 各方式の倍率は既に比較した1/2/4。各々に変動制限なし/旧方式比±0.05の2通りを適用。新12候補と旧全群の計13。
- 過去の検証5開催以上のBrierだけで翌年候補を選ぶ。2013〜2025の13開催で旧方式と比較。4採用条件は050から維持。全候補の同期間首位と過去年選択の成績を区別。
- 既使用過去から提案した追加探索であり、合格でも未知試験・市場・収益の証明ではない。段階050/060と合わせた多重探索を隠さない。結果に合わせ中央値・切捨て数・倍率・制限幅を細かく変えない。
- 保存根拠/候補/年度指標をSHA検証して再利用する独立CLIを追加し、全予測・指標・選択根拠・bootstrap・採否を保存。中央値/中央平均、cap合計3、未来遮断と独立検算を実施する。通常予想・DB・既定モデルは変更しない。
