# 重賞別独立研究と平場分離方針

作成日: 2026-11-20。利用者指示による研究方針。コード実装前の研究計画で、改善結果ではない。

## 方針と対象

- 重賞は同名競走の歴史から固有パーツとその組み合わせを個別に検証する。一般的な能力・類似条件の評価は補助とする。固有情報が不足・不安定なら根拠の強い一般評価へ縮約する。根拠の薄い固有条件を無条件に高く重み付けしない。
- 平場の共通条件研究は別トラック。今回の二重賞から平場での有効性を主張しない。平場用の条件・評価は別途仕様化する。
- 終了3重賞はarchive/2026へ回顧と次年課題を保存し凍結。spec220の能力評価優先・未使用他重賞を主にする案は、本方針で優先順を置き換える。時点管理・独立評価・一般能力比較の注意は継承する。
- 今回の2研究は、候補設定、年度分割、組み合わせ選択、採否、結果を別管理する。一方の最良重みを他方へ自動転用しない。

マイルCS候補: 秋の前哨戦経路と成績、春秋のマイル重賞実績、1400/1600/1800m等の距離経路、京都外回り経験、休養・叩き。外国馬の海外履歴欠測を国内実績なしにしない。阪神代替開催は京都と区別する。

上記は仮説候補であり未検証。公式の記事は候補発見に利用できるが、同じ過去年を見て作られた記事を独立な証明と扱わない。騎手・厩舎等の小標本条件を初めから大量追加しない。

## 検証手順・成果物

1. 各同名競走のDB収録年、全頭履歴、代替開催、欠測、資料公開時点を監査。今回まだDB監査は未実施。
2. 使えるパーツの定義・少数の組み合わせ候補・待機年数・年度分割・採否基準を各研究の仕様に固定してから実装する。件数未確認のため、この段階で試行数や閾値を捏造しない。
3. 過去年だけで候補を選び、後続年へ適用する。同名競走内でも探索と評価を分ける。試行履歴を残し、反復参照した過去を未知検証と呼ばない。2026本番は事前凍結後の追跡対象にする。
4. 比較は一般評価のみ／固有パーツのみ／固有主軸＋一般補助。既存v2は比較基準として残す。市場は別の基準・追加比較とし、市場の効果を固有パーツの成果と混同しない。
5. Brier・logloss・上位1/3/6頭の捕捉、年度別安定性、各パーツ除去比較を評価。小標本・1回の高配当依存を明記し、精度と利益を分ける。実オッズのない券種で期待回収を断言しない。
6. 採用候補、見送り理由、各馬への根拠を固定形式で保存。合格する組み合わせがなければ「専用方式の優位未確認」と結論する。無理に最良案を採用しない。

予定成果物: 各研究の収録監査、実装仕様・計画、全候補と時系列比較、採否理由、発走前の全頭評価・市場比較・仮想買い目、確定後の回顧。

## 再利用と影響範囲

既存SELECT reader、原本根拠/SHA保存、特徴集計、時系列評価、説明出力を再利用できるか確認する。既存elizabeth限定validatorを無条件に緩めず、対象固有条件を分離する。新たな計算・設定・入口を実装する前に具体的変更範囲を提示する。現時点ではコード・DB・スキル・既定モデルの変更なし。
