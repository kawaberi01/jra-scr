# 既知条件の継続仮説・固定比較

作成日: 2026-11-13。利用者は一定の結果まで仮説と検証を継続し、追加許可は不要と明示。付帯情報取得は別作業。spec040の全32構成は完了したため、次の仮説を実装前に固定する。

## 判定基準と範囲

主評価は3着以内の出走行数加重Brier。各年の候補選択は以前の検証5開催以上だけを用い、2013〜2025の13開催で旧全5群固定・一律と比較する。候補の同値は1e-12以内、少数群、固定候補順。loglossと順位指標も全て報告する。

「有望な研究候補」の今回の事前基準は、(1)旧全群よりBrierが相対1%以上改善、(2)開催paired bootstrap5000回・seed20261113の差区間上端が0未満、(3)loglossが旧全群以下、(4)同じ外側対象年の過半数でBrier改善。市場・未知期間・利益の証明とは呼ばない。後ろ向きデータを再利用した仮説であり、この基準通過も本番昇格ではない。

## 固定する6仮説群・69候補

| 群 | 仮説 | 候補 |
|---|---|---|
| H1 | 評価差が小さすぎる/過大かもしれない | 全5群の差分倍率0（一律）/0.5/1（旧方式）/2/4/8の6候補 |
| H2 | パーツ除去と強度低下を分離する必要がある | 全群/空集合を除く30部分集合を、採用群数で平均。全体強度1 |
| H3 | 条件群の等配分が不適切 | 各1群を2、他を1として総和を1へ正規化する5配分と、基本0.5/経路2/直近2/変更0.5/実績1の1配分。それぞれ倍率1/2/4、計18 |
| H4 | 一律20件の縮約が不適切 | 縮約5/80、それぞれ倍率1/2/4、計6 |
| H5 | 古い年の影響が強すぎる | 開催年差の半減期5/10年（重み2^(-年差/半減期)）、倍率1/2/4、計6 |
| H6 | 同場集計の少数性が害になる可能性 | 同名競走の全場だけの率、倍率1/2/4、計3 |

候補数6+30+18+6+6+3=69。既知結果で有望に見えた経路/直近/実績を重視する配分は既知期間からの提案で、その事実を明記する。調整結果を見て候補や区切りを追加しない。6群同士の全交差は今回実施しない。

## 算式と時点

基礎は初版の特徴と式。半減期なしは各過去出走の重み1。半減期ありは競走年差から同じ開催の全馬に同重みを与え、基準率・カテゴリ率・同場率の全ての分子分母に同じ重みを使う。縮約は固定仮想件数。全場のみではカテゴリ全場率を使い基準も全場率。未知カテゴリは中立。倍率は群差分合成後に掛け、同じ切片調整で合計3にする。

特徴と集計は当該より以前の結果だけ。選択は当該より以前の検証損失だけ。各仮説群の個別時系列選択と、69候補全体からの時系列選択を両方保存する。仮説群単体の全期間首位を未知性能と呼ばない。最終保存候補は全検証18開催で選んだ参考設定であり同期間成績は探索値。
