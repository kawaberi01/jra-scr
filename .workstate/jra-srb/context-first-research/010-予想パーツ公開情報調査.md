# 競馬予想に使われる情報と分析パーツの公開情報調査

調査日: 2026-11-08。対象: JRAを中心とする予想家本人の公開記事、JRA、JRA-VANとTARGET、JRDB、netkeibaの公式説明。

同名重賞の年次履歴を研究の主軸とし、血統・騎手・厩舎・コース・仕上がり等を補助部品として蓄えるための候補一覧。公開資料から利用の実例を確認したもので、各部品の将来の有効性や収益性を検証した結果ではない。非公開・有料本文の内容を推定せず、公開範囲に限定する。全予想家の網羅や利用頻度の順位を示すものではない。

「3区の馬」は産駒、「不対情報」は付帯情報として解釈した。血統の系譜と、本番に至る前哨戦・ローテーションの経路を区別する。

## 今回特に重要な条件の組合せ

公開実例を確認できた組合せは、父×母父、種牡馬×ペース、騎手×コース、騎手×馬主、騎手×厩舎、ローテーション×血統、血統×レースのラップや枠、当日の馬場×騎手の戦法など。これらは複数の独立票ではなく、条件によって部品の意味が変わる関係として扱う。

本案件への応用候補は次の通り。組合せ自体の有効性は未検証であり、実装仕様として確定していない。

| 問い | 必要な部品 | 比較上の要点 |
|---|---|---|
| この産駒はこの重賞で強いか | 同名競走、血統、全出走馬、当時の実績・人気 | 好走馬中の比率だけでなく、該当馬全体の好走率と非該当馬を比較。父系全体の供給頭数も考慮 |
| この騎手はこの重賞で強いか | 同名競走、騎手、馬の能力、人気、継続騎乗 | 強い馬への騎乗機会と騎手固有の差を区別。繰り返し出走する同馬の影響も表示 |
| 例年の前哨戦経路を今年も重視できるか | 前哨戦、間隔、距離実績、今年の馬場・展開 | 日程・施行場・距離・出走資格変更を確認。レース名だけで同条件としない |
| 短縮で走る血統か | 血統、前走距離、今回距離、前走内容 | 芝ダート・クラス・馬齢等の構成差を考慮して検証 |
| 休み明けでも走る仕上がりか | 厩舎、外厩、帰厩日、調教過程、過去実績 | 外厩未収録を未利用と扱わない。休養期間と帰厩後日数を区別 |
| 前走不利だった馬を今回上げるか | 映像評価、馬場偏り、枠、想定位置、相手 | 不利の大きさだけでなく、今回その課題が再発する可能性も扱う |

## データ化に向けた区分

| 区分 | 例 | 判断 |
|---|---|---|
| 成績等から構成するもの | 前哨戦、距離、血統ID、騎手、斤量、間隔、過去体重 | まず既存DBの期間・欠損・当時の所属と公表時点を監査 |
| 算出方法の定義が必要なもの | 同名競走ID、ローテーション経路、補正時計、想定ペース、血統系統 | 正確な入力から同じ定義で再計算できるようにする |
| 別データや利用契約を要する可能性があるもの | 外厩、詳細調教、馬具詳細、記者評価、パドック評点 | 公開説明があることと、無料で一括取得・再利用できることは別。契約・過去収録範囲は未監査 |
| 観察者の判断を含むもの | 不利、仕上がり、歩様、折合い、陣営コメントの解釈 | 観測した事実、評価、予測への反映を別に残す |
| 今回の追加研究候補 | 風向風速や気温との細かな相互作用、目標レースの推定 | 本調査では個々の利用法の裏付けが不足。確認済みパーツに混ぜず追加調査対象とする |

## 研究に持ち込む前の注意点

- 同名重賞が10年あっても独立した開催は10回。出走馬数が多くても、独立開催の不足は解消しない。出走数・実頭数・年数・開催日数を併記する。
- 結果を見て大量の条件から良いものだけ選ぶと、偶然を拾う。探索候補数と不成立も残し、過去年で固定したルールを翌年に順次適用する。既に使った研究期間は未知テストと呼ばない。
- 上がり1位やその競走で実際に取った脚質は当該レース終了後の情報。事前予想には過去実績や想定値を使う。前哨戦の後続馬の次走成績も予測時点までに確定したものに限る。
- 当日の馬場偏りは対象レースより前の終了済み競走だけで推定する。後日確定した全日馬場差や進路評点を当日の入力へ戻さない。
- 人気・能力を調整しない騎手や血統成績を因果効果と呼ばない。多数の馬が同じ血統・厩舎・生産者に重複することを考慮する。
- 古い解説の閾値や運用範囲をそのまま現行仕様にしない。井内解説には旧美浦坂路との明示があり、JRDB展開説明には2010年時点の記述がある。今回確認できたのは分析形式。
- JRDBの[現行お知らせ](https://jrdb.com/notices)には2026年5月24日をもってローカル開催の当日馬具・脚元詳細情報の提供を終了したとの記載がある。後日の成績データと当日提供範囲を分けて監査する。
- 高い好走確率と割安な馬券は別。能力・条件評価と、オッズを使った購入判断を分離して比較する。

## 調査範囲と未確認事項

確認対象は公開本文・公式説明・公開された記事紹介。会員限定の具体的手順、予想家ごとの全ファクター、独自指数の完全な算式、各分析の独立した将来精度は不明。競馬ブックの調教欄PDFは403、TARGETの休み明け記事id146は取得失敗のため、その本文を根拠にしていない。JRA入門PDFの細かな説明は検索抽出の補助資料とし、具体的なデータ項目はJRDB等の本文でも照合した。

既存ローカルDB、SQL、APIには接続していない。取得契約、追加費用、過去収録年数、発走前可用性は未監査。モデル学習・製品コード・既定予想の変更は行っていない。

次はこの候補一覧を材料に、同名重賞を一つ選び、既存データで作れる部品と追加取得が必要な部品を監査する。すべてを実装対象に決めたものではない。
