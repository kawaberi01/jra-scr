## 保存先の意味

`api_runtime.races` / `runners` と版付き `race_card_snapshots` / `race_card_snapshot_runners` が既存Storeで保存される。APIでGETするだけでは、この業務用カード保存は自動実行されない。今回は取得後に明示保存した。

近走72件は `write_receipts.payload_json` のカード原応答内に保持される。現行write_cardは近走を研究用の正規化履歴行へ展開しない。固定研究snapshot31を更新したわけではない。

## 残る入力監査

1. APIのRunnerモデルに恒久馬IDがない。既存の研究ID/公式IDとの確認済み対応を用意し、馬名一致だけで確定しない。
2. 近4走の情報には競走名・格・斤量条件・競走記号が揃っていない。過去走のリンク/日付/場/Rを既存競走情報へ対応付け、現行特徴に必要な条件を補う。
3. 全保存期間の重賞実績、同名/同場距離の好走を判定するには近4走だけでは不足。固定履歴との突合と、保存終端2026-10-04以後の補完範囲を確定する。海外・地方を含む真の最新走の網羅性は未確認。
4. 騎手名には `岩田望来109M` 等の評価注記らしい文字が混在。原応答はそのまま保存し、確認済みの正規化名と混同しない。現行v2は騎手の効果を使わないが、他の項目も原文照合してから予想用へ変換する。
5. 馬体重は未公表としてNULL。当日馬場・馬体重・オッズの観測を取得済みとは呼ばない。今回返ったカード内オッズを別の時刻保証付きオッズsnapshotとみなさない。
6. v2の事前カード適用アダプターは未実装。既定モデルや予想係数を変更していない。

今回の確認は対象1競走の既存経路による取得・保存・読戻し。全年度・全履歴の取り込み成功や予想の完成を意味しない。コード変更がないため既存単体テストの再実行は行わず、実際の保存とreader接続での読戻しを確認方法とした。
